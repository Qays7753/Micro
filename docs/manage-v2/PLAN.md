# Micro Manage v2 — خطة التنفيذ

> **المرجع الملزم:** `docs/manage-v2/micro-manage-spec-final.md` (v1.1). خريطة الواجهة: `micro-manage-ux-final.md`. الشرح: `micro-manage-concept-final.md`. الأثر: `IMPACT.md`.
> **هذا الملف خطة لا أوامر.** أوامر ZAI تُكتب مرحلةً مرحلة عند بدئها، من قالب `ZAI-TASK-TEMPLATE.md`.
> **القاعدة:** كل مهمة تحمل أرقام قواعدها؛ وكل مرحلة تنتهي باختبارات خضراء + تحديث المتتبّع + مراجعة قبل أوامر المرحلة التالية.

## 0. تعريف «خلص» للمشروع كاملًا

1. كل الشاشات الثلاث + P-01 + النماذج والنوافذ تعمل على السيرفر، وكل رقم معروض يطابق §8 و§8.2.
2. كل اختبارات §13 (S1–S9، T1–T60) تمر، وكل اختبار ينتهي بـ`INV-1` و`INV-2`.
3. لا يوجد أي كود مالي قديم، ولا مسار ميت، ولا مخزن مانج محلي كمصدر بيانات، ولا استيراد من مجال محذوف.
4. كل عملية معاملة واحدة، والدفتر غير قابل للتعديل على مستوى القاعدة، ومنع التكرار فعّال (R-11، R-12، R-23، R-25).
5. التوصيل والسوق و«اسأل Micro» لم تُلمس إلا بحالات الفصل المعتمدة، ولا كسر فيها.
6. `pnpm check` أخضر، والوثائق محدَّثة، والمتتبّع مكتمل، وقرار الدمج مكتوب من المالك.
