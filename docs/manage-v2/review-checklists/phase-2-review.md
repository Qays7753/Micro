## 4. ما يُرفض فورًا بلا مناقشة

- أي `number` عشري أو `parseFloat` على مبلغ، أو `/100` أو `*100` في كود مانج الجديد.
- معادلة §8 مكتوبة خارج موديول القراءة، ولو «مؤقتًا».
- عملية بلا `INV-1` و`INV-2` في اختبارها.
- حماية الثبات بالكود فقط، أو تعليق يطلب عدم التعديل.
- idempotency بفحص سابق للمعاملة، أو مفتاح اختياري في مسار إنشاء.
- اختبار تزامن بـ mock، أو «سيُختبر لاحقًا».
- توسيع نطاق المهمة لتسهيل اختبار (تعديل ملف خارج المسموح).
- تضعيف حارس أو رفع سقف أو إضافة إعفاء.
