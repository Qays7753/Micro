## المهمة M1.11 — إضافة knip لكشف الكود الميت

**الالتزام:** `0d1f0c1d6e76c3c4ea4a29aec4883848d4d2f8f4` (يحمل الكود والتوثيق وتحديث المتتبّع معًا).

### ما تغيّر، ملفًا ملفًا

1. **`package.json`** — devDependency واحدة: `knip ^6.48.0` (لا تبعية أخرى)، وسكربت حرفي كما في الأمر: `"knip": "knip"`.
2. **`pnpm-lock.yaml`** — قفل التثبيت (+24 حزمة في شجرة knip). تحقق فوري بعده: كل الحراس خضراء، و`check-vendored-braces` ظل PASS بنفس النسخ الموثقة الأربع (انجراف التثبيت الجزئي وحّدته إعادة تثبيت نظيفة من القفل — الأدلة §5.6).
3. **`knip.json`** (جديد) — النطاق المفوَّض (مانج + أدواتي):
   - منطقة الجذر: `src/domain/manage/**` + `src/domain/costing/**` + `src/domain/planning/**` (مانج + النواة المحايدة المستخرجة لمانج/أدواتي + مجال أدواتي).
   - منطقة التطبيق: `client/src/application/{manage,planning,estimates}/**` (بيت مانج + بيوت أدواتي: التخطيط والتقديرات).
   - **الأبواب العامة معلنة نقاطِ دخول** بنمط أمر المالك نفسه: `src/domain/manage/index.ts` و`src/domain/costing/index.ts` و`src/domain/planning/index.ts` + `client/src/application/manage/strings/index.ts` (بنمط الأمر الحرفي `client/src/application/manage/**/index.ts`) ومعه بابا بيوت أدواتي `application/planning/index.ts` و`application/estimates/index.ts` (نمط STR-615 الموثق في السجل: الباب هو السطح العام المعلن) — فالواجهات العامة لا تُبلغ كغير مستعملة.
   - `paths` مثبتة صراحةً (`@/*` و`@micro-domain/*` و`virtual:pwa-register`) لأن مستخرج أسماء إضافة vite يخطئ حساب `path.resolve(import.meta.dirname, …)` الديناميكي في تكوين هذا المستودع.
   - قاعدتا `dependencies`/`devDependencies` مطفأتان: تحت نطاق مقصوص تُحسب كل التبعية الحية «غير مستعملة» لأن مستهلكيها خارج النطاق الداخلي — تحقق ذلك واحدًا واحدًا قبل الإطفاء (clsx وtailwind-merge وvaul وminiflare و@embedded-postgres/linux-x64 وstylelint-declaration-strict-value كلها مستعملة فعلًا في الشجرة — الأدلة §5.1). هاتان فئتا مستوى package.json لا مسارات، وقصّهما قصّ نطاق تحليل موثق لا إخفاء كود ميت.
4. **`.github/workflows/ci.yml`** — خطوة جديدة بعد `pnpm check`: `Detect dead code (knip — Manage and Tools scope)` تحمل `KNIP_DISABLE_RAW_TRANSFER=1` (مفتاح knip الموثق: مسار تسلسل oxc البديل أداءً فقط لا نتائج — موحَّد بين CI والتحقق المحلي؛ الحاوية المحلية بذاكرة 4GB لا تحيّن 6GB عنوانية لكل عملية تحليل). اختبارات سياسة CI الأربعة (38/38) خضراء بعد التعديل.
5. **تصحيح ذاتي (نتيجة حقيقية أصلها القاعدة لا أخفاها):** أول تشغيل كشف تصديرين ميتين حقيقيين في مسار من النطاق: `PLANNING_INPUT_SCHEMA_VERSION` و`PLANNING_CALCULATION_VERSION` في `planningCalculationLifecycle.ts` — لا مستورد لهما في الشجرة كلها (ولا الاختبارات)، لكنهما مستعملان محليًا (سطرا 131–132). أُزيلت كلمة `export` وحدها عنهما (مع سطر تعليق لكلٍّ يوثق السبب): القيمتان والسلوك والتعليقات الأصلية كما هي — ملف واحد خارج الملفات الحرفية المسموحة للمهمة، تصحيح ذاتي بقاعدة «التسليم بلا أحمر» موثق هنا وفي المتتبّع.
