## قواعد العمليتين (§5)

- **الدمج:** يحتاج صندوقين فعّالين (وإلا `E-BOX-STATE`)؛ يُرفض إن كان افتتاح أي منهما مجهولًا (`E-MERGE-UNKNOWN` — T47/T53)؛ القيد بتاريخ اليوم (R-26)؛ الصندوق المدموج لا يقبل أي عملية بعدها (`E-BOX-STATE` — مثبتًا بتحويلٍ إليه).
- **الفصل:** يعيد تنشيط الصف المدموج نفسه (قيد R-9 الكلي)؛ `0 ≤ المبلغ ≤ رصيد النقد` (`E-SPLIT-AMOUNT` — T41)؛ المبلغ 0 قلب صفٍّ بلا قيد (T59)؛ نقدٌ مجهول الافتتاح → `E-MERGE-UNKNOWN`؛ السالب مدخل مشوه (`E-AMOUNT`).
- **§5.0:** مبلغ الصف = المبلغ المتحرك (0 عند غياب القيد)؛ مجموعة الفلتر `op.transfer`؛ box_id = الحساب.
