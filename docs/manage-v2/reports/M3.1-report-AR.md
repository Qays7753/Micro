## القراءة التفسيرية (خمس)

1. **R-25 على سطح R-17:** الحفظ مُرادف بالبناء — معرف المنتج من العميل يُدخل upsert محصورًا بالمشروع؛ إعادة المحاولة تعيد كتابة القيم نفسها. لا حجز (project_id, request_id) لأن لا عملية تُنشأ أصلًا (R-17: المنتجات تحديث مباشر لا عمليات) — موثق في رأس المعالج.
2. **تكلفة 0 صريحة قيمة:** «الصف بيلزمه الاثنين» — الاسم أو التكلفة الغائبان يُسقطان الصف؛ أما 0 فقيمة مقدَّمة (مكون مجاني) — §3.3 تسمح `cost_minor ≥ 0`.
3. **ترتيب قائمة P-22:** المواصفة لا تفرض ترتيبًا؛ اعتُمد ترتيب الإنشاء (`archived, created_at, id`) — ترتيب «الأكثر استخدامًا» في P-61 ملك شاشة الاقتراحات (مرحلة 5).
4. **`productId` خارج شكل اللقطة:** اللقطة بيانات البند المنسوخة (وصف/سعر/تكلفة/مكونات)؛ `product_id` مرجع السطر — يمرره المستدعي (M3.2 تملكه في مخططها).
5. **مفتاح JSON `cost_minor`:** حرفي §3.5 (لا camelCase) — يوافق فحص مصدر M1.7 الذي يمنع تسمية Minor في وحدة مانج.
