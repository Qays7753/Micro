# عقد Pilot لقيد تشغيل محلي محدود — Micro G9.1

**الحالة:** `CURRENT / G9.1 CONTRACT GATE`
**النطاق:** قيد واحد اختياري قابل للقياس في النسخة الأولى، فوق المواعيد المحلية القائمة.

## سؤال القرار

هل أقبل أو أؤجل العمل عندما أملك قيدًا معروفًا في نافذة زمنية أو مورد واحد أو مادة حرجة واحدة؟ يختار المستخدم **نوعًا واحدًا فقط** من القيود؛ لا يدّعي Micro معرفة السعة عند غياب البيانات.

## النوع الأولي المختار

يبدأ Pilot بقيد **نافذة زمنية يومية** مرتبط بيوم العمل المحلي: حد دقائق اختياري يحدده المالك، وتقارن به مدد المواعيد المعروفة في اليوم نفسه. لا ينشئ النظام موعدًا، ولا يضمن التوفر، ولا يعيّن موظفًا أو موردًا.

| الحالة | الإشارة | القرار المعروض |
|---|---|---|
| غير مستخدم | لم يحدد المالك سعة يومية أو لا توجد مدة معروفة | `unknown`: لا قبول/رفض آلي؛ راجع الوقت أو اتركه مجهولًا |
| ضمن الحد | مجموع المدد المعروفة أقل أو يساوي الحد | `within_limit`: القيد لا يظهر سببًا للتأجيل |
| متجاوز | مجموع المدد المعروفة أكبر من الحد | `over_limit`: تحذير قابل للتفسير؛ المالك يقرر القبول أو التأجيل |
| بيانات ناقصة | موعد بلا وقت/مدة أو مدة غير قابلة للمقارنة | `needs_review`: لا تحول المجهول إلى صفر |
| ملغى | الموعد ملغى أو أزيل بسبب | لا يدخل في ضغط اليوم، ويبقى حدث الإلغاء محفوظًا |
| تعارض | موعدين متداخلين | تحذير مستقل؛ لا يتحول تلقائيًا إلى رفض أو تعديل مالي |

## أقل البيانات والقواعد

تستخدم القراءة `scheduledFor` و`durationMinutes` و`status` و`dailyScheduleCapacityMinutes` فقط. تقبل المدة من عقد الموعد الحالي، وتجمع المدد المعروفة للمواعيد غير الملغاة في اليوم المحلي. لا تدخل المواعيد ذات المدة المجهولة في الجمع، بل تزيد عداد `needs_review` وتُظهر سبب النقص.

لا يغيّر القيد `CashWallet` أو `FinancialEvent` أو الذمم أو النتيجة أو `CostSnapshot` أو سعرًا أو طلبًا تاريخيًا. تغيير السعة أو إزالتها قابل للعكس كسجل تفضيل محلي، ولا ينشئ أثرًا ماليًا.

## السيناريوهات الإلزامية

يجب أن تغطي الاختبارات يومًا ضمن الحد، يومًا متجاوزًا، تعارضًا، مدة مفقودة، سعة غير مفعلة، إلغاء موعد، إعادة تحميل، وإعادة طلب القراءة. يجب أن تثبت أن القراءة idempotent ولا تكتب موعدًا أو مالًا، وأن إلغاء الموعد يستبعده دون حذف الحدث.

## الحدود والممنوعات

لا تقويم خارجي، ولا Google Calendar، ولا حجز ذاتي، ولا ضمان توفر، ولا تحسين أو توصية تلقائية ملزمة، ولا موارد متعددة، ولا موظفون، ولا مادة حرجة في هذا Pilot. إذا لم يحدد المالك السعة أو لم يسجل مدة، فالنتيجة `unknown` أو `needs_review` وليست صفرًا أو رفضًا كاذبًا.

## بوابة التنفيذ

لا تبدأ G9.2 قبل دمج هذا العقد. التنفيذ التالي يضيف Domain/Application/Storage للقيد اليومي فقط، ويصل القراءة بسياق الجدول الحالي دون إنشاء Dashboard أو Calendar جديد.
