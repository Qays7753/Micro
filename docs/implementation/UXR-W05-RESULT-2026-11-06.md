### PERF-005 — كلفة فحص idempotency بمسح كامل المخزن داخل معاملة الكتابة

| N (أحداث) | حفظ حدث مالي جديد — وسيط | مدى | حفظ بيع مباشر — وسيط |
|---|---|---|---|
| 100 | 0.483 ms | 0.43–4.01 ms | 0.368 ms |
| 1000 | 3.562 ms | 3.45–33.1 ms | 2.591 ms |
| 5000 | 17.555 ms | 17.08–57.3 ms | 12.496 ms |

**معايير الإغلاق (04):** تكرار الأمر بنفس المفتاح يحفظ الأثر **مرة واحدة** (عدّ العائلة قبل/بعد: +1 بالضبط ثم إعادة الاستخدام بلا كتابة ثانية) ✓ · نداءان متزامنان بنفس المفتاح → **أثر واحد** (فحص داخل المعاملة) ✓ · نفس نص المفتاح في عائلة أخرى (بيع مباشر) لا يتصادم (مخازن منفصلة) ✓ · **بعد الحفظ مباشرة القراءة تعكس الأثر** (لا قِدم) ✓.

**القرار:** لا عنق معتبر مثبت عند الأحجام الواقعية — كلفة 17.6ms وسيطًا عند 5000 سجل (سنة استخدام كثيف) ضمن زر حفظ تفاعلي، والحتمية هي عقد P0 محروس. **يُغلق بالقياس بلا تعديل**؛ أي استبدال بالفهرس = مخطط 42 + زوج تصدير 35 + قرار مالك منفصل — **حزمة قرار موثقة للمالك** (النمو خطي ≈3.5ms/1000 سجل).

### PERF-013 — تصفية الطلبات والمنسق لكل ضغطة

- **Chromium 1×CPU فوق 1000 طلب مبذور:** كتابة «عمل اصطناعي 42» حرفًا حرفًا (14 ضغطة، ~70ms بينها): **صفر مهام طويلة** وصفر إدخالات تفاعل بطيئة (PerformanceObserver type=event)؛ النتائج صحيحة: 11 صفًا يطابق الاستعلام نصيًّا؛ **مسح البحث أعاد القائمة كاملة (30 = حد العرض) — لا نتائج قديمة** ✓.
- **التحقق الأثقل 4×CPU (محاكاة جهاز بطيء):** صفر مهام طويلة أيضًا (typingWall 1472ms لعينة 14 ضغطة).
- منسق التاريخ: كائن جديد لكل نداء **مقصود** لمتابعة توقيت الجهاز الحي (`formatters.ts` موثق) ولم يُثبت له كلفة — لا مساس.

**القرار:** فرضيتا الكلفة غير مثبتتين عند الأحجام المقيسة (شاشة تجلس تحت سقف عرض + في الذاكرة). **يُغلق بالبروفايل بلا تعديل** (لا memo بلا دليل).

### PERF-014 — كتابة المسودة عند كل تغيير قيمة (3 عمليات IndexedDB)

- **مختبر Node:** 200 حفظ متتالٍ: وسيط **0.10–0.11ms** عبر الأحجام (0.109/0.103/0.104 عند N=100/1000/5000؛ مخزن المسودات سجل واحد لكل نموذج) — **~1.3% من ميزانية إطار 60fps**، والحد 32k محروس (`too_large` مرفوض ✓)، وحارس التزامن يرفض الطابع المتقادم بـ`conflict` بلا كتابة ✓.
- **Chromium (أثر المستخدم):** كتابة مسودة في محرر المصروف الموجه ثم **إغلاق مفاجئ** للصفحة → عند الفتح: عرض استرجاع صريح «عندك مسودة غير محفوظة…» → استرجاع يعيد القيم **بالضبط** (33.10 + النص الحرفي) ✓.

**القرار:** لا debounce — الكلفة المقيسة هامشية والمتانة القصوى للمسودة هي العقد (٣٦). **يُغلق بالقياس بلا تعديل.**

### A22 — تحديث نسخة مع مسودة وسجل ثم تشغيل بلا شبكة

بناءان متتاليان بمؤشر نشر محلي غير مُتتبَّع (ملف وسم HTML في `public/` فقط أثناء البناء ثم يُحذف — شجرة العمل نظيفة): A→B ثم B→C.

- **فوق نموذج قذر:** إشعار «تحديث Micro جاهز…» الصادق؛ الضغط على «حدّث الآن» يعرض «عندك مدخلات غير محفوظة — احفظها أولًا ثم حدّث؛ التحديث لن يبدأ فوق عملك المفتوح» و**لا إعادة تحميل** (علامة نافذة باقية) ✓ (عقد ٣٨).
- **بعد الخروج النظيف (حارس «اخرج دون حفظ»):** التحديث يعيد التحميل **مرة واحدة**، والعامل الجديد نشط بدليل إرساء precache لمؤشر النسخة الجديدة تحت `workbox-precache` ✓؛ الأحداث (5001) والمسودة (1) كما هما تمامًا ✓.
- **بلا شبكة بعد التهيئة:** إعادة تحميل offline → الرئيسية جاهزة من كاش SW في **1035ms**، البيانات سليمة، وإشعار «أنت غير متصل الآن… لا مزامنة أو نسخة سحابية» الصادق ✓.
