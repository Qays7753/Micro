## تصور المستخدم بعد الإصلاح

- **الرئيسية:** اسم المشروع، إجراءات سريعة، متابعات تستحق الفعل، لمحة الفترة والنقد الآن. لا حائط شروحات.
- **الطلبات:** طلب جديد، تبديل مضغوط للقائمة والتقويم، بحث وتصفية، ثم الطلبات أو المواعيد مباشرة.
- **المالية:** تسجيل عملية، النقد والمستحقات الآن، نتيجة الفترة بحالتها، ثم مدخلان للإدارة وفهرس لبقية الوظائف.
- **الشاشات الداخلية:** عنوان المهمة، بياناتها اللازمة، فعل رئيسي واضح، تفاصيل إضافية عند الطلب، وإفصاح قصير ظاهر عندما يؤثر في القرار.
