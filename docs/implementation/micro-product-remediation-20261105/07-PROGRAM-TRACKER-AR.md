## حالات المرآة

PLANNED → READY بعد نشر الأمر وقبول التبعيات وClaim صالح → IN_PROGRESS → IN_REVIEW → قبول المالك على الفرع. مراجعة Manus المستقلة على SHA محدد؛ ChatGPT ليس بوابة. بعد الدمج MERGED_UNVERIFIED ثم VERIFIED بعد تحقق main. BLOCKED يذكر العائق وصاحبه وإجراءه.

## سجل التسليم الذي يملأ لكل دفعة

| الحقل | المطلوب |
|---|---|
| تعريف العمل | stage ID، معرفات المشكلات و UNITs/العقود، Claim/Item الفعلي |
| خط الأساس | main SHA الحي، base الدفعة، رأس branch الحالي |
| التغييرات | commits، الملفات، معاني النصوص، ما حذف/نقل ولماذا وأين البديل |
| البيانات | schema/export قبل/بعد أو عدم الانطباق وسببه، حماية الرجوع |
| الدليل | اختبار/خطوات/قبل وبعد/قياس خام، النتيجة وحدودها، ما لم ينفذ |
| المراجعة | candidate SHA موحد، حكم Manus المستقل، الملاحظات وكيف عولجت؛ ChatGPT غير مطلوب |
| القرار | قبول المالك أو طلب تصحيح أو منع الانتقال |
| الاستئناف | آخر التزام آمن، ملفات الأمر الحالي، العوائق والخطوة المحددة |

لا يحتفظ ZAI بالتقدم في ذاكرة المحادثة فقط. يسلم تقريره ويحدث المصدر الرسمي بتكليف الأمر؛ تتحول المرآة لإحالة للسلطة الحية عند التسجيل. تغيير حسابه أو محادثته لا يتطلب إعادة جرد النظام.
