# مرآة متابعة البرنامج والتسليم

هذه مرآة موجات التنفيذ الخمس؛ الحالة الرسمية في Operations Control، وبطاقات UXR الأصلية تحفظ نطاق كل وحدة. لا تعدل generated يدويًا؛ Drive ليس مصدر أوامر ZAI.

**نقطة الاستئناف:** **W01–W05 منفذة ومسلَّمة كلها** (تقاريرها المؤرخة أعلاه). W05 (UXR-07 ثم UXR-08) نُفذت وسُلّمت بأمر المرحلة النهائية المؤرخ 2026-11-06 (DOC-032/WS-248 — IN_REVIEW بانتظار قرر المالك): قياسات PERF-005/006/007/013/014 مغلقة بالقياس بلا تعديل، وأدلة A20/A22 وF-012، وتغطية المستهلكين النهائية (مع Foundation التي عالجتها المراجعة ٢ في `4360a92c`)، والقبول التكاملي، وتسديد ديون الفحوص؛ ثم **المراجعة الخماسية المستقلة بجولتيها** (15 عيبًا مؤكدًا عبر الجولتين — عولجت كلها جذريًا في `4360a92c` وملحق التسليم؛ المال/المجال والبيانات/الأمن صفر عيوب) والفحوص المركزة (15 ملفًا/79 اختبارًا خضراء) وفحص المستودع الكامل مرة واحدة على الشجرة النهائية والتحقق من Actions وCloudflare على الرأس النهائي بعينه (تعليق التسليم على PR #384). **لا قبول ذاتي ولا دمج — قرار القبول والدمج للمالك وحده**؛ PR #384 يبقى Draft.

## حالات المرآة

PLANNED → READY بعد نشر الأمر وقبول التبعيات وClaim صالح → IN_PROGRESS → IN_REVIEW → قبول المالك على الفرع. مراجعة Manus المستقلة على SHA محدد؛ ChatGPT ليس بوابة. بعد الدمج MERGED_UNVERIFIED ثم VERIFIED بعد تحقق main. BLOCKED يذكر العائق وصاحبه وإجراءه.

## سجل التسليم الذي يملأ لكل دفعة

| الحقل | المطلوب |
|---|---|
| تعريف العمل | stage ID، معرفات المشكلات و UNITs/العقود، Claim/Item الفعلي |
| خط الأساس | main SHA الحي، base الدفعة، رأس branch الحالي |
| التغييرات | commits، الملفات، معاني النصوص، ما حذف/نقل ولماذا وأين البديل |
| البيانات | schema/export قبل/بعد أو عدم الانطباق وسببه، حماية الرجوع |
| الدليل | اختبار/خطوات/قبل وبعد/قياس خام، النتيجة وحدودها، ما لم ينفذ |
| المراجعة | candidate SHA موحد، حكم Manus المستقل، الملاحظات وكيف عولجت؛ ChatGPT غير مطلوب |
| القرار | قبول المالك أو طلب تصحيح أو منع الانتقال |
| الاستئناف | آخر التزام آمن، ملفات الأمر الحالي، العوائق والخطوة المحددة |

لا يحتفظ ZAI بالتقدم في ذاكرة المحادثة فقط. يسلم تقريره ويحدث المصدر الرسمي بتكليف الأمر؛ تتحول المرآة لإحالة للسلطة الحية عند التسجيل. تغيير حسابه أو محادثته لا يتطلب إعادة جرد النظام.
