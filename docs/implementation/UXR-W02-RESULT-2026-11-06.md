## خطة التنفيذ الموجزة (من بطاقة UXR-03 مباشرة)

1. **F-003** — إصلاح ملكية التاريخ في اللوحة: استهلاك الحارس بلا `back()` في مسارات التنقل/الميزانيات/المغادرة، كشف بعد الاستقرار؛ تحديث حراس S15-MR-001 بالعقد الجديد وإضافة فحص الرابط النهائي/خطوات الرجوع (ما كان غائبًا — F-013).
2. **F-002** — مدخل المصروف الموحد: سؤال حالة الدفع الصريح («دفعت الآن»/«لم أدفع بعد») من الجذر واللوحة → توجيه للمحررين القائمين `_cash`/`_payable` بـreturnTo=/finance (UXR-D09)؛ إصلاح المستهلكين الاثنين.
3. **F-005 + F-010 + F-008 (FIN)** — إزالة التكديس وفق DEC-FIN-01/عقد 02-FIN: أول مشهد (أفعال + الآن + النتيجة + مال المالك)، الطبقة الثانية (قراءة الفترة → الجسر → التغطية والتعادل → السياسات → الميزانيات)، فهرس اللوحة بالمجموعات الخمس الكنونية (F-016: دمج /suppliers، إضافة عدّ الصندوق، مداخل سياقية للوظائف الفرعية)، توزيع قيم «ما نعرفه الآن» على أصحابها، راتشة كثافة النص بالقياس.
4. **F-009 (ORD)** — مفتاحا العرض المضغوطان (القائمة/التقويم ونطاق العرض) بعقد إتاحة كامل فوق radio أصلية + نصوص القاموس (سطر النطاق، مثال البحث، الفراغات الصادقة).
5. **HOM + Schedule** — عنوان وجهة واحد (حذف overline الرئيسية/التنظيم التشغيلي)، COPY-13 للمتابعات، اختصار «اسأل Micro» إلى عنصر واحد عند الطلب في قائمة «مايكرو» (DEC-SHELL-01 الموحدة — موضع ضيق في القشرة).
6. **الإغلاق** — فحوص مركزة بعد كل وحدة؛ فحص كامل واحد على الشجرة النهائية؛ ترسية أسطح الحزمة ببروتوكولها؛ توثيق/Control/تقرير؛ ثم مراجعتان قراءة-فوق على الرأس النهائي بعينه؛ فحص Actions/Cloudflare على الرأس الفعلي؛ إبقاء PR Draft؛ توقف وبلاغ.
