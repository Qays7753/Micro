## 2. ترتيب العمل الملزم لهذه الخطة

1. تثبيت التجربة والمواصفات الوظيفية في أصحابها مع المعاني المالية المعتمدة، دون فرض مخطط تخزين.
2. تثبيت نسخة مرجعية من الوثائق: أسماء الملفات وإصداراتها وموافقاتها وبصماتها. يعين ZAI التزام المصدر الذي يفحصه ويفصل أي انزياح لاحق.
3. تحليل الموجود في الكود مقابل **جميع** المواصفات: إعادة استخدام، تعديل، إضافة، إزالة مبررة، مجهول، أو تعارض. لا تنفيذ أثناء التحليل ولا إعادة جرد بلا غرض.
4. مراجعة النتيجة ثم إعداد عقد بيانات وقواعد مالية مشترك، وتحديد مخطط التخزين والترحيل والقراء وحدود الالتزام والتعافي. لا تملى الجداول على التحليل مسبقًا.
5. تحديث ملفات UNIT بالمقابلات والإحالات الدقيقة إلى العقد المشترك، ثم تجهيز دفعات التنفيذ واختبارات المشترك قبل إعلان الجاهزية.

لا يبدأ تنفيذ كتابة مالية أو ترحيل لمكوّن متأثر قبل تحديد عقده المشترك وتبعاته. يمكن إكمال التخطيط ومراجعة الواجهة دون تشغيل أثر مالي. الاجتياز قد يكون لدفعة مترابطة بعد جرد التبعيات، وليس ادعاءً بأن كل النظام جاهز أو إلزام إعادة بنائه.

## 3. بوابة DATA-GATE قبل التنفيذ

لكل عائلة بيانات/قصد عمل في نطاق دفعة التنفيذ، يجب أن يثبت العقد:

| المعرف | المطلوب قبل إتاحة السلوك |
|---|---|
| DATA-G01 | هوية المعنى والمالك والكاتب القانوني والقراء؛ تمييز أصل العمل من فهرس أو تجميع مشتق أو مسودة. |
| DATA-G02 | أنواع القيم، الوحدة والدقة والتقريب وحدودها، وحالات مؤكد/تقريبي/مجهول/صفر/غير منطبق/لم يستكمل؛ لا صفر أو طرف أو تاريخ مختلق. |
| DATA-G03 | هوية المشروع والسجلات والعلاقات وإصداراتها؛ فصل تاريخ الواقعة والفترة والقياس ووقت الإدخال والتعديل. |
| DATA-G04 | أثر القصد على النقد والإيراد والتكلفة والربح والذمم والمقدمات ومال المالك والكميات؛ ما يُحتسب مرة واحدة وما لا يُنشأ أصلًا. |
| DATA-G05 | حد الكتابة الصحيح، والتحقق من الحالة الحية، والتعارض، والحتمية، والحفظ المجهول أو الجزئي والتعافي؛ لا تسمية نداءين منفصلين معاملة ذرية بلا دليل. |
| DATA-G06 | قواعد التصحيح والإلغاء ورد المال والتفصيل اللاحق وربط المصادر، دون إعادة تنفيذ الأصل أو محو الدليل أو احتساب الأثر مرتين. |
| DATA-G07 | نطاق القراء والتقارير والمقارنات والميزانيات والتكاليف والمعرفة؛ لا قارئ محلي يخترع معادلة بديلة. |
| DATA-G08 | إصدار البيانات والتحقق والترحيل وتوافق المخازن والنسخة الاحتياطية واستبدالها والتعافي منها دون إعادة تشغيل عمليات. |
| DATA-G09 | فحوص ذات نتائج متوقعة للمنطق المشترك والتخزين المحلي والفشل والتعارض والتكرار والتصحيح والاستعادة؛ الفحوص المكتوبة ليست نتائج تشغيل. |

هذه قائمة عقد وتحليل، لا أسماء حقول أو جداول أو واجهات برمجية مفروضة. عدم احتياج عائلة لبند يثبت بسبب محدد، ولا يملأ «غير منطبق» افتراضيًا.
