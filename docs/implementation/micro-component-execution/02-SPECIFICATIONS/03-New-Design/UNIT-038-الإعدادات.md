## P3 — تكليف UNIT-038 المحدّث: المنتج والبيانات وبنية التنفيذ

### P3.2 — الحقول والملكية والأثر المالي

هذا **فرق البيانات** اللازم فوق قاموسB الموجود؛ لا يلغي الحقول الصحيحة أو يسقط سبب ظهورها/إلزامها. التسميات التقنية المقترحة أدناه تصف عقد المعنى، ولا تدعي أن كل حقل مضاف موجود حاليًا. لا نسخ كامل لقاموس جديد منافس.

| العنصر محل التعديل | التمثيل والقيد ومصير القديم |
|---|---|
| offeringPreference/workMode | تفضيل منتجات/خدمات/كلاهما أو غير مختار، مستقل عنworkMode ودون إعادة تصنيف الماضي. |
| capability preferences | اختيارية وظائف، لا مستويات اشتراك أو معالج عام؛ الإخفاء لا يحذف حقوقًا أو يعيد قدرة ملغاة. |
| dataGeneration | جيل محلي يرفض النماذج القديمة؛ يستثنى حقله من التصدير خلاف بقيةpreferences الداخلة. |
| maintenance/returnTo | مدخل لصاحب كل إجراء، لا نموذج مال داخل الإعدادات. |

**الأثر وحد الالتزام:** تحديث حقول محددة بنسخة حية مع حفظ البقية؛044 يجدد الجيل في حد الاستبدال ولا يعيده تفضيل قديم.

**تخزين/ترحيل هذا المكون:** local-preferences داخل اللقطة، مع استثناء الجيل الجديد صراحة. حذف042 مستهدف لا تصفير أعمال، وLightMode فقط.

**العائلات القائمة المحتمل لمسها:** `local-preferences`, `form-drafts` هذه قائمة نطاق، وليست أمرًا بإدراج كل مخزن في كل معاملة.044 يراجع كل عائلات اللقطة في§19، لا هذه القائمة المختصرة فقط.

**الحرس العام عند وجود كتابة:** الأمر بهوية قصد وحمولة ونسخ مصادر وجيل، والمبلغ الصحيح بوحدةminor والتاريخ الفعلي؛ فحص الحالة الحية داخل حد الكتابة. نجاح مؤكد أو فشل بلا أثر أو مآل مجهول يسترد بالقصد نفسه. عند تغيير النوع/المخزن: المهايئان والتصدير والوارد والعلاقات والمهاجرات في الشريحة نفسها. المخازن المشتركة المرشحة في§8 ليست منشأة تلقائيًا، ولا يختار المنفذ أرقامschema/export من هذا الملف. القراءة البحتة لا تنشئcommand-receipt أو حركة مال لإثبات أنها فُتحت.
