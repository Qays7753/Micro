## P3 — تكليف UNIT-032 المحدّث: المنتج والبيانات وبنية التنفيذ

**التاريخ:**2026-10-27 · **الحالة:** تكليف تعديل/دمج حسب القرار المعتمد؛ التخطيط موثق، والتنفيذ والاختبار والإغلاق لم تبدأ بهذه الجولة.
**طريقة القراءة:** هذا القسم جزء من ملف المكون نفسه، لا ملف بديل أو تصميم موازٍ. اقرأ المهمة والتصميم والحقول والمحتوى فيA/B، ثم تعليماتP3 والحذف المعلل وB-DUP والقبول. المعرف والاسم والمشكلات والأدلة وACD/DUP السابقة محفوظة. أي وصف للمصدر عندSHA أقدم يبقى دليلًا تاريخيًا لا حقيقة حية عن الكود الحالي.

### P3.2 — الحقول والملكية والأثر المالي

هذا **فرق البيانات** اللازم فوق قاموسB الموجود؛ لا يلغي الحقول الصحيحة أو يسقط سبب ظهورها/إلزامها. التسميات التقنية المقترحة أدناه تصف عقد المعنى، ولا تدعي أن كل حقل مضاف موجود حاليًا. لا نسخ كامل لقاموس جديد منافس.

| العنصر محل التعديل | التمثيل والقيد ومصير القديم |
|---|---|
| estimateId/inputVersion/snapshot | هوية ومدخلات محفوظة، لا نسخ كتكلفة طلب أو واقعة فعلية. |
| knowledge/precision | درجة معرفة وإجمالي دقيق وافتراضات، دون تحديث تلقائي بأسعار029 عند الفتح. |
| old route/returnTo | تحويل إلى031 بمرجع صالح ورجوع قانوني، دون صفحة أو دفتر موازٍ. |

**الأثر وحد الالتزام:** المحفوظ من صاحبه031 بنسخته؛ الحذف لا يمس منتجًا أو بيعًا أو اتفاقًا ولا يؤثر النقد.

**تخزين/ترحيل هذا المكون:** cost-estimates يبقى في النسخ؛ لا مسح بسبب إزالة الصفحة أو إعادة تنفيذ مال عند العرض.

**العائلات القائمة المحتمل لمسها:** `cost-estimates` هذه قائمة نطاق، وليست أمرًا بإدراج كل مخزن في كل معاملة.044 يراجع كل عائلات اللقطة في§19، لا هذه القائمة المختصرة فقط.

**الحرس العام عند وجود كتابة:** الأمر بهوية قصد وحمولة ونسخ مصادر وجيل، والمبلغ الصحيح بوحدةminor والتاريخ الفعلي؛ فحص الحالة الحية داخل حد الكتابة. نجاح مؤكد أو فشل بلا أثر أو مآل مجهول يسترد بالقصد نفسه. عند تغيير النوع/المخزن: المهايئان والتصدير والوارد والعلاقات والمهاجرات في الشريحة نفسها. المخازن المشتركة المرشحة في§8 ليست منشأة تلقائيًا، ولا يختار المنفذ أرقامschema/export من هذا الملف. القراءة البحتة لا تنشئcommand-receipt أو حركة مال لإثبات أنها فُتحت.

### B2. الحالات والحماية

فشل الحفظ:«لم يُحفظ الحساب. حاول مرة أخرى» مع المدخلات نفسها. فشل الفتح:«تعذر فتح الحساب» مع إعادة محاولة؛لا محرر فارغ بدل خطأ.لا يوجد الحساب:رسالة مناسبة والعودة للقائمة دون إزالة بيانات أخرى. حذف آخر محفوظ يخفي مدخل المحفوظات بعد التزام الحذف؛عند فشل قراءة عددها لا يدعى أنها فارغة.

الرجوع يبقي سياق القائمة أو الحاسبة؛إن وجدت تعديلات غير محفوظة يتيح متابعة التعديل أو الخروج دون حفظ. لا تأكيد لكل رجوع إذا لم يتغير شيء.استعادة مسودة مؤقتة بعد تحديث الصفحة،إن نفذت،تعلن كمسودة غير محفوظة وتختلف عن حفظ حساب؛لا إكمال031/032 قبل اختبار هذا العقد. لا حفظ تلقائي دائم أو حفظ منتج من الاستعادة.

الحذف يلغي الحساب التخطيطي فقط؛الطلب التاريخي المرتبط قديمًا يحتفظ بلقطته ومعنى مصدره حتى لو لم يعد الأصل موجودًا.لا حذف متسلسل لكلفة طلب أو سعر اتفاق أو كتالوج.النسخ الاحتياطي044 ينقل الحسابات المدعومة دون تغيير سياقها،والنسخ السابقة تبقى قابلة للترحيل الصريح أو الرفض الآمن.
