# Micro — إضافة الحسابات السابقة والعودة بعد انقطاع

**المعرّف:** JRN-010 · **النسخة:** V1 · **التاريخ:**2026-10-26 — عمّان.
**الحالة:** مفهوم وظيفي مثبت بطلب المالك؛ المواصفة المالية والتخزين المشترك مؤجلان إلىDATA-01 قبل التنفيذ. لا كود أو اختبار تشغيل أو إغلاق.
**مصدر السلوك:** [UNIT-002 — استكمال الحسابات](../../03-New-Design/UNIT-002-استكمال-بيانات-المشروع.md#accounts-completion-20261026). هذه الرحلة توثق الترتيب والانتقالات والاستثناءات؛ لا دفتر مالي أو نسخة ثانية من حقول كل مالك.

## A. الغرض والنطاق

يسجل المستخدم من اليوم أو من تاريخ سابق يختاره، أو يستكمل ما لم يسجله بعد انقطاع؛ يحتفظ بتاريخه ويعود للعمل دون إعادة بناء الماضي كله. المجاميع والتقديرات اختيار متاح ضمن حدود المعرفة والتغطية، والتفاصيل تظهر عند الحاجة. لا يضبط هذا المسار السجلات حتى تتوازن تلقائيًا، ولا يحول001 إلى إعداد طويل.

الواجهة عربيةRTL، أرقام0–9، هاتف فقط، دون تغيير الهوية البصرية. الأسئلة قصيرة، والتفسير العام خلف مساعدة متاحة؛ النطاق والمال والخطأ والحد المؤثر ظاهرة باختصار. لا سؤال طبقة أو إعداد كل القدرات.

## E. التوسع والرجوع والسياق

- خطوة واحدة ظاهرة في كل مرة مع تقدم مفهوم؛ عدد المراحل الفعلي يتغير بالاختيارات. يمكن الرجوع للخطوات السابقة دون فقد، ولا قائمة ضخمة مفتوحة للجميع.
- «+ إضافة تفاصيل» يفتح داخل السياق أو محرر المالك ضمن إطار عودة يحفظ المسودة، ولا يفرض قائمة منفصلة أو يعيد اختيار الفترة. لا ترحيل مالي من مجرد فتحه أو الرجوع منه.
- الانتقال إلى أصل قديم للتصحيح يحفظ مرحلة الرحلة ومدخلاتها. بعد تصحيح محفوظ يعاد تحديث المراجعة، ولا يعاد حفظ الأصل من مسودة قديمة.
- إغلاق المساعدة/الطبقة يعيد التركيز، وخروج متسخ يتيح الاحتفاظ كمسودة أو تجاهلها بوضوح. تجاهل المسودة لا يحذف أعمالًا محفوظة سابقًا.
- المسودة محلية مرتبطة بسياق المشروع ونسخة المعنى؛ لا تتحول إلى عمليات من التحديث أو الاستعادة. إبطال سياقها بعد044 يطلب مراجعة ولا يستأنف كتابة.

## F. المعرفة والمقارنة والحالات الاستثنائية

| الحالة | السلوك |
|---|---|

| مبلغ تقريبي | وسم عند الرقم والمعاينة والقراء؛ «النتائج مبنية على المبالغ التي أدخلتها. يمكنك تعديلها لاحقًا.» لا نسبة دقة أو هامش مختلق أو لوم للانقطاع. |
| رصيد سابق أو قياس حالي مجهول | لا فرق نقدي محدد دون أساس مطابق؛ يمكن حفظ المعلومات الصحيحة والمتابعة دون ادعاء مطابقة. |
| فرق مؤهل مع أرقام تقريبية | إن عرضت المقارنة وفق العقد، تسمى «فرق بحسب المبالغ التقديرية» لا عجزًا مؤكدًا أو اقتراح قيمة نهائية؛ حد التسامح لا يخترع. |
| مبلغ واحد مجهول | يمكن تذكيره بمراجعة القسم الموافق لاتجاه الفرق بعد الحركات الأخرى؛ لا يعبأ الرقم تلقائيًا أو يدّعى أن إجمالي البيع/المصروف عرف من صافي النقد. |
| أكثر من مجهول | لا توزيع للفرق عليها؛ روابط مباشرة للأقسام الناقصة أو متابعة لاحقًا. |
| تطابق النقد | توافق الرقمين في نطاق المقارنة فقط؛ لا اكتمال السجلات أو الربح أو المخزون. |
| حقوق أو مقدمات قديمة | تفصيل بسيط وصاحب حق وأصل عند وجوده؛ لا عميل وهمي، ولا قبض سابق يضاف اليوم، ولا تسوية دين مجهول التاريخ بتاريخ اليوم. ما تعذر توثيقه يبقى للاستكمال. |
| مجموع يغطي أكثر من يوم/شهر | يحفظ نطاقًا؛ لا توزيع متساوٍ أو تاريخ اليوم كواقعة أو تقرير يومي مختلق. |
| تفصيل يتجاوز المجموع أو اشتباه بتداخل | مراجعة صريحة للمدى وما يغطيه الرقم؛ لا مجموع سالب أو تعديل تلقائي أو حذف السجلات. |
| تغير مصدر أثناء التحرير | تبطل المعاينة المتأثرة وتحدث قبل الحفظ؛ لا تكرار أو overwrite صامت. |
| فشل أو مآل حفظ غير معلوم | المدخلات محفوظة حيث أمكن، والاسترداد يتحقق من نفس القصد قبل محاولة جديدة. لا نجاح وهمي أو دعوة لإعادة تسجيل ما نجح. |

## I. ما يبقى مؤجلًا

المخطط وأسماء الحقول والخدمات والمهاجرات وحد المعاملة ونطاق القياس والتغطية والقراء وتعافي الحفظ المشترك ضمنDATA-01؛ توقيت الدعوة ومكانها التفصيلي قرار تصميم لاحق. موافقة المفهوم ليست اجتياز هذه البوابات أو تصريح تنفيذ. لا طلب موافقة ثانية على نفس حرية الفترة واختيارية القدرات.

**سجل التحديث:** V1 تثبيت المفهوم والمسارين والارتباطات والتغطية المخططة بطلب المالك، دون ادعاء تحقق الكود أو جاهزية قاعدة البيانات.
