4. مصالحة السلطة والنسخ وخط الأساس دون تغيير المعنى المالي أو المنتج.

**ممنوع تنفيذ S02 أو أي مرحلة أخرى في هذه المهمة.**

- **Manus:** ينفذ S01 التوثيقية، وينشر الحزمة والوثائق والسجلات المسموح بها، ويسجل الوقائع والأدلة الفعلية.

في بيئة Manus الحالية، يتوفر وصول Google Workspace/Drive للقراءة عند الحاجة إلى التحقق من provenance فقط، دون تعديل صلاحيات المشاركة أو محتوى Drive. إذا تعذر الوصول في جلسة لاحقة، يسجل ذلك `UNVERIFIED` ولا يتعطل التنفيذ من GitHub. لا تفترض وجود مزامنة آلية.

سجل البرنامج في GitHub هو فهرس التقدم والأدلة والتسليم، مستند إلى Operations Control ونتائج الفحوص والمراجعتين. Drive مرآة متابعة للمالك. بعد تحقق ChatGPT من GitHub، يتولى تحديث مرآة Drive عند تكليفه بذلك، مع تسجيل آخر SHA مطابق وتاريخ المطابقة.

- ظهر PR أو فرع أو Claim متعارض.

لا تحذف الفرع أو PR. لا تعمل cleanup. لا تستخدم force-push.

### عقد التوقف والاستئناف

عند كل توقف، سواءً بسبب انتهاء الجلسة أو تغيير الحساب أو عائق، يجب تسجيل:

- آخر فعل مؤكد وما لم يكتمل.
- اسم الفرع، وbase SHA، وcandidate/head SHA الكامل.
- حالة العمل غير الملتزم (`git status --short`) وأسماء الملفات إن وجدت.
- الفحوص التي شُغلت، والرأس الذي شُغلت عليه، والنتائج والملاحظات المفتوحة.
- مآل أي كتابة مجهول قبل إعادة المحاولة.
- الفعل التالي الدقيق والمراجع اللازمة له.

عند الاستئناف، يبدأ المنفذ بقراءة سجل S01 وفحص الفرع وPR والـworktree والـcommits الحالية، ثم يحدد أول فعل غير مكتمل. لا يعيد إنشاء الفرع أو PR أو تنفيذ فعل مؤكد تلقائيًا، ولا يعمل reset أو reclone فوق عمل موجود. إذا اختلفت الحالة عن آخر checkpoint، يسجل `STATE_DRIFT` ويتوقف قبل الكتابة.

الرجوع المسموح هو:

- إصلاح commit توثيقي إضافي على نفس الفرع، أو
- revert موثق لآخر commit توثيقي إذا طلبت بوابة المراجعة ذلك.

لا يمس الرجوع تنفيذ UNIT-001 V3 المدموج ولا تقاريره ولا تاريخ Operations Control السابق.
