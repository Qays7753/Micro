# Micro — التبعيات وملكية البناء وتغطية المتطلبات

**النسخة:** V1 · **التاريخ:** 2026-10-27 — عمّان.
**الحالة:** خريطة التبعيات منشورة ضمن S01 للمراجعة؛ S01 وحدها تسلمت توثيقيًا، وS02–S18 ما زالت PLANNED_REVIEW.

## 1. معنى الروابط

BUILD: أصل يبنى مرة واحدة. ATOMIC: أطراف كتابة تتغير حقوقها أو كميتها أو تغطيتها داخل الحد نفسه. CONSUME: استهلاك عقد مقبول. ACCESS: بديل ووصول ورجوع قبل إزالة مدخل. TRANSFER: المهايئان والمهاجرة والتصدير والوارد مع التغيير. REGRESSION: اختبار اتساق دون اشتراط إعادة بناء الجيران.

لا يتحول الجوار كله إلى شرط بدء متبادل. الكاتب يملك الأصل، والقارئ ينقل أثره. مراحل تبني الهيكل ثم تستهلكه؛ لا مرحلتان تبنيان الوظيفة نفسها تحت اسمين.

## 6. حدود التحقق

التحقق وثائقي: 45 مكونًا لها مالك مرحلة، و427 معرّف ACD محفوظة، و38 معرّف DUP في المصادر، و72 حالة SDF مسندة، وتبعيات المراحل بلا دورة. هذا ليس نجاحًا لاختبارات المنتج. يراجع Manus قابلية التنفيذ وحجم الشرائح والمنافذ والحدود؛ لا يغير حالات الأدلة أو يضيف مخزنًا أو كاتبًا عامًا لكي يبدو الجدول مكتملًا.
