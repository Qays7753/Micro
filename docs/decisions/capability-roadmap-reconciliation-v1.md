# مصالحة خريطة القدرات: التنفيذ الحالي مقابل الأولويات المعتمدة

**الحالة:** معتمد ومُحدّث بعد تنفيذ G3 في فرع Agent 1 وقبل دمجه إلى Bridge/main
**التاريخ:** 26 أغسطس 2026
**المرجع المباشر:** خريطة النواة المالية والتشغيل والتوسع المرفقة من المؤسس.

## القرار

لا يوجد تعارض في **المبدأ المالي** بين الخريطة المرفقة وMicro المنفذ: الافتتاح والتصحيح يسبقان التقارير، الشراء لا يساوي تكلفة بيع، الاستهلاك هو مصدر فرق المادة، والبيانات الناقصة ليست صفرًا.

يوجد اختلاف يجب تصحيحه في **ترتيب الخطوات التالية وتسميتها**. فقد قفزت مسودة «المجموعة الثالثة» إلى وضع التشغيل والوقت قبل أن تكتمل السياسة المالية الأعمق التي وضعتها الخريطة كأولوية: المصاريف المشتركة، تعريف المنتجات/الخدمات، ربحية قابلة للتفسير، نقطة تعادل وسيولة قصيرة. لذلك لا يبدأ وضع التشغيل أو الوقت كـ«المجموعة الثالثة» المستقلة. يبقيان قدرات تمكينية لاحقة داخل تجربة القطاع المناسبة.

> قدرات التشغيل لا تعالج مكان نقص سياسة مالية. وهي تضيف قيمة فقط بعد أن يستطيع النظام تفسير ما يعرفه وما يستبعده في السؤال المالي المقصود.

## المطابقة الواقعية

| الخريطة المرفقة | الحالة الحقيقية في `main` | الحكم |
|---|---|---|
| الافتتاح ومحافظ الكاش والتصحيح | منفذ ومختبر: محافظ، افتتاح، تحويل، ضبط وعكس | متوافق ومكتمل في نطاق Prototype |
| تصنيف المصروف وسياقه | منفذ ومختبر: علاقة، طبيعة، سلوك، غرض ودرجة معرفة | متوافق ومكتمل في نطاق Prototype |
| المورد والشراء والدفعات | منفذ ومختبر: مورد وشراء ودفعة جزئية وذمة | متوافق؛ لا مرتجعات أو ضرائب أو خصومات |
| المخزون والاستهلاك والهدر | منفذ ومختبر: مادة ووحدة وافتتاح/استلام واستهلاك وهدر وضبط وعكس | متوافق؛ لا وصفات أو LOT أو MRP |
| نتيجة فترة أوسع ومصاريف مشتركة | G3 منفذ في فرع Agent 1: تحميل حصة ثابتة أو نسبة صريحة أو تقدير مالك، ومسار مؤجل غير محمل، وقراءة فترة مفصلة؛ schema 21/export 12 مع قبول 20/11 | **منفذ في PR، غير معلن على `main` قبل Bridge**؛ لا يسمى صافي ربح، ولا يثبت COGS فعليًا أو توزيعًا على طلب/منتج |
| ربحية المنتجات والتحليل | ربحية أولية حسب اسم العمل وفرق مادة للطلب؛ لا كتالوج اختياري أو تحليل أسباب كامل | **جزئي** |
| نقطة التعادل والسيولة | مؤشر تغطية محافظ وسيولة مسجلة؛ لا هامش مساهمة أو استحقاقات/تحصيلات قريبة | **جزئي** |
| شهر/تكرار/تنبيه وقدرة | يوم/أسبوع وتحذير قدرة فقط | مؤجل كما تقترح الخريطة |
| POS/مرتجعات | غير منفذ | مؤجل كما تقترح الخريطة |
| استيراد افتتاحي ونسخ محسنة | export/import محلي متحقق؛ لا معالج Excel افتتاحي | مؤجل كما تقترح الخريطة |
| PWA ومزامنة وصلاحيات | غير منفذ | مؤجل كما تقترح الخريطة |

## 3. الترتيب الموحد الملزم

1. **المجموعة الثالثة: سياسة نتيجة الفترة الأوسع** — منفذة في شريحة G3 الحالية وقيد PR إلى Bridge: أساس تحميل المصروفات المشتركة، مصدر الرقم ودرجة معرفته، والنسبة الصريحة أو التأجيل غير المحمل. لا تسمي الناتج صافي ربح إذا بقي عنصر مؤثر غير معروف؛ ولا تعتبر COGS الفعلية مكتملة خارج الدليل المسجل.
2. **المجموعة الرابعة: منتجات/خدمات وربحية وتحليل سبب** — كتالوج اختياري، أعمال/منتجات متشابهة، تفسير مادة ووقت وهدر عند توفر سجلها.
3. **المجموعة الخامسة: نقطة التعادل والسيولة القصيرة** — بعد وجود تكاليف ثابتة وهامش مساهمة وسياسة فترة وبيانات استحقاق كافية.
4. **المجموعة السادسة: تشغيل متدرج حسب طريقة العمل** — شهر وتكرار وقدرة ثم POS أو مصدر الاتفاق أو الاستيراد الافتتاحي حسب Pilot القطاع.
5. **المجموعة السابعة: PWA والنسخ والمزامنة والهوية** — بعد اختبار الاستعادة والتضارب والحاجة إلى أكثر من جهاز أو مستخدم.

## موضع وضع التشغيل والوقت الفعلي

لا يُلغى القرار السابق عن الاختيارية ودرجة المعرفة. بل يعاد توظيفه كقاعدة واجهة داخل كل مجموعة:

| العنصر | القرار بعد المصالحة |
|---|---|
| وضع التشغيل | طبقة إعداد تمكينية صغيرة، لا مجموعة تنافس السياسة المالية؛ لا يبدأ قبل تثبيت سؤال المجموعة الثالثة. |
| الوقت الفعلي | قدرة تدخل في تحليل الربحية للمنتج/الخدمة عند كون العمل محور التكلفة؛ ليست مدخلًا إجباريًا لكل مشروع. |
| فرق المادة | يبقى قراءة منفذة للطلب؛ يستعمل لاحقًا كأحد أسباب الربحية ولا يتحول وحده إلى COGS أو نتيجة كاملة. |
| الهدر المرتبط بطلب | يؤجل حتى يحتاج التحليل إلى عزوه صراحة ويثبت Pilot أن المستخدم يسجله بانتظام. |

## الحواجز غير القابلة للتفاوض

لا يبدأ تقويم شهر أو POS أو PWA أو مزامنة أو توصية تسعير قبل أن تظل القواعد التالية محفوظة: القبض ليس ربحًا، الشراء ليس تكلفة بيع، الدين ليس كاشًا، السحب ليس مصروفًا، والبيانات الناقصة ليست صفرًا.
