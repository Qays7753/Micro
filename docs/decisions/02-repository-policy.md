# سياسة مستودع Micro والملكية

**الحالة:** قرار تشغيلي مؤقت قبل الإطلاق التجاري

## القرار

يُستخدم مستودع Micro حاليًا لتطوير منتج SaaS تجاري مملوك لصاحب المشروع. لا نضيف ترخيص Open Source للكود أو الوثائق تلقائيًا، ولا نعتبر كون المستودع عامًا إذنًا بنسخ الكود أو إعادة توزيعه.

يجب تحديد سياسة نهائية قبل نشر كود المنتج أو قبول مساهمات خارجية. يمكن أن تكون الوثائق العامة والكود التجاري تحت سياسات مختلفة، لكن لا نخلطهما دون قرار مكتوب.

## لماذا لا نضيف ترخيصًا الآن؟

اختيار MIT أو GPL أو Apache أو شروط خاصة ليس قرار تنسيق؛ فهو يغير حقوق الاستخدام والتوزيع والاشتقاق. لذلك نؤجل الترخيص الملزم إلى مراجعة المالك ومختص قانوني عند الحاجة، مع إبقاء بوابة واضحة تمنع إدخال كود خارجي بلا provenance وترخيص معلوم.

هذه وثيقة قرار تشغيلية وليست استشارة قانونية. قبل الاعتماد التجاري أو توزيع الكود، يجب مراجعة مختص مؤهل.

## قواعد المرحلة الحالية

لا يُرفع إلى المستودع أي سر أو بيانات مستخدم حقيقية أو كود مأخوذ من مشاريع GitHub. تُذكر المشاريع الخارجية كمراجع فقط في `docs/06-reference-library.md` و`THIRD_PARTY_NOTICES.md`. لا تُفتح مساهمات عامة قبل تحديد شروط الملكية والمراجعة.

## شروط تغيير القرار

يُعاد فتح القرار عند أول استخدام لكود المنتج خارج فريق المالك، أو عند نشر نسخة قابلة للتنزيل، أو عند فتح Pull Requests عامة، أو عند توزيع SDK أو مكتبة. يسجل التغيير في `docs/02-decision-log.md` ويُراجع أثره على README وCONTRIBUTING وTHIRD_PARTY_NOTICES.
