## 3. D-14 — عقود التركيز الكاملة للمودالين الحقيقيين (الالتزام `e2bcc752`)

- **المساعد المشترك** `components/security/overlayFocusContract.ts`: ستار (صنف CSS القائم — صفر تغيير بصري) + focus-in عند الفتح + احتواء Tab/Shift+Tab بالالتفاف الأول/الأخير (ترتيب DOM فيبقى ترتيب Tab في RTL كما هو) + Escape بمسار الإغلاق الآمن (مع إيقاف الانتشار) + استعادة التركيز لمُشغّل الفتح عند الإغلاق.
- **DataActionPinGate**: autoFocus استُبدل بـfocus-in المملوك للمساعد؛ Escape = إلغاء؛ منطق الرمز لم يتغير بايتًا.
- **Settings protectionBlocked**: استُخرج غطاء الحجب إلى مكوّن مالك `ProtectionBlockedOverlay` يُركّب مع الغطاء (الحقيقة الهندسية المكتشفة: hook على مستوى الأب لا يعمل أبدًا لأن المرجع فارغ عند التركيب — الاستخراج هو الشكل الصحيح الوحيد)؛ focus-in على «حسنًا»؛ Escape = حسنًا.
- **7 اختبارات jsdom عبر صفحة الإعدادات الحقيقية**: focus-in للموضعين؛ دورة الالتفاف كاملة (مع استبعاد زر الإكمال المعطّل والرمز ناقص — عقد التحديد)؛ Escape + الاستعادة للمشغلين؛ سحب التركيز الخارجي إلى الداخل؛ تدفق الرمز الصحيح كما كان.
- **الأثر المقيس**: المدخل 630,783/154,984 تحت السقفين الصامدين؛ lazy +1,168 خام/+449 gzipNorm وprecache +1,099 — إرساء أسطح موثق بالبروتوكول المعتمد على الرأس الكودي `a76afabb` (ocRef WS-219) + ثلاثة مداخل راتشة حجم.
