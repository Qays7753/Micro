## 0. بطاقة الفهم

**سؤال القرار:** خدمة التشخيص المحلية كانت تحصل على `localStorage` المتصفح داخل ملف الخدمة نفسه (R11-W1A-NF-001) — كيف يُقفل هذا الصنف كله بحد جذري مسجل لا بترقيع موضعي؟
**النطاق:** مهايئ تشخيص المتصفح في حد تخزين صريح + حارس مخصص فاشل-المغلق مسجل-البنود داخل `pnpm guards` + اختباراته الخصومية + اختبارات المهايئ + توثيق الحدود (security-boundaries + touchpoints + الفهرس).
**خارج النطاق:** مهايئ المسودات التراثية `legacyFormDraftMigration.ts` (إيجاد جديد مستقل R11-ARCH010-NF-001 — قرار مالك معلق؛ عقد المتابعة §7 «لا نقل ملفات غير مترابطة»)؛ أي تغيير لسلوك التشخيص القائم؛ أي مساس بـ`storage/local/` أو عقد 130-طريقة أو Schema 38/Export 30/Legacy/Transfer/مالي/تاريخي.
**حد الاستعادة:** عكس التزامات هذه المرحلة يعيد الشكل السابق بلا أي ترحيلة بيانات (نفس المفتاح `micro.diagnostics.v1` ونفس عقد الحقول والفشل)؛ الحارس واختباراته قائمة بذاتها.

## 3. الحارس المخصص (فاشل-المغلق، مسجل-البنود)

- **النطاق:** كل ملفات الإنتاج تحت `client/src` (369 ملفًا عند القياس) — لا طبقة مستثناة.
- **الكشف (AST بمحلل TypeScript نفسه — التعليقات ليست عقدًا فلا تُحتسب):** المرجع المجرد (`sessionStorage.getItem`)؛ الوصول الخاص بجذر window/globalThis/self/global (مع `?.`)؛ الوصول المحسوب الحرفي (`globalThis["localStorage"]`)؛ تفكيك الكائن (`const {localStorage: ls} = globalThis` والمختصر)؛ تصريح الاسم المستعار (`const ls = localStorage`)؛ مفتاح الكائن الحرفي بالاسم؛ ربط الاستيراد/التصدير بالاسمين.
- **الموضعان المسجلان حرفيًا (registered-entry — لا قائمة عامة):** مهايئ التشخيص (الحد الجذري) والاستثناء التراثي الموثق `legacyFormDraftMigration.ts` (R11-ARCH010-NF-001 بشرط إزالة موثق: قرار المالك بترحيله). موضع مسجل غادر الشجرة = فشل (تسجيل متقادم).
- **حدود موثقة:** الوصول المحسوب بدمج نصي (`globalThis["local"+"Storage"]`) خارج الكشف الحرفي — نفس حد كل حراس AST في المستودع؛ `indexedDB` ليس نطاق هذا الحارس (له بنية مسجلة وحراسها).
- **التوصيل:** داخل سلسلة `pnpm guards` (الحارس رقم 23) المتصلة بـ`pnpm check` وبالتالي بـCI.
