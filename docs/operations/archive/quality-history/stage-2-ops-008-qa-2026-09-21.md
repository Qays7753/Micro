# سجل QA — Stage 2 / الموجة 5 (OPS-008 — صدق مقارنة الوقت)

**التاريخ:** 2026-09-21 · **PR:** #201 · **الفرع:** `stage-2/completion-remaining` · **خط الأساس:** `8986385`

## 1. قرار الواجهة (بروتوكول التسليم §5.4)
قرار واحد: استبدال سطر السبب المصنوع «الفرق كبير — راجعه قبل الاعتماد عليه.» بسطر السبب الصادق من مصدره «سبب المراجعة: الوقت المخطط في لقطة التكلفة تقديري أو غير معروف بالكامل.» — تبديل نصي محايد الكثافة داخل بنية البطاقة القائمة (لا عناصر/رموز/CSS/مسارات جديدة).

## 2. مصفوفة الحالات المختبرة (آليًا)
| المسار | الحالة | الاختبار | النتيجة |
|---|---|---|---|
| not_recorded (مخطط معروف/غائب) | «غير مسجل» لا صفر؛ «غير متاح» للمخطط الغائب والفرق | DOM | PASS |
| recorded | القيم والفرق وسطر «للقراءة فقط ولا يغيّر النتيجة المالية» | DOM | PASS |
| needs_review (تقديري) | السبب الصادق من مصدر الوقت — لا «الفرق كبير» | DOM | PASS |
| needs_review (صفري/غائب) | «غير متاح» لا «0 دقيقة» واثقة | خدمة + DOM | PASS |
| فعلي < مخطط | فرق سالب صادق | خدمة | PASS |
| مواد تقديرية + وقت معروف | recorded (المعرفة من مصدر الوقت) | خدمة | PASS |
| أي قراءة | لا كتابة (مطابقة لقطة المخزن الكاملة) | خدمة | PASS |
| عكس موثق | الأصل ظاهر مع السبب والتاريخ | DOM | PASS |

## 3. QA الحي / الجهاز
`NOT_EXECUTED` — لا متصفح حي في البيئة؛ تبديل نصي داخل بنية قائمة RTL/وصولها من بنية البطاقة الأم.
