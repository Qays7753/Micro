# G8.3 — QA الاستيراد الافتتاحي الموجّه

## ما تم فحصه

أضيف مسار إعدادات عربي RTL وهاتفي يختار ملف JSON افتتاحيًا، يعرض معاينة قبل الكتابة، ثم يؤكد إدخالًا ذريًا على Store فارغ. يمر المسار عبر `GuidedOpeningImportService` ثم `PrototypeLocalStore`، ولا تصل React إلى IndexedDB مباشرة.

| السيناريو | النتيجة |
|---|---|
| ملف صحيح بمحفظة ومادة | preview ناجح، ثم profile ومحفظة وحركة افتتاح ومادة وحركة مخزون |
| ملف ناقص/تالف/نسخة غير مدعومة | رفض عربي قبل الكتابة، وبقاء الحالة الحالية |
| Store غير فارغ | رفض `non_empty_store` بلا overwrite أو merge |
| إعادة المحاولة | مفاتيح deterministic وإعادة نتيجة سابقة دون تكرار الأثر |
| قيمة تقديرية | تظهر في الملخص كتقديرية ولا تتحول إلى نتيجة أو ربح |
| فشل الحفظ | يعرض فشلًا صريحًا ولا يعلن نجاح الاستيراد |

## حدود القبول

اجتاز `pnpm --filter @micro/prototype-web test -- client/src/application/transfers/guidedOpeningImportService.test.ts` و`pnpm check` محليًا. لم يُنفذ اختبار جهاز فعلي أو Cloudflare Pages لهذا المسار. لم تتغير إصدارات schema/export؛ الاستيراد الافتتاحي له `format` و`version` مستقلان.

## ما لم يدخل

لا استيراد Excel/CSV، ولا تاريخ مبيعات، ولا ذمم أو التزامات سابقة، ولا تحويل كاش إلى ربح، ولا sync أو Auth أو CRM. الاستيراد لا يعيد كتابة طلب أو Snapshot أو حدث قائم.
