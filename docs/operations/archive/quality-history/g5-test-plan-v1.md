# خطة اختبار G5 — هامش المساهمة، نقطة التعادل، والسيولة القصيرة

هذه الخطة تسبق التنفيذ وتحوّل عقد [`17-contribution-break-even-short-cash-g5-contract.md`](../contracts/17-contribution-break-even-short-cash-g5-contract.md) إلى حالات قابلة للاختبار. لا تستخدم بيانات حقيقية، ولا تعتبر نجاح الاختبارات التقنية دليل تبنٍّ أو استعداد للدفع.

## بطاقة الفهم والقبول

| الحقل | قرار G5 |
|---|---|
| المستخدم والموقف | صاحب مشروع صغير يراجع فترة، يريد تغطية تكاليفها، أو يريد فهم كاشه مع تحصيلات والتزامات قريبة أعلنها بنفسه. |
| سؤال القرار | كم يلزم من هامش مساهمة مسجل وبافتراضات معلنة لتغطية الفترة، وهل التوقع القصير المبني على الكاش والإعلانات يكفي؟ |
| أقل إدخال | فترة، طلبات نهائية ذات كمية وإيراد وتكلفة مباشرة، مصروفات مصنفة، وكاش مسجل؛ وللتوقع: اتجاه، مبلغ، تاريخ، مصدر، ودرجة معرفة. |
| ما يبقى مجهولًا | COGS فعلي، ضرائب، إهلاك، أجر، توزيع مختلط، موعد دين غير معلن، ووعد التحصيل أو الدفع. |
| ما لن يتغير | لا تعديل Snapshot أو حدث أو كاش أو ذمة؛ لا تحويل الدين إلى كاش؛ لا توصية شراء/سحب/اقتراض/تسعير. |
| السيناريو الكاشف | هامش صفر/سالب، مصروف mixed بلا أساس، طلب نهائي ناقص، وكاش 100 مع تحصيل معلن 80 والتزام معلن 140، وذمة إضافية بلا تاريخ. |
| شرط الإيقاف | تعارض مع P0 أو G3، حاجة إلى سياسة ضريبة/قرض/أجر/COGS، أو فقد تاريخ/عكس غير آمن. |

## مصفوفة الاختبارات

| ID | الطبقة | المدخل | المتوقع | ما يظل مجهولًا أو الحاجز |
|---|---|---|---|---|
| G5-D01 | Domain | طلبان نهائيان بكمية موجبة ومصروف ثابت معروف | هامش الفترة يساوي الإيراد ناقص التكلفة، والتكلفة الثابتة منفصلة، ونقطة التعادل تحسب بـ`ceil(fixed / marginPerUnit)` | ليست نتيجة صافي ربح نهائي |
| G5-D02 | Domain | هامش مساهمة صفري | `status: invalid` و`breakEvenUnits: null` | لا يعرض `0` ولا يقترح بيعًا |
| G5-D03 | Domain | هامش مساهمة سالب | `status: invalid` وسبب مراجعة السعر/التكلفة | لا ينشئ نقطة تعادل سالبة |
| G5-D04 | Domain | طلب نهائي بنتيجة `estimated` أو `incomplete` داخل الفترة | الطلب مستبعد من الهامش، وعدّاد الاستبعاد ظاهر، والنتيجة `incomplete` | لا يتحول النقص إلى صفر معرفي |
| G5-D05 | Domain | مصروف `fixed` معروف وحصة مشتركة بأساس معلن | يدخل الثابت مرة واحدة في الفترة؛ لا يدخل هامش اسم العمل | لا يوزع على طلب أو منتج |
| G5-D06 | Domain | مصروف `mixed` أو `unknown` بلا ربط مباشر | لا يوزع، ونقطة التعادل `incomplete` بلا رقم | لا تفترض نسبة ثابتة/متغيرة |
| G5-D07 | Domain | ثابت مقدّر أو حصة مشتركة مقدّرة مع بقية البيانات مكتملة | `needs_review`، والرقم موجود مع الافتراض والمصدر | لا يسمى الرقم نهائيًا |
| G5-D08 | Domain | مزيج مسجل من طلبات نهائية بأسماء مختلفة | المزيج يعرض العدد/الكمية/المصدر كما سجل، دون توقع منتج جديد | لا يساوي اسم العمل كتالوجًا |
| G5-D09 | Domain | إعلان تحصيل معروف: مبلغ وتاريخ ومصدر وارتباط اختياري | سجل إعلان مستقل لا يغير الكاش أو الذمة؛ يقرأه التوقع داخل الأفق | الإعلان ليس قبضًا فعليًا |
| G5-D10 | Domain | إعلان التزام معروف داخل الأفق | يطرح من التوقع فقط، ولا ينشئ مصروفًا أو التزامًا جديدًا | المصدر والتاريخ لازمان |
| G5-D11 | Domain | إعلان `estimated` أو `needs_review` صالح | يدخل التوقع مع `needs_review` ومصدر ظاهر | لا يخفي درجة المعرفة |
| G5-D12 | Domain | دين/التزام مؤثر بلا تاريخ أو إعلان مطابق | `incomplete` و`projectedCashMinor: null` مع فعل تسجيل الموعد | لا يُعامل المجهول صفرًا |
| G5-D13 | Domain | إعلان بمبلغ غير موجب أو تاريخ غير صالح أو مصدر فارغ | `invalid` أو رفض حفظ واضح | لا يكتب سجلًا مشوهًا |
| G5-D14 | Application | إعادة حفظ الإعلان بنفس `idempotencyKey` ونوع العملية | يعيد السجل نفسه مع `reused: true` ولا يكرر الأثر | لا توجد حركة مالية أصلًا |
| G5-D15 | Application | عكس إعلان فعال بمبلغ واتجاه مطابقين | ينشئ سجل عكس مرتبطًا؛ القراءة تستبعد الأثر المعكوس، والأصل محفوظ | لا حذف ولا تعديل صامت |
| G5-D16 | Application | عكس غير موجود أو عكس مرتين أو اتجاه/مبلغ مختلف | خطأ تحقق مفهوم ولا تتغير الحالة | لا تسوية خفية |
| G5-A01 | Application | مصروفات تشغيل/استثمار/سحب/تسديد التزام مع طلبات | G5 لا تدخل الاستثمار والسحب والتسديد في الهامش، ولا تغيّرها | القبض ليس ربحًا والسحب ليس مصروفًا |
| G5-A02 | Application | حركة مخزون أو تغيير سعر بعد Snapshot | قراءة G5 لا تعدل الحركة أو Snapshot أو النتيجة التاريخية | لا COGS فعلي |
| G5-S01 | Storage | export/import v10/schema19 يحوي إعلانات | round-trip يحفظ المعرفات والحالات والروابط والدرجات | لا ازدواج إعلان |
| G5-S02 | Storage | import v9/schema18 بلا إعلانات | يهاجر إلى مصفوفة إعلانات فارغة دون تخمين مواعيد | الحالة القديمة لا تتغير |
| G5-S03 | Storage | ملف ناقص/تالف/إصدار غير مدعوم | يفشل قبل الكتابة ويحافظ على الحالة الحالية | لا مسح للحالة |
| G5-S04 | Storage | إعادة تحميل IndexedDB | تبقى الإعلانات الفعالة والمعكوسة والحالات كما هي | لا اعتماد على ذاكرة الصفحة |
| G5-U01 | UI | RTL، Light/Dark، عرض 360/390/430px | قراءة سؤال واحد، أرقام ASCII/LTR، فصل المسجل عن المفترض، وحالات نصية لا تعتمد على اللون | لا Dashboard عام مزدحم |
| G5-U02 | UI | فترة فارغة أو بلا طلبات نهائية | Empty صريح مع سبب، دون `0` مضلل كنقطة تعادل | لا يساوي غياب البيانات أمانًا |
| G5-U03 | UI | نقطة تعادل متاحة/ناقصة/غير صالحة | يعرض الفترة والمصدر والمزيج والافتراض والفعل التالي؛ ويحجب الرقم في `incomplete/invalid` | لا «نقطة تعادل نهائية» |
| G5-U04 | UI | كاش 100، تحصيل 80، التزام 140، وذمة بلا تاريخ | يفصل الكاش والتحصيل والالتزام والذمة؛ لا يعرض 40 أو 180 ككاش حالي | لا وعد بتحصيل الدين |
| G5-U05 | UI | reload وexport/import ثم فتح صفحة Finance | لا تغيير في الكاش/الذمة/Snapshot بسبب القراءة، وتظهر الإعلانات نفسها | لا أثر مالي مخفي |

## التحقق الآلي المطلوب

يجب أن توجد اختبارات pure لـDomain للحسابات والحالات، واختبارات Application للتدفق من القراءة إلى الحفظ والعكس وإعادة المحاولة، واختبارات LocalStore للترحيل وround-trip، ثم فحص حي لسطح الهاتف. لا تُقبل نقطة التعادل إذا كان الهامش غير موجب أو البيانات المؤثرة ناقصة، ولا تُقبل السيولة كتوقع إذا غاب تاريخ أو مصدر مؤثر.
