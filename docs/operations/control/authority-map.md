# خريطة السلطة ومنع الازدواج

| نوع المعلومة | المصدر الحاكم | ما لا يجوز فعله |
|---|---|---|
| تعريف المنتج وحدوده | وثائق المنتج والعقود والقرارات | إعادة تعريفه داخل Tracker |
| قواعد المال والتخزين | العقود + الكود + الاختبارات | اعتبار وصف Issue عقدًا |
| حقيقة الدمج الحالية | `main` + CI + `current-state.md` | إعلان الاكتمال من فرع أو محادثة |
| تنسيق التنفيذ | `control/items` و`control/workstreams` | إنشاء Tracker موازٍ |
| Expansion E-00 | `docs/expansion/TRACKER.md` | نسخ بنوده إلى سجل مستقل متضارب |
| التقارير والأدلة | `reports/` والروابط المفهرسة | تعديل تقرير تاريخي لإظهار واقع جديد |

## ترتيب حل التعارض

1. حقيقة الكود والاختبارات على `main`.
2. العقد أو القرار الحاكم للسلوك.
3. `current-state.md` لحالة البرنامج المندمجة.
4. السجل المنظم لتنسيق العمل.
5. Views المولدة، ثم وصف PR، ثم المحادثة.

أي اختلاف بين المستويات 1–4 يُسجّل كبند `REOPENED` أو `REVIEW_REQUIRED` مع الدليل، ولا يُحل بالافتراض.
