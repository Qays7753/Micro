# حدود النطاق قبل الـPilot

## الحدود الحالية

- منتج Local-first لمالك واحد، يعمل دون Cloud أو مزامنة أو فرق.
- المجهول لا يعرض صفرًا معروفًا.
- التاريخ `16/09/2026`، والتاريخ مع الوقت `16/09/2026، 03:30 م`، والعرض بتوقيت الجهاز مع تخزين داخلي موحد.
- إيقاف قدرة يمنع مداخل الإنشاء ويحافظ على قراءة التاريخ السابق.
- السوق والتوصيل نطاق مستقبلي بحالة صادقة، وليس قدرة عاملة.
- Pilot مؤجل بقرار المالك حتى إغلاق بوابات المنتج والجهاز والقبول المستقل.

## مستقبل بعد دليل وقرار

- مزامنة وتعدد مستخدمين وصلاحيات.
- نسخ سحابي واستعادة عبر أجهزة.
- فواتير أو ضرائب رسمية بعد مراجعة أردنية متخصصة.
- دفع وتجارة إلكترونية وتكاملات خارجية.

## لا يُبنى ضمن النطاق الحالي

- ERP أو POS أو CRM شامل.
- دفتر مزدوج ظاهر للمستخدم أو تعقيد محاسبي لا يخدم قراره.
- توسع آلي في التنبؤ أو AI بلا بيانات ودليل.
- قدرة سوق أو توصيل فعلية قبل بوابتها المستقلة.
