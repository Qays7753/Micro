# حدود النطاق قبل الـPilot

## تعريف المنتج الكامل في هذه المرحلة

«نسخة Micro متكاملة وظيفيًا وآمنة للاستخدام الفعلي ضمن نطاق مستخدم واحد، جهاز واحد، Local-first، لإدارة مشروع منزلي أو متناهي الصغر أو شركة صغيرة جدًا.»

هذا التعريف يعني أن الرحلات الأساسية داخل النطاق يجب أن تكون مكتملة ومقروءة، وأن كل رقم يملك مصدر حقيقة واحدًا، وكل Writer حساس محمي من التكرار والتعارض وله عكس/تصحيح مناسب، وكل قدرة جديدة تدخل التصدير والاستعادة إذا أصبحت جزءًا من البيانات الدائمة. لا يعني هذا تحويل Micro إلى نظام محاسبة ثقيل أو منصة متعددة المستخدمين.

## الحدود الحالية غير القابلة للخلط

- منتج Local-first لمالك واحد وجهاز واحد، دون Cloud أو مزامنة أو فرق.
- المجهول لا يعرض صفرًا معروفًا.
- التاريخ `16/09/2026`، والتاريخ مع الوقت `16/09/2026، 03:30 م`، والعرض بتوقيت الجهاز مع تخزين داخلي موحد.
- إيقاف قدرة يمنع مداخل الإنشاء ويحافظ على قراءة التاريخ السابق.
- السوق والتوصيل الخارجي نطاق مستقبلي بحالة صادقة، وليس قدرة عاملة ضمن Pilot.
- Pilot مؤجل حتى إغلاق بوابات المنتج والجهاز والقبول المستقل وقرار المالك.

## لا يُبنى ضمن النطاق قبل الـPilot

| خارج النطاق | سبب عدم اعتباره نقصًا في المنتج المحلي |
|---|---|
| الحسابات وتعدد المستخدمين والصلاحيات | بوابة MVP تجاري لاحقة وليست شرطًا لمنتج المالك الواحد |
| Cloud Sync والنسخ السحابي التلقائي | خارج Local-first ويتطلب قرارًا أمنيًا وتشغيليًا مستقلًا |
| السوق والتوصيل الخارجي وتكامل الدفع والمتاجر الإلكترونية | Expansion/Future Scope يحتاج عقدًا وPilot مستقلًا |
| POS كامل أو CRM | يوسّع هوية المنتج خارج إدارة مشروع المالك |
| محاسبة القيد المزدوج الظاهرة | ليست سؤال القرار الأساسي للمستخدم الحالي |
| الفواتير الضريبية الرسمية | تحتاج مراجعة أردنية متخصصة واعتمادًا قانونيًا قبل أي ادعاء |
| AI أو تنبؤات موسعة بلا بيانات ودليل | لا تتحول فرضية إلى قدرة قبل قياس الحاجة |

## تعريف الجاهزية

القدرة الجزئية أو الوعد غير المدعوم لا تُخفى؛ تسجل في Item بحالة وتصنيف ومصدر ومالك ومعايير قبول. `FIX_BEFORE_PILOT` يعني أنه لا يجوز إعلان الجاهزية قبل الإغلاق. `BUILD_AFTER_EVIDENCE` و`FUTURE_SCOPE` و`PILOT_VALIDATION` لا تمنح إذن تنفيذ. التفاصيل التشغيلية في `context.md` و`roadmap.md`، بينما معنى المال والسلوك تحكمه العقود والكود والاختبارات.
