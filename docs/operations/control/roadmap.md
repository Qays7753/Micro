# خارطة ما قبل الـPilot

| الترتيب | المرحلة | شرط الخروج |
|---:|---|---|
| 0 | مصالحة السجل والتقارير | لا بند مفقود أو مكرر، وكل حالة لها دليل |
| 1 | إغلاق إصلاحات الجودة المتبقية | P0/P1/P2 = صفر، وP3 مقبول أو مؤجل بقرار |
| 2 | اكتمال التشغيل اليومي | المواعيد، المخزون، التكرار، والقوالب تخدم رحلة حقيقية |
| 3 | اكتمال الإدارة المالية | تمويل، ميزانيات، مقارنة، سحب آمن، توقع، ربحية، ومراجعة فترة |
| 4 | تنظيف الحدود والأسطح | لا Surface ميت أو مسار جزئي أو وعد بلا قدرة |
| 5 | إعادة تصميم UI/UX الجذرية | نظام تصميم ورحلات وهوية واختبارات وصول بلا تغيير الحقيقة المالية |
| 6 | الصمود والجهاز | فشل التخزين/التصدير/التحميل + Android/iOS/WebKit/PWA فعلي |
| 7 | المراجعة الأردنية والقبول | مراجعة مختص + UAT ببيانات Demo + تدقيق مستقل |
| 8 | قرار Pilot | لا يبدأ آليًا؛ قرار مالك موثق بعد تحقق جميع البوابات |

تفاصيل التنفيذ تعيش في `items/`. هذه الخارطة ترتيب اعتماديات وليست إذنًا تلقائيًا ببناء كل بند.
