## R2-MF-03 — قرارات تباعد صلاحية التاريخ (SEMANTIC_CHANGE_MANIFEST — بوابة مالك)

- **التصنيف:** `PROTECTED_DECISION_PACKAGE` (لا تنفيذ — العقد: «توحيد date-validity بعد مقارنة الحدود» والحد المحمي يمنع أي تغيير رفض/قبول بدون قرار).
- **المانيفست (قبل ← بعد المقترح، المستهلكون، القرار المطلوب):**
  - **R2-D1 (سنوات 0000–0099):** النواة ترفض / صنف B وصنف C **كلاهما يقبلان**. مستهلكو القبول الحالي: مدققو النقل الـ~18 (صنف B) **+ مواضع صنف C كلها بما فيها `recurring-margin/policies.ts:22` داخل المجال نفسه** (recurrenceService:61، recurringWorkService:148، ownerEntitlementService:185، agreementService:64). التوحيد على الرفض يغيّر قبول ملفات استيراد وتواريخ مجالية متكررة؛ التوحيد على القبول يغيّر رفض النواة. **قرار مالك مطلوب؛ لا توحيد صامت.**

## R2-MF-04 — تصنيف رسائل المال وحماية النصوص المحفوظة

- **التصنيف:** `MESSAGE_CLASSIFICATION` (توثيق + تثبيت توصيفي).
