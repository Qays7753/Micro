## قواعد التفسير

`VERIFIED` لا يستخدم إلا مع Merge SHA وSHA تحقق على `main` ودليل قابل للوصول. البنود التي تحيل إلى تقرير خارجي لا تعتبر منفذة بسبب التقرير وحده؛ التقرير يثبت Finding أو سؤال تحقق، وتبقى الحالة في السجل الجديد حتى دليل `main` أو قرار المالك. التوسعات المستقبلية مثل POS وCRM وAuth وCloud وSync ليست مهام `READY` ولا تدخل نطاق الإصلاح الحالي.

إذا سبق الكود السجل، يصنف الفرق `CODE_AHEAD_OF_TRACKER` ويُثبت فقط بعد مراجعة الـSHA. إذا خالف التقرير التاريخي رأس `main`، يصنف `REPORT_HISTORICAL`. وإذا تعارض عقد مالي أو تعريف عد مع خطة، يسجل `OWNER_DECISION_REQUIRED` ولا يحسمه Agent منفردًا.
