# قالب شريحة Micro — بدء، PR، وتسليم

> ينسخ الوكيل هذا القالب إلى وصف PR أو Issue الخاص بالشريحة. لا ينشئ وثيقة دائمة جديدة لمجرد ملء القالب.

## بطاقة الاستلام

| الحقل | المحتوى |
|---|---|
| المرجع في `main` | `<commit>` |
| سؤال المستخدم/القرار | `<سؤال واحد قابل للتحقق>` |
| العقد الحاكم | `<path>` |
| النطاق الصغير | `<ما سيتغير>` |
| خارج النطاق | `<ما لن يتغير>` |
| التخزين/الترحيل | `<لا شيء أو schema/export/migration>` |
| معيار القبول | `<اختبارات + QA مطلوب>` |
| شرط الإيقاف | `<تعارض أو Pilot أو قرار مالك>` |

## وصف PR

### ما تغير

اكتب أثرًا وظيفيًا واحدًا أو اثنين، لا قائمة ملفات مجردة.

### ما لم يتغير عمدًا

اذكر صراحة حدود المال، التاريخ، التخزين، والقدرات التي بقيت مؤجلة.

| QA حي إن لزم | `<ما اختبر وما نُظف>` |
| CI | `<pass/fail>` |

### تسليم الوكيل التالي

- حدّث `docs/operations/current-state.md` بمستوى الحقيقة الجديد.
- حدّث `todo.md` للبنود المندمجة فقط.
- اذكر العقد أو البوابة التالية؛ لا تفتحها تلقائيًا.
