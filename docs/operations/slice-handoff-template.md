> ينسخ الوكيل هذا القالب إلى وصف PR أو Issue الخاص بالشريحة. لا ينشئ وثيقة دائمة جديدة لمجرد ملء القالب.

## وصف PR

### ما تغير

اكتب أثرًا وظيفيًا واحدًا أو اثنين، لا قائمة ملفات مجردة.

### ما لم يتغير عمدًا

اذكر صراحة حدود المال، التاريخ، التخزين، والقدرات التي بقيت مؤجلة.

### الملفات والتأثير (المجموعة ٦ — قالب PR الموحد)

- **الملفات/الوحدات المتغيرة:** قائمة صريحة.
- **أثر المخطط/التصدير/الاستيراد/الترحيل:** لا شيء، أو التغيير وسببه (`localSchemaVersion`/`localExportVersion` كما هما أو بقرار مالك).
- **أثر الثبات التاريخي والعكس (snapshots/reversals):** الوصف، أو «لا ينطبق — السبب».
- **أثر التزامن/الحتمية/إعادة المحاولة (sensitive writes):** الوصف ومفتاح الحتمية، أو «لا ينطبق — السبب».
- **أثر الواجهة (RTL/الوصول/الوضعين):** الوصف، أو «لا ينطبق — السبب».
- **الـinvariants المعنية وحالات الفشل:** القواعد التي لا تُكسر وأهم حالات الفشل المتوقعة.

### الاختبارات

- **النجاح:** ملف/أسماء.
- **الفشل (خطأ صادق):** ملف/أسماء، أو «لا ينطبق — السبب».
- **الترحيل/التوافق (released pairs/envelopes):** ملف/أسماء، أو «لا ينطبق — السبب».
- **التزامن/إعادة المحاولة (إن لمس الكود كتابة حساسة):** ملف/أسماء، أو «لا ينطبق — السبب».

### حد الاستعادة والمؤجل

- **حد الاستعادة (rollback boundary):** آخر التزام آمن للعودة إليه وأثر الرجوع.
- **المؤجل/القيود المعروفة:** بنود صريحة، أو «لا يوجد».
- **قرار المالك مطلوب؟** لا، أو نعم + السؤال الدقيق.

### تسليم الوكيل التالي

- حدّث `docs/operations/current-state.md` بمستوى الحقيقة الجديد.
- حدّث `todo.md` للبنود المندمجة فقط.
- اذكر العقد أو البوابة التالية؛ لا تفتحها تلقائيًا. بعد إغلاق برنامج التحصين الكامل (المجموعات ١–٦): البوابة التالية هي **المسح الهيكلي للقراءة فقط** بموجب `AGENTS.md` §11 — لا إعادة هيكلة أو نقل ملفات قبل قرار المالك على مكتشفات المسح.
