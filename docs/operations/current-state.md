# حالة Micro التشغيلية الحية

**الحالة:** `CURRENT / UPDATE WITH EVERY MERGED SLICE`
**آخر تحديث:** 2 أكتوبر 2026 (تنفيذ تنظيف السطح التوثيقي جارٍ وفق تدقيق 2026-10-01: PR #286/WS-206 مدموج — 12 تصحيح صدق و23 أرشفة؛ WS-207 (موجة C التوثيقية) قيد المراجعة؛ المخطط/التصدير 38/30 كما هما)
**التاريخ:** كل سجل الشرائح والموجات المؤرخ (§9–§93 وفقرات المتابعة قبل 2026-10-01) في [`current-state-log.md`](current-state-log.md) — append-only ولا يُحمَّل مع هذا الملف.

**قاعدة العمل:** العربية، RTL، phone-first، والأرقام المالية ASCII/LTR.

> هذا الملف يجيب عن سؤال واحد: **«إذا فتحت المستودع الآن، ما الذي أستطيع قوله أو تغييره بأمان؟»** لا يحل محل العقود أو فحوص Git. قبل أي عمل نفّذ `git fetch origin --prune` وتحقق من رأس `main` الحي؛ لا يُعامل أي SHA مذكور هنا كرأس حالي بعد commits لاحقة.
>
> **عقد محتوى هذا الملف (يحرسه `scripts/check-current-state-size.mjs`):** بوابات وحالة متحققة وحدود توقف وخطوة تالية مسموحة وقرارات نشطة **فقط** — بحد 20 KB. كل سجل موجات/شرائح/دمج مؤرخ يُكتب في `current-state-log.md` حصرًا.

## 2. ما هو منشور على `main`

| المجال | الحالة والحد |
|---|---|
| الطلب والاتفاق والتنفيذ والتحصيل/الدين | منفذ محليًا؛ القبض ليس ربحًا والدين ليس كاشًا. |
| المصروف والمورد والشراء والدفعات | منفذ محليًا؛ الشراء لا يصبح COGS تلقائيًا. |
| محافظ الكاش والافتتاح والتحويل والضبط والعكس | منفذ؛ كل تصحيح بعكس كامل وسبب ومفتاح idempotency. |
| المادة والمخزون والاستهلاك والهدر | منفذ؛ فرق المادة للطلب تفسيري ولا يغير Snapshot. |
| المالية العميقة | نتيجة الفترة (G3) واستحقاق المالك (O1) والكتالوج الاختياري (G4-A) والوقت الفعلي (G4-B) والتعادل والسيولة (G5) — مقبولة ومندمجة؛ ثم الميزانيات والأهداف (عقد 42) والإهلاك الاسمي (عقد 43) وتذكير المصروف المتكرر (عقد 41) من خارطة الطريق المالية المكتملة (اللوق §75–§85). |
| الاستعادة وPWA | export/import ذري محلي محروس (عقد 39) وPWA تشغيلية بلا backup أو Sync. اختبار Android/iOS وOffline الإنتاجي وPages production وPilot البشري **غير منفذ**. |
| الاختبارات والبوابات | عند إغلاق البرنامج الرئيسي: جذري 514/514 وتطبيق 1996/1996 والحزمة تحت سقف 650,000/155,000 بلا رفعه (اللوق §84/§85)؛ آخر حالة CI لكل رأس تُقرأ من GitHub لا من هنا. |

## 3. الحزمة المالية G3–G5 وما بعدها (مدمجة)

كل شرائح G3/O1/G4-A/G4-B/G5 **مقبولة وظيفيًا ضمن نطاقها ومندمجة على `main` عبر PR #115**، وهذا لا يعني اجتياز جهاز فعلي أو Pilot. عقودها الحاكمة: 14 (توزيع نتيجة الفترة)، 12/17 (الرؤى والتعادل)، 15 (الكتالوج)، 16 (الوضع التشغيلي والوقت الفعلي)، وتغطيتها التنفيذية في `docs/implementation/02-domain-contract-coverage.md` و`docs/implementation-traceability.md`؛ جدول القبول التفصيلي بحدوده الصريحة في اللوق §16–§29.

### 3.1 تكامل التخزين والاستعادة

الزوج الحالي: schema `38` وexport `30` (`storage/local/types.ts`). الاستيراد يتحقق قبل `replaceSnapshot` الذري من علاقات G3/O1/G4/G5 والعقود 26–39 (التنقل والمسودات والقفل والبيان والمشاركة والتصحيحات ومظروف النسخ)، والأزواج التاريخية المقبولة تُهاجر بأمان فقط (القائمة في `localTransferService` وعقد 39). **الحدود:** لا مزامنة ولا استعادة بين أجهزة ولا Cloud backup؛ التصدير اليدوي مطلوب قبل تغيير الهاتف أو مسح بيانات المتصفح.

## 4. حدود مالية غير قابلة للتفاوض

> collection ≠ profit، debt ≠ cash، purchase ≠ COGS، owner money ≠ sale/expense، missing ≠ zero.

لا تصف أي سطح بأنه COGS كاملة أو صافي ربح نهائي أو قيمة مشروع أو توقع مضمون. في G3، COGS اختيارية من دليل استهلاك فقط؛ عند غياب الدليل يبقى Snapshot بديلًا معلنًا. لا يغير أي مسار `CostSnapshot` أو طلبًا تاريخيًا بصمت. لا توزع مصروفًا أو هدرًا أو استهلاكًا عامًا على طلب/منتج بلا عقد وأساس ظاهر. لا تحول وقت التنفيذ إلى أجر أو تكلفة فعلية أو سعر مقترح. كل تصحيح حساس بعكس أو تسوية موثقة؛ لا حذف صامت أو restatement.

## 5. ما هو متوقف عمدًا

| المجال | الحالة |
|---|---|
| الشرائح المالية | لا شريحة مالية جديدة تلقائيًا؛ كل توسع يحتاج قرار نطاق وعقدًا وفرعًا وPR مستقلة. |

## 7. متطلبات الإغلاق القادم

أي PR يجب أن تحدّث **هذا الملف** (الحقول الحية فقط: البوابات، الحالة المتحققة، الخطوة التالية، القرارات النشطة) **وتُلحق سجل الشريحة/الموجة في `current-state-log.md`** داخل الـPR نفسها، وتذكر: النطاق، العقد، PR التاريخية، schema/export إن تغيرتا، أثر الاستيراد/التصدير، الحدود، والفعل التالي. لا تذكر SHA دمج PR الحالية بوصفها رأسًا لاحقًا؛ استخدم `git fetch origin --prune`. لا تضف `apps/prototype-web/client/public/__manus__/version.json` إلى Git، ولا تخلط تغييرات `todo.md` المحلي داخل commit.
