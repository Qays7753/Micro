## 3. الحزمة المالية G3–G5 وما بعدها (مدمجة)

كل شرائح G3/O1/G4-A/G4-B/G5 **مقبولة وظيفيًا ضمن نطاقها ومندمجة على `main` عبر PR #115**، وهذا لا يعني اجتياز جهاز فعلي أو Pilot. عقودها الحاكمة: 14 (توزيع نتيجة الفترة)، 12/17 (الرؤى والتعادل)، 15 (الكتالوج)، 16 (الوضع التشغيلي والوقت الفعلي)، وتغطيتها التنفيذية في `docs/implementation/02-domain-contract-coverage.md` و`docs/implementation-traceability.md`؛ جدول القبول التفصيلي بحدوده الصريحة في اللوق §16–§29.

### 3.1 تكامل التخزين والاستعادة

الزوج الحي: schema `42` وexport `34` (`storage/local/types.ts`؛ ارتفع في S14). سجل `RELEASED_LEGACY_EXPORT_PAIRS` يقبل 28 زوجًا موروثًا، والإجمالي مع الزوج الحالي 29؛ كتابة الأزواج في السجل بصيغة export/schema، بينما الزوج الحي هنا schema/export. تاريخيًا كان زوج S12 schema `40`/export `33`، وصار 32/40 (export/schema) موروثًا؛ وأضافت S14 الزوج 33/40. الاستيراد يتحقق قبل `replaceSnapshot` الذري من العلاقات والعقود، ويهاجر الأزواج المقبولة تمثيلًا دون إعادة أعمال. **الحدود:** لا مزامنة ولا استعادة بين أجهزة ولا Cloud backup؛ التصدير اليدوي مطلوب قبل تغيير الهاتف أو مسح بيانات المتصفح.

## 4. حدود مالية غير قابلة للتفاوض

> collection ≠ profit، debt ≠ cash، purchase ≠ COGS، owner money ≠ sale/expense، missing ≠ zero.

لا تصف أي سطح بأنه COGS كاملة أو صافي ربح نهائي أو قيمة مشروع أو توقع مضمون. في G3، COGS اختيارية من دليل استهلاك فقط؛ عند غياب الدليل يبقى Snapshot بديلًا معلنًا. لا يغير أي مسار `CostSnapshot` أو طلبًا تاريخيًا بصمت. لا توزع مصروفًا أو هدرًا أو استهلاكًا عامًا على طلب/منتج بلا عقد وأساس ظاهر. لا تحول وقت التنفيذ إلى أجر أو تكلفة فعلية أو سعر مقترح. كل تصحيح حساس بعكس أو تسوية موثقة؛ لا حذف صامت أو restatement.

## 9. بوابات العمل الحالية وحدود الإغلاق

- لا يبدأ أي إعادة هيكلة أو نقل ملفات أو تنظيم بنيوي اعتمادًا على هذا التوثيق. تُطبق بوابة ما بعد المجموعة ٦: مسح شامل حديث للقراءة فقط على أساس العمل، تقرير يصنف النتائج `fix now / preserve / defer / out of scope` ويحدد خريطة هدف وموجات وحدود رجوع ومخاطر ومعايير قبول؛ ثم مراجعة المالك وقراره قبل التنفيذ. لا يفتح PR #385 التوثيقي هذه البوابة.
- روجعت النتائج الأمنية الثلاثون مباشرة على `74d74c`: 22 `fixed-verified` و8 `open`، منها `MNG-LOCAL-03` المفتوحة تقنيًا والمؤجلة بقرار المالك. سجل المتابعة الآمن يبين كل حالة، والتفاصيل الداعمة في ملف المشروع الخاص. النتائج المفتوحة تبقى واجبة المتابعة؛ أعد فحص ما ينطبق منها قبل ربط DB/Media إنتاج أو السماح ببيانات حقيقية.
- PR #385 توثيقي. وفق قرار المالك، الدمج العادي إلى `main` بلا بادئة تخطٍ يطلق نشر Pages. هذا النشر يرفع الواجهة والعامل، لكن الإعداد الإنتاجي الحالي يجعل `/api/*` ترد `503` لغياب DB/Media؛ لا يفعّل الخدمات المتصلة ولا يجيز بيانات حقيقية. لا تغيير لإعدادات Cloudflare أو قاعدة البيانات. بعد الدمج تحقق من SHA ونجاح Pages ومحتوى الوثائق، ثم توقف قبل حذف أي فرع واطلب تأكيد المالك الأخير؛ `main` يبقى.
