# G9.3 — سطح قرار قيد التشغيل وQA

يعرض `/schedule` فوق الجدول المحلي الحالي عدد الدقائق المعروفة، والتعارض، وتجاوز السعة، والوقت غير المحدد. تظهر الرسالة والسبب داخل يوم الأسبوع/الشهر بدل لون منفرد، ويبقى الفعل التالي بيد المالك. لا ينشئ السطح تقويمًا عامًا أو حجزًا أو موردًا جديدًا.

| الحالة | ما يراه المستخدم |
|---|---|
| ضمن الحد | الدقائق المعروفة مع غياب تحذير السعة |
| متجاوز | تحذير «يتجاوز السعة المعلنة» مع إبقاء القرار يدويًا |
| ناقص | «وقت غير محدد» بدل احتسابه صفرًا |
| تعارض | تحذير مستقل للتعارض |
| فارغ | لا مواعيد مسجلة، دون ادعاء توافر كامل |

اجتازت الفحوص المحلية `pnpm check` واختبارات ScheduleService القائمة واختبارات capacity decision. لم تتغير أي بيانات مالية أو سجلات مواعيد عند القراءة. مراجعة الجهاز الفعلي وقياسات Pilot ليست منفذة.
