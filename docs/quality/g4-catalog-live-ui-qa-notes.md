# G4-A Live UI QA Notes

**التاريخ:** 23 أغسطس 2026
**البيئة:** معاينة المستودع الفعلي على `localhost:3001`
**بيانات الاختبار:** مشروع محلي باسم «مشغل اختبار G4»؛ سيزال بعد التحقق.

## نقطة البداية

- فتحت شاشة التأسيس المحلي بعد التأكد من خلو التخزين السابق.
- ثبّت التطبيق اسم المشروع التجريبي وانتقل إلى اختيار سجل جديد بنجاح.
- لا توجد في هذه المرحلة أحداث مالية أو طلبات أو مراجع كتالوج تجريبية مثبتة بعد.

## ملاحظة واجهة أولية

- فتحت صفحة `/catalog` وظهرت حقول المنتج/الخدمة والاسم ووحدة العرض بوضوح، مع توضيح صريح أن المرجع لا يحدد سعرًا أو مخزونًا أو ربحًا نهائيًا.
- ظهرت رسالة «تعذر قراءة الأعمال المرتبطة لحساب الهامش المسجل» في حالة كتالوج فارغ، مع أن Console لم يعرض خطأً. سيفحص المسار قبل اعتماد QA؛ لا تعد هذه الحالة مقبولة بعد.

## إصلاح الترحيل وتحقق الكتالوج

- السبب كان قاعدة محلية وصلت إلى schema 16 بلا مخزن `catalog-items`؛ رُفع الإصدار إلى schema 17 ليضيف المخزن ويعيد الروابط القديمة إلى `null` بأمان.
- بعد إعادة فتح `/catalog` اختفت رسالة الفشل، وظهرت الحالة الفارغة السليمة.
- أضفت المنتج التجريبي «صندوق هدايا» بوحدة «قطعة». ظهر المرجع في القائمة بلا سعر أو مخزون أو COGS، وعرض «لا توجد طلبات نهائية مرتبطة» مع حد أن الهامش لا يشمل تكلفة فعلية كاملة أو مصاريف عامة أو وقتًا غير مسجل.

## تحقق ربط المسودة

- أنشأت مسودة طلب عميل محلية بعد حفظ المرجع.
- ظهر اختيار «مرجع العمل» كحقل اختياري، مع خيار صريح «لا أربط هذه المسودة بمرجع الآن» وخيار «صندوق هدايا · منتج».
- توضح الواجهة قرب الحقل أن المرجع لا يغير السعر أو Snapshot أو تكلفة طلب سابق؛ لم تختبر هذه QA أي أثر مالي أو اتفاق أو بيع.
- تعذر اختيار القائمة عبر أداة المتصفح بسبب خطأ UTF-8 من الأتمتة؛ قُرئت قيمة الخيار من DOM ثم عُيّنت عبر حدث `change` محلي. تحققت الواجهة من ظهور «صندوق هدايا · منتج» محددًا في الحقل. هذا بديل QA للأتمتة فقط، وليس تغييرًا في منطق المنتج.
- أُدخل وصف مسودة وعميل وملاحظة ثم حُفظت؛ أظهرت الواجهة رسالة نجاح، وبقي المرجع المختار ظاهرًا. لم يجر الانتقال إلى Snapshot تكلفة أو اتفاق، لذا لم ينشأ أثر سعر أو كاش أو ذمة أو نتيجة.

## تحقق المظهر الداكن

- فُعّل المظهر الداكن على محرر المسودة؛ بقي اختيار المرجع، النص التوضيحي، رسالة الحفظ، والحقول العربية/الرقمية مقروءة بوضوح.

## تنظيف البيانات

- حذفت قاعدة `micro-prototype-local` من IndexedDB ومسحت `localStorage` و`sessionStorage` بعد الاختبار.
- أعادت المعاينة توجيه `/catalog` إلى شاشة التأسيس المحلي، ما يؤكد عدم بقاء مشروع «مشغل اختبار G4» أو مرجع «صندوق هدايا» أو المسودة التجريبية.
