# تحقق Slice F بالسيناريو — الموعد والقدرة

هذا تحقق مفهومي واختباري لشريحة محلية. لا يثبت التبني أو الاستعداد للدفع؛ يحتاج ذلك Pilot منفصلًا مع أصحاب مشاريع.

## الدليل

غطت اختبارات `ScheduleService` التداخل، تجاوز السعة، الوقت غير المحدد، وتأجيل اليوم بسجل محفوظ. وغطى `FulfillmentService` إكمال الموعد عند التسليم مع ثبات الكاش والذمة والإيراد المعترف به. وترحل schema 8 سجلات Slice B القديمة إلى وقت ومدة `null` مع تفضيل سعة يومية `null` بدل اختراع تاريخ أو قدرة.
