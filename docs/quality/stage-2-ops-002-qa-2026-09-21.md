# سجل QA — Stage 2 / الموجة 6 (OPS-002 — تنبيهات انخفاض المخزون)

**التاريخ:** 2026-09-21 · **PR:** #202 · **الفرع:** `stage-2/completion-remaining` · **خط الأساس:** `771db4e`

## 1. قرار الواجهة (بروتوكول التسليم §5.4)
قراران: (١) شريحة تنبيه نصية واحدة في صف معرفة المادة القائم، نصها قالب مُدار بالبيانات يذكر قيمة الحد نفسها (مفهوم بلا تفسير إضافي)؛ (٢) محرر الحد داخل `<details>` منهار (ملخص واحد محسوب +1 موثق «حدود تنبيه المخزون» وتسمية فعل واحدة «احفظ الحد» — سقف InventoryMaterials 60→61 بسابقة FinanceMore)؛ كل نصوص المحرر الأخرى داخل الجسم المنهار. لا CSS/رموز/مسارات جديدة.

## 2. مصفوفة الحالات المختبرة (آليًا)
| المسار | الحالة | الاختبار | النتيجة |
|---|---|---|---|
| تحت الحد (كمية معروفة + حد معلن) | شريحة بقيمة الحد | خدمة + DOM | PASS |
| عند الحد تمامًا | صمت (لا إلحاح مصنوع) | دومين + DOM | PASS |
| فوق الحد | صمت | دومين | PASS |
| بلا حد معلن (سجل قديم أو بعد الإزالة) | صمت — لا يُخترع حد | دومين + خدمة + DOM | PASS |
| كمية غير مؤكدة | صمت مهما كان الحد | دومين + خدمة + DOM | PASS |
| غير متتبَّعة | لا تُقيَّم إطلاقًا | دومين + خدمة | PASS |
| الحفظ/الإزالة | تفضيل حقيقي عبر البوابة + إعادة اشتقاق بلا إعادة تحميل | خدمة + DOM | PASS |
| أي قراءة | لا كتابة (مطابقة لقطة المخزن الكاملة) | خدمة | PASS |
| تعطيل قدرة المخزون | المحرر يختفي والقراءة تبقى (G-004) | DOM | PASS |
