# G9.1 — خطة اختبار قيد التشغيل المحدود

| الحالة | المتوقع |
|---|---|
| السعة غير مفعلة | `unknown`، لا رفض ولا سعة صفر |
| مجموع معروف ضمن الحد | `within_limit` مع مجموع الدقائق ومصدره |
| تجاوز الحد | `over_limit` مع تحذير وقرار المالك، دون منع أو أثر مالي |
| مدة ناقصة | `needs_review` وسبب واضح، ولا تدخل كصفر |
| تعارض | تحذير تعارض مستقل، ولا تعديل للموعد أو المال |
| إلغاء | لا يدخل في مجموع الضغط، ويبقى حدث الإلغاء محفوظًا |
| إعادة القراءة | النتيجة نفسها دون كتابة أو تكرار |

يثبت الاختبار أن القيد قراءة تشغيلية محلية فقط، ولا يغير الكاش أو الذمم أو النتيجة أو `CostSnapshot` أو سجل موعد تاريخي.
