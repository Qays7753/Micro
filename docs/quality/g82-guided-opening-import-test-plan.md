# G8.2 — خطة اختبار عقد الاستيراد الافتتاحي الموجّه

هذه الخطة تسبق واجهة G8.3، وتحوّل العقد إلى حالات قبول قابلة للتنفيذ. مصدر fixtures هو `docs/fixtures/g82-guided-opening-import-fixtures.json`.

| الحالة | الإعداد | المتوقع | حارس عدم فقد الحالة |
|---|---|---|---|
| ملف صحيح | Store فارغ، fixture `valid` | preview ثم confirm يضيف فقط profile ومحفظة افتتاحية ومادة افتتاحية | snapshot بعد الفشل/قبل التأكيد مطابق للسابق |
| ملف ناقص | fixture `incomplete` بلا مصدر/تاريخ/ملاحظة كاملة | `validation_error` يذكر الحقول الناقصة | لا استدعاء كتابة |
| ملف تالف | `corrupt` | `validation_error` عربي | لا تغيير في Store |
| نسخة غير مدعومة | `unsupported.version = 99` | رفض الإصدار دون migration تخمينية | لا تغيير في Store |
| Store غير فارغ | Store يحوي طلبًا أو حدثًا، ثم fixture `valid` | `non_empty_store` | لا overwrite ولا merge |
| إعادة المحاولة | confirm مرتين لنفس `importId` | نفس النتيجة دون أثر ثانٍ | عدد المحافظ/الحركات ثابت |
| مبلغ/كمية سالبة أو غير صحيحة | تعديل fixture صحيح | رفض قبل الكتابة | لا تحويل إلى صفر |
| تاريخ أو عملة غير صالحة | تعديل fixture صحيح | رفض قبل الكتابة | لا أثر مالي |
| تاريخ مبيعات/دين شامل | إضافة حقل تاريخي غير متعاقد عليه | رفض الحقل/الملف | لا اختلاق أحداث |

## معيار النجاح

تمر الخطة عندما يثبت الاختبار أن التحقق كامل قبل الكتابة، وأن الفشل لا يمس snapshot السابق، وأن كل أثر افتتاحي يمر عبر Application/Domain/LocalStore مع مفاتيح idempotency مستقلة. لا تعتبر الخطة قبولًا لجهاز فعلي أو مزامنة أو backup سحابي.
