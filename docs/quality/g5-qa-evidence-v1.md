# دليل QA لشريحة G5

**التاريخ:** 24 أغسطس 2026

**الفرع:** `g5/contribution-break-even-short-cash`

**البيئة اليدوية:** Prototype محلي على `http://localhost:3000` ببيانات اصطناعية فقط داخل profile باسم `G5 QA`.

## بطاقة قرار QA

| البند | الدليل المقبول |
|---|---|
| السؤال | فصل الهامش المسجل ونقطة التعادل المفككة عن الكاش والتوقعات القصيرة المعلنة. |
| الوضع الفارغ | عند غياب الطلبات النهائية أو الثابت المسجل، لا يظهر رقم نقطة تعادل؛ يظهر سبب النقص والفعل التالي. |
| التوقع القصير | الكاش المسجل، التحصيلات المعلنة، والالتزامات المعلنة في خانات مستقلة؛ الإعلان لا يصبح قبضًا أو دفعًا. |
| الحماية المالية | القراءة لا تعدل `CostSnapshot` أو الطلبات أو الأحداث أو الكاش أو الذمم. |
| التصحيح | الإعلان الفعال يملك فعل «صحح بعكس موثق»، والعكس يحفظ الأصل ولا يعدله صامتًا. |
| الإيقاف | `incomplete` و`invalid` لا ينتجان رقمًا بديلًا لنقطة التعادل أو التوقع. |

## الفحص اليدوي

| المسار | الإجراء والنتيجة |
|---|---|
| `/finance` بلا بيانات | ظهر Empty State يشرح عدم وجود كمية نهائية أو تكلفة ثابتة موجبة، وحجب نقطة التعادل والتوقع القصير بدل استخدام صفر مضلل. |
| `/finance/g5/declaration` | ظهرت حقول الاتجاه، المبلغ بالدينار، التاريخ، المصدر، درجة المعرفة، والملاحظة، مع نص واضح أن الإعلان لا يغير الكاش. |
| حفظ تحصيل اصطناعي `80.00` بتاريخ `2026-08-25` | عاد المسار إلى `/finance`; ظهر الإعلان بالمصدر والتاريخ، وبقي الكاش المسجل `0.00` بينما ظهر التوقع بعد المعلن `80.00` في بطاقة منفصلة. |
| RTL/phone-first | السطح ظهر ضمن عمود الهاتف، البطاقات مرتبة رأسيًا، الأرقام ذات اتجاه LTR داخل `micro-number`، والأفعال متاحة بلمس واضح. |
| Dark theme | تم التبديل والعودة إلى Light؛ بقيت حالات القراءة والأرقام والنصوص قابلة للفهم دون الاعتماد على اللون وحده. |
| تصحيح الإعلان | زر العكس ظاهر في السطح؛ منطق الحفظ والعكس والتحقق اختُبر آليًا دون حذف الأصل أو إنشاء حركة مالية. |

## الحدود المعروفة

بيانات المتصفح اليدوية اصطناعية ولا تمثل حالة مالية حقيقية. لم تُنفذ عمليات قبض أو دفع أو شراء أو مزامنة. لم يُختبر العرض ببيانات طلبات نهائية متعددة من خلال خطوات UI الكاملة؛ تغطي ذلك اختبارات Domain/Application، بينما يبقى فحص المزيج المرئي اليدوي خطوة QA لاحقة إذا طلب المالك توسيع السيناريو.
