الاقتراح الأكثر تحفظًا هو منتج Micro واحد، بحدود منطقية مستقلة لـManage المحلي وMarket وDelivery، دون افتراض فصل النشر أو قاعدة البيانات أو المزود. أي مشاركة بين السياقات تكون استخدامًا صريحًا ومعتمدًا، لا استيراد سياسات أو سجل سياق لآخر. هذا وصف مستهدف مشروط بقرار؛ لا يفتح موجة تنفيذ.
