**ما لم يُنفذ (بنفس ترتيب الأولوية للقرار):**
1. **MNG-LOCAL-03** — مؤجلة بقرار المالك؛ تنفيذها (تشفير/مفاتيح/صيغة) ينتظر قرارًا صريحًا جديدًا.
2. **توصيل مزود Ask Micro** — مؤجل بقرار المالك المسبق؛ لا مزود اختير أو وُصل أو استُدعي.
3. **البوابات التشغيلية قبل أي بيانات حقيقية** كما هي موثقة في DOC-041: G11/G12، MFA للحساب الإداري، تطبيق المشغل للترحيلات حتى 0017، ومراجعة النتائج المفتوحة ذات الصلة قبل أي ربط إنتاجي.
4. **قياس الأجهزة الفعلية** (بوابة DEVICE) — السقوف وقائية مشتقة من القياس الكنوني للذهبي، ولا يُدّعى أداء أضعف الأجهزة.
5. لا مس لبوابة المسح الهيكلي — أي عمل بنيوي ينتظر قبول المالك لمسح 2026-11-21.

**حدود الرجوع (rollback):** كل إصلاح التزام مستقل قابل للرجوع منفردًا؛ الإرساءات (`fe2b1b5a`) تُرجع مع كودها لأن راتشة الحجم وأسطح الحزمة تفشلان بدونه؛ لا ترحيل بيانات ولا حالة تحتاج رجوعًا. الترتيب الآمن للرجوع الكلي: عكس التزامات docs ثم fe2b1b5a ثم f0b31877 ثم ec4c8928 ثم ea3f52e1 ثم c707b279.

**أفعال Manus/المالك المطلوبة قبل أي تجربة بيانات حقيقية/خدمات متصلة:**
1. مراجعة هذا التقرير وdiffs الالتزامات الخمسة عند بوابة IN_REVIEW (DOC-044/WS-254) وقرار الدمج.
2. حسم MNG-LOCAL-03 (تشفير بيانات الجهاز) صراحة قبل أي بيانات مالك حقيقية على جهاز فعلي.
3. خطوات المشغل الموثقة (G11/G12، MFA، الترحيلات 0001–0017، بيئة تجربة منفصلة Q291) قبل فتح أي بوابة اتصال.
4. إن قُبل تفاعل المظهر الجديد لسلوك Q270 (رفض الحفظ دون اتصال برسالة «لم يُحفظ») فتوصى مراجعته في تجربة استخدام قصيرة لأنه تغيير سلوك مقصود وموثق — القرار مسجل وليس اجتهاد وكيل.
