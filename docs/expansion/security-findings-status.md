## قاعدة الإغلاق والتشغيل

لا تنتقل أي نتيجة إلى `fixed-verified` إلا مع دليل قابل للتتبع يربط فحصًا مباشرًا بالنتيجة والشجرة والالتزام الحالي. تقرير تنفيذ أو ادعاء في PR أو نجاح اختبارات عامة لا يكفي وحده. لا تُسقط النتائج المفتوحة من سجل العمل. لم يغيّر فرع الإصلاح إعدادات Cloudflare أو قاعدة البيانات ولم يستخدم بيانات حقيقية؛ إعداد إنتاج Pages لا يحتوي bindings لخدمات قاعدة البيانات/الوسائط، وعامل النشر يرفض طلبات `/api/*` عند غيابها. هذا قيد تشغيل حالي، وليس إغلاقًا لنتائج الشيفرة. `MNG-LOCAL-03` تبقى واجبة المراجعة قبل أي بيانات حقيقية، ومعها البوابات الموثقة (G11/G12، MFA، تطبيق الترحيلات حتى 0017، وقرارات المالك المفتوحة في DOC-041). لا يحتوي هذا الملف على أسرار أو إرشادات استغلال.
