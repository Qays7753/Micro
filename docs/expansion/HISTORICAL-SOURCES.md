# Expansion — سجل المصادر والأرشيف

**الحالة:** `CURRENT / NAVIGATION ONLY`
**الغرض:** حفظ أصل الفكرة والتحليلات السابقة من دون أن تخلط على Agent بين قرار تاريخي وقرار حاكم حالي.

## Major Discussion Points

## 1. ما هو المرجع التنفيذي الآن؟

لا يبدأ التنفيذ من أي ملف هنا. المرجع هو [`README.md`](README.md) ثم [`DECISIONS.md`](DECISIONS.md) و[`TRACKER.md`](TRACKER.md)، مع عقود Micro وحالة Git الحية.

| المصدر | التصنيف | متى يستخدم؟ | لا يستخدم من أجله |
|---|---|---|---|
| `docs/expansion/README.md` | CURRENT / ENTRY POINT | أي مهمة توسعة. | وصف حالة Git التفصيلية بدل `current-state.md`. |
| `docs/expansion/DECISIONS.md` | CURRENT / OWNER-ALIGNED | تثبيت النطاق، الخصوصية، ووعد المنتج. | اختراع تفاصيل Schema أو provider. |
| `docs/expansion/TRACKER.md` | CURRENT / EXECUTION TRACKER | ترتيب عمل E-00 ثم L/A/B ومعايير الانتقال. | تأشير بند بلا دليل أو PR/QA. |
| `docs/expansion/historical-source/` | ARCHIVE / HISTORICAL | الرجوع لسبب فكرة أو تفصيل يناقش بديلًا. | كتابة كود أو اختيار حالة أو صلاحية من دون مطابقة CURRENT. |

## 2. ما الذي استبدلناه عمدًا من الحزمة التاريخية؟

| الصياغة التاريخية المحتملة | القرار البديل | السبب |
|---|---|---|
| «New Expansion» أو مساحات تبدو منتجات ظاهرة مستقلة | استُبدلت أولًا بقدرات تحت `الخدمات`، ثم أُلغي ذلك بقرار E-00.14: `السوق` في BottomNav ورمز Delivery في AppBar بلا صفحة خدمات مركزية ([عقد IA](MARKET-DELIVERY-OWNER-IA-CONTRACT.md)). | لا نريد تحميل Owner قرار اختيار تطبيق قبل أن يرى عمل مشروعه. |
| بطاقتا Market/Delivery كأول سطح للخدمات | صندوق وارد تشغيلي قصير للمتابعات ثم مدخلا بدء. | الصفحة يجب أن تجيب «ما الذي يحتاج قراري؟» لا «أي خدمة أختار؟». |
| التوسع مباشرة إلى بوابات متصلة | تجربة L local-first، ثم A للتفعيل الحقيقي. | لا ننسب أمنًا أو تعاونًا حقيقيًا لمحاكاة المتصفح المحلي. |
| أي API/Webhook/Driver أو Dispatch لاحق | لا API خارجي أو Driver Portal أو تشغيل أسطول في النطاق الحالي. | لا دليل أن هذه أول مشكلة أو أن التشغيل متاح. |
| تقييمات/نجوم أو Marketplace عام | مؤجلة وغير مصرح بها. | لا نبني سمعة ظاهرية أو سوقًا عامًا قبل إثبات مسار فئة/منطقة واحد. |

## 3. حفظ التاريخ بلا إعادة استخدام عشوائي

لا نحذف الحزمة تحت `historical-source/` لأنها قد تفسر أصل قرار أو سؤال مستخدم. لكنها موسومة في رأسها بوضوح. عند الاستشهاد منها، يذكر Agent اسم الملف والفقرة ويعيد ربطها بقرار CURRENT أو يوضح أنها لم تعد معتمدة.
