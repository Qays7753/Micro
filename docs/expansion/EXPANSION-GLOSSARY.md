# Expansion — قاموس المصطلحات الحاكم

**الحالة:** `CURRENT / E-00 / VOCABULARY ONLY`
**الغرض:** يمنع أن تعني كلمة واحدة «نية» في شاشة و«واقعة مالية» في أخرى أو أن تتحول أسماء منتجات إلى حدود صلاحية.

## Major Discussion Points

| المصطلح | المعنى المعتمد | لا يعني |
|---|---|---|
| Micro | منتج واحد لمالك مشروع يدير عمله ويصل إلى قدرات شبكة عند الحاجة. | ثلاثة تطبيقات أو ثلاثة اشتراكات. |
| Micro Manage | جزء Micro المحلي لإدارة المال والطلبات والمخزون والمواعيد. | مصدرًا تلقائيًا لبيانات Market/Delivery أو شرطًا لحساب شبكة. |
| الخدمات | لوحة متابعة خارجية قصيرة مرتبطة بالمشروع. | Marketplace أو قائمة منتجات أو Dashboard مالية ثانية. |
| Market | قدرة شبكة للعثور/الرد/العرض ضمن نطاق محدود. | Checkout أو دفع أو ضمان مورد أو سوق عام. |
| Delivery | قدرة شبكة لطلب حركة/Quote/حالة معلنة. | شركة توصيل أو تتبع حي أو إثبات قبض/تسليم. |
| Owner | صاحب مشروع أو ممثل مخول له داخل Workspace. | مديرًا لمورد/Courier أو مالك بيانات جهة أخرى. |
| Supplier member | عضو داخل جهة مورد. | رؤية مال Owner أو عروض المنافسين أو قرار Owner. |
| Courier member | عضو داخل جهة توصيل. | Driver portal أو حق رؤية كل العناوين/المهام أو مال Owner. |
| Admin | دور داخلي محدود للـModeration والبلاغ والسياسة. | Super-admin مالي أو مشغل تجاري لكل تفاعل. |
| Need | وصف Owner لحاجة يمكن نشرها. | Purchase أو التزام أو فاتورة. |
| Response | ما أعلنه Supplier عن Need. | بيع مؤكد أو سعر نهائي أو استلام دفع. |
| Listing | عرض مورد قابل للنشر بعد مراجعة. | توفر حي أو ضمان جودة أو سمعة. |
| Quote | عرض Courier للحركة. | Expense أو Booking أو Payment. |
| Status event | واقعة حالة قالها Courier بفاعل ووقت. | حقيقة مخزون أو تسليم Order أو قبض. |
| Attention | عنصر متابعة يحتاج قرارًا أو اطلاعًا من Owner. | إشعار Push مضمون أو رقم نشاط عام. |
| External reference | رابط اختياري بين سياق شبكة وسجل Manage. | حق قراءة Manage أو مزامنة أو أثر مالي. |
| Recording suggestion | اقتراح لOwner لتسجيل واقع داخل Manage. | كتابة حدث تلقائية أو تعبئة مبلغ/تاريخ. |
| Role simulator | بيئة QA محلية تمثل View وسياسة دور. | حسابات حقيقية أو Authorization أو عزل أجهزة. |
| L | تجربة بيت محلية قبل Cloud/Auth. | Pilot متعدد الأطراف أو أمن إنتاج. |
| A | بوابة التفعيل الحقيقي متعدد الأطراف. | مجرد Login أو صفحة حساب. |
| Pilot | تجربة ضيقة مع أطراف حقيقيين وبنود قياس. | نجاح سوق شامل أو دليل دفع أو اعتماد عام. |
