# 03 — ترتيب الفجوات

> كل قدرة مرتبة حسب المسافة بين تكرارها المتوقع وموقعها الحالي. أكبر فجوة أولًا.
> هذه الصفحة هي ما سيتخذ المالك بناءً عليه قرارات النقل.

## مقياس الفجوة

| الفجوة | التعريف |
|---|---|
| **كبيرة جدًا** | قدرة يومية أو تأسيسية في طبقة `ج` أو `د` مشروطة ببيانات لا تظهر بسهولة |
| **كبيرة** | قدرة يومية أو تأسيسية في طبقة `ج`، أو أسبوعية مشروطة بحجب سطح كامل |
| **متوسطة** | قدرة يومية في طبقة `ب`، أو أسبوعية في `ج` |
| **صغيرة** | أسبوعية في `ج`، أو شهرية في `ج` |
| **لا فجوة** | التكرار يتناسب مع الموقع |

## الخلاصة: ما يحتاج نقلًا فوريًا

ثلاث قدرات تأسيسية (محفظة بداية، رصيد مالك افتتاحي، مادة بداية) لا يمكن لمستخدم جديد الوصول إليها دون إكمال دورة طلب كاملة أو استيراد ملف JSON. وخمسة أسطح يومية (المالية، الكاش، الجدول، المتابعات المستحقة، مؤشرات مالية) إما مشروطة بظهور وحدات أو غير قابلة للوصول أصلًا.
