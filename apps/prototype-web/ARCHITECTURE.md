# معمارية Web App لـMicro Prototype

## نطاق الحزمة الحالي

تحتوي هذه الحزمة Web UI للـPrototype. اكتملت فيها **Slice 0** للغلاف العربي RTL، و**Slice 1** للتأسيس والمسودة المحلية، و**Slice 2** لـSnapshot التكلفة وسعر الحماية، و**Slice 3** للاتفاق والعربون وبداية التنفيذ، و**Slice 4** للجاهزية والتسليم والتحصيل أو الدين ونتيجة الطلب، و**Slice 5** للحماية المحلية والتصدير والاستيراد. لا تنفذ الحزمة PWA أو Cloud Sync أو Auth أو SaaS أو استضافة Cloudflare أو Native.

## مسار المسؤولية

```text
React UI
  → Application services / view state
  → Micro Domain Core في ../../src/domain/craft-order
  → LocalStore port
  → IndexedDB adapter
```

لا تستورد مكونات React `IndexedDbLocalStore` ولا تضع قواعد المال فيها. `CostService` و`AgreementService` و`FulfillmentService` تستدعي Domain Core. `LocalTransferService` يقرأ ويحلل ويتحقق من ملف النقل، ثم يستدعي LocalStore فقط بعد تأكيد صريح من المستخدم. `PreferenceService` يحفظ تفضيل المظهر كبيانات واجهة محلية لا كحقيقة مالية.

## ما يحفظه Prototype محليًا

يحفظ التطبيق ملف النشاط، تفضيلات المظهر، مسودات قبل Domain، تاريخ Snapshots تكلفة غير قابل للتعديل، و`StoredCraftOrder` عند تثبيت الاتفاق. يحمل سجل الطلب الموعد ومصدر الاتفاق بالإضافة إلى `CraftOrder` المجمّد. ربط المسودة بالطلب وحفظهما يتم عبر `commitOrderFromDraft` داخل transaction واحدة في IndexedDB، حتى لا ينجح أحد السجلين منفردًا.

يستخدم Adapter إصدار مخطط IndexedDB صريحًا `schemaVersion = 5`. تضيف migrations مخازن الطلبات والتفضيلات عند فتح سجلات أقدم وتحافظ على المسودات بإضافة حقول Snapshots ومعرّف الاتفاق الفارغ. لا تغير نسخة تكلفة أو حدثًا تاريخيًا بصمت.

## قواعد السعر والتنفيذ والنتيجة

سعر الحماية ناتج من Domain ويمثل تكلفة القطعة مع هامش الحماية المدخل، لا سعر سوق ولا ربح ولا قرار قبول. العربون كاش محصل لا ربح تلقائي ولا تسليم. لا يمكن تسجيل الجاهزية إلا من `in_progress`، ولا التسليم إلا من `ready`. التسليم لا يزيد `collectedMinor`؛ بعده فقط يمكن تحصيل المتبقي أو تسجيله دينًا. الدين لا يزيد الكاش.

لا تظهر `profitIndicatorMinor` إلا عندما تكون `resultStatus = final`. عند تكلفة ناقصة أو متغيرة أو تحتاج مراجعة، تعرض الواجهة سبب الحجب وحقول الإيراد/التكلفة التي اعترف بها Domain دون ادعاء ربح نهائي. المحاولات الحساسة تعيد الحالة المحفوظة ولا تضيف حدثًا ماليًا ثانيًا.

## Export/Import المحلي

ينشئ التصدير ملف JSON محليًا بالصيغة `micro-prototype-local-export` مع `version` و`schemaVersion` ووقت التصدير وSnapshot للملف والتفضيلات والمسودات والطلبات وSnapshots والأحداث. لا يحتوي أسرارًا أو مفاتيحًا، ولا يمثل Backup سحابيًا أو مزامنة.

عند الاستيراد، يقرأ التطبيق الملف دون كتابة، ثم يتحقق من الصيغة والإصدارات والتواريخ والحقول الأساسية للملف والمسودات وSnapshots والطلبات والأحداث وحالات Domain والمراجع بين المسودة والطلب. يعرض ملخصًا قبل التأكيد. بعد التأكيد فقط، ينفذ `replaceSnapshot` داخل transaction واحدة على مخازن الملف والتفضيلات والمسودات والطلبات. الملف التالف أو الناقص أو غير المدعوم لا يلمس البيانات الحالية.

تغطي الاختبارات round-trip لطلب حقيقي وSnapshot وحدث، وملفًا تالفًا أو جزئيًا أو غير مدعوم، واستبدال IndexedDB لسجلات موجودة، واستمرار تفضيل المظهر بعد إعادة فتح Adapter.

## حدود لا تتغير

لا توجد Cloud Sync أو Workspace أو Auth أو صلاحيات أو Service Worker أو PWA مكتمل. لا يوصف الحفظ بأنه نسخة سحابية أو Backup تلقائي. لا يوصف Prototype بأنه جاهز تجاريًا أو محاسبيًا عامًا قبل الاختبارات الحقلية.
