# WF-011 — ورقة التسجيل السريع (بيع/مصروف) + وصل التسجيل

**ورقة مملوكة لسطح SCR-057** (تُفتح من أزرار «سجّل بسرعة» في الرئيسية — قرار NAV-001؛ لا SCR مستقلًا لها في الجرد) · أيضاها: `QuickActionSheet` فوق أي سطح قشرة عند فتحها برمجيًا · القالب: TPL-D · المقاسات: 360×800 / 390×844 / 430×932 · **قائم بالكامل** — يرسم `QuickActionSheet.tsx` + `QuickSaleForm.tsx` + `QuickExpenseForm.tsx` عند BASE_SHA حرفيًا.

## (ب) نموذج المصروف (من زر «(¢) تسجيل مصروف» — بنية الورقة نفسها)

```
│ │ سجّل مصروفًا الآن                    [✕] │ │
│ │ مبلغ وبند اختياري — يتم التسجيل هنا فوق    │ │
│ │ شاشتك من دون انتقال.                      │ │
│ │  المبلغ المدفوع بالدينار الأردني            │ │
│ │  [ 12.50                         ] ←LTR │ │
│ │  البند (مطلوب)                             │ │ ← الحقل الإلزامي
│ │  [ خامة كريم                      ]       │ │   الوحيد هنا
│ │  تاريخ المصروف [16/09/2026]               │ │ ← EXE-007: قابل
│ │  مصدر الصرف (اختر واحدًا…)                 │ │   للتحرير
│ │  [الدرج — تغطية من رصيدها ▾]              │ │ ← متعدد المحافظ:
│ │  (خيار: الكاش غير الموزع)                 │ │   اختيار إلزامي صريح
│ │  (رقاقات: تغليف · خوام · توصيل …)         │ │ ← تصنيف اختياري
│ │  ▸ سينقص الكاش 12.50 د.أ من «الدرج» —     │ │ ← معاينة الأثر
│ │    مصروف مسجل لا يُعدّ ربحًا ولا يُخصم      │ │
│ │    من دين، وبلا حركة أمانة ولا سحب مالك.   │ │
│ │ [         سجّل المصروف          ]         │ │
│ │  رجوع إلى القائمة →                        │ │
```

**قواعد مصدر الصرف (FIN-003/FIN-005 — قائمة):** بلا محافظ → سطر حقيقة «لا محافظ معلنة بعد — سيُسجَّل المصروف من الكاش غير الموزع…»؛ محفظة واحدة → معيّنة مسبقًا بشكل مرئي؛ محافظ متعددة → نائب «اختر مصدر الصرف» معطّل يُلزم بالاختيار (لا تُذكر آخر محفظة).

> **تنبيه نسخ قائم (موثق للدمج):** وصف رأس ورقة المصروف يقول «مبلغ وبند اختياري» بينما حقل «البند» داخل النموذج موسوم «مطلوب» ومُنفَّذ برسالة `اكتب ما حدث قبل الحفظ؛ الوصف جزء من السجل المالي.` (EXE-007 — إلزامي في المدخلين). تناقض وصف/سلوك لحظي لا يمس الأثر المالي — يُرسم كما هو ويُحال لجولة توحيد النصوص (قرب F-06 عند الوكيل 4؛ **DEEPENS_EXISTING**).

## (ج) إغلاق بمدخل مكتوب (حماية المدخل — داخل الورقة نفسها)

```
│ │  في رقم مكتوب — تسجّله أو تتجاهله؟        │ │ ← alertdialog
│ │  الإغلاق الآن يفقد ما كتبته في هذه الورقة؛ │ │
│ │  لا يوجد حفظ تلقائي.                      │ │
```

## قائمة التحقق

- **العنوان:** «سجّل بيعًا الآن» / «سجّل مصروفًا الآن» / «ماذا تريد أن تسجّل؟» / «وصل التسجيل» — أربعة أوجه لطرح واحد، الورقة لا تغادر مكانها.
- **السياق/الملخص:** فعل عابر فوق شاشة الوقوف: البيع والمصروف يُسجَّلان هنا؛ الطلب والمسودة والعربون مسارات عميقة تُسلَّم للموجه ب`returnTo` محفوظًا.
- **CTA الأساسي:** «سجّل البيع» / «سجّل المصروف» (save، بعرض كامل أسفل الورقة؛ «جارٍ التسجيل…» معطّل أثناءه). في الوصل: «تم» (نقرة واحدة تغلق وتعيد للسطح الذي فتح الورقة).
- **الثانويات:** «رجوع إلى القائمة»؛ [✕] إغلاق (بسؤال التجاهل عند الوسخ)؛ في الوصل «افتح السجل» (secondary).
- **فوق الطية:** العنوان + الحقلان الأولان (البند/المبلغ) + رؤية زر الحفظ — بلا تمرير على 390؛ الورقة ترتفع مع الكيبورد ويبقى الزر مرئيًا (قاعدة TPL-D).
- **الحالات عند اختلافها عن القالب:** تحقق inline تحت الحقل داخل الورقة («أدخل مبلغ البيع بالأرقام 0–9.»، «البيع الآجل يقتضي تحصيلًا أقل من المبلغ الكامل.»، «اكتب اسم الزبون ليتجمع دينه في دفتر الناس.»)؛ خطأ الحفظ يبقي المدخلات كما كتبها المالك؛ بلا محافظ (بيع): حقل الوجهة يسقط كليًا؛ بلا محافظ (مصروف): سطر حقيقة FIN-005. **تنبيه جودة قائم:** محدد CSS لإخفاء القائمة عند فتح نموذج تالف في `index.css` (`.micro-sheet-actionsidden]`) — علة تنفيذ تُوثَّق لا قرار تصميم.
- **الرجوع:** زر الرجوع (Back) يغلق الورقة أولًا قبل الشاشة؛ بعد الحفظ لا انتقال — الوصل يغلق إلى السطح الأصلي (قاعدة عقد الورقة).
- **الرسائل والتأكيدات:** الوصل role=status؛ سؤال التجاهل alertdialog بخيارين مسميين (سجّله الآن / تجاهل ما كتبت) — لا إغلاق صامت؛ لا توست فوق الورقة.
- **ما خلف الإفصاح:** التكلفة (خلف select «هل تعرف تكلفته؟»)؛ حقلا الآجل (خلف «آجل»)؛ وجهة القبض تظهر عند وجود محافظ فقط؛ رقاقات التصنيف مشتقة من الاستعمال (قراءة فقط).
- **ملاحظات المقاسات:** **360×800:** الورقة بعرض الشاشة؛ الحقول عمود واحد؛ سطر المعاينة يلتف سطرين بلا قص. **390×844:** الأساس المرسوم. **430×932:** الورقة ≤640px ويبقى الغطاء مرئيًا على الجانبين (طبقة عابرة لا صفحة)؛ المقبض وزر الإغلاق داخل مساحة الإبهام.
