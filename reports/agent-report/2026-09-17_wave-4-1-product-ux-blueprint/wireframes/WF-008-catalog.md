## «سجّل بيع هذا المنتج» — العقد المرئي للجسر (مهم للدفعة ب)

```
نقرة [ سجّل بيع هذا المنتج ] على صف «كيك شوكولا» (المتاح فقط):
→ /direct-sales/new?product=<catalog-item-id>&returnTo=/catalog
   • المرجع مُعبأ مسبقًا في محرر البيع (اقتراح معلن قابل للتعديل —
     السعر الفعلي ما يُدخل ويُؤكد هناك، لا قيمة مفروضة)
   • بعد الحفظ يعود إلى الكتالوج (عقد 26 §2 قاعدة 4 — returnTo)
   • الموقوف للطلبات الجديدة: لا زر أصلًا (لا زر معطل يوهم بيعًا)
```

## محرر الافتراضيات المفتوح (داخل الصف — إفصاح قائم)

```
│  │ ▾ عدّل الافتراضيات                        │ │ ← فتح الإفصاح يعبّئ
│  │   سعر مقترح جديد [ 35.00 ]                │ │   قيم المرجع الحالية
│  │   تكلفة مقترحة جديدة [ 18.00 ]            │ │
│  │   [حفظ الاقتراحات]  [إلغاء التعديل]        │ │ ← save + secondary
│  │   ● خطأ: أدخل الاقتراحات بالأرقام 0–9 أو   │ │ ← نص القائم حرفيًا
│  │     اتركها فارغة بلا قيمة.                 │ │
```
الخروج من الصف باقتراحات مكتوبة غير محفوظة يفتح حارس التغييرات غير المحفوظة (TPL-E) — قائم في الصفحة كلها (`useUnsavedChangesGuard`).

## حالة الفراغ (لا مراجع بعد — النص القائم حرفيًا)

```
│  ── مراجعي · أعمال متكررة (0) ──────────      │
│  لا يوجد مرجع بعد. أضف فقط العمل الذي يتكرر.   │ ← بلا أزرار فراغ
│                                                │   إضافية — النموذج
│                                                │   أعلى الصفحة هو الفعل
```

## قائمة التحقق

- **العنوان:** overline «مرجع اختياري» + H1 «منتجاتي وخدماتي» (الاسم الموحد المعتمد) + جملة الحدود القائمة («لا يحدد مخزونًا ولا ربحًا نهائيًا»). ترويسة القشرة تعرض تسمية سياقية مقاربة — **انحراف مسجل F-04 عند الوكيل 4** (تسمية الترويسة «الكتالوج») يصحح مع هذا الاسم.
- **السياق/الملخص:** مرجع ما يتكرر: نموذج إنشاء بالاسم فقط في الوجه ← قائمة المراجع بأفعالها السياقية ← أقسام متقدمة مطوية (وحدات/قوالب/قراءات).
- **CTA الأساسي:** «أضف مرجعًا» (create — داخل نموذج الوجه)؛ إجراء الصفحة اليومي الأسرع «سجّل بيع هذا المنتج/هذه الخدمة» (create) زر سياقي داخل صف المرجع المتاح فقط.
- **الثانويات:** عدّل الافتراضيات (إفصاح داخل الصف)؛ الأقسام المطوية الثلاثة؛ الرجوع؛ (بعد النقل) رابط «افتح السياسات في المالية».
- **فوق الطية:** نموذج «ابدأ بالاسم فقط» كاملًا مع زر الإضافة (الإفصاحان داخل النموذج مطويان) + أول صف مرجع.
- **الحالات عند اختلافها عن القالب:** Empty أعلاه؛ Loading «جارٍ قراءة الفهرس المحلي…»؛ Success لافتات حرفية: «تم حفظ مرجع العمل محليًا. يمكنك إضافة القياس أو القالب لاحقًا، وليس ذلك مطلوبًا للحفظ.» / «تم حفظ الاقتراحات الجديدة؛ لا يتأثر أي بيع سابق بقيمه المسجّلة.» / «تم إيقاف المرجع للطلبات الجديدة مع بقاء تاريخه محفوظًا.»؛ المرجع بلا اقتراحات: يُحذف ذكر السعر/التكلفة من سطره (لا «0.00» ولا «—»)؛ الموقوف: الشارة في السطر وبلا زر بيع؛ قدرة الكتالوج متوقفة (SET-003): تُخفى مداخله من الرئيسية والعمل — السطح نفسه يبقى قابلًا للوصول المباشر بروابطه القائمة.
- **الرجوع:** [→ رجوع] إلى `returnPath` (returnTo القانوني — عقد 26)؛ البديل الكنوني اليوم `/tools` — **W4-DEC-IA-2 (موصى به: `/`)**: بعد تنظيف أدواتي (WF-009) لم يعد للكتالوج ذراع في أدواتي يبرر هذا البديل؛ التغيير تحديث موثق واحد لجدول عقد 26 §2.2 مع اختباره.
- **الرسائل والتأكيدات:** FeedbackNote role=status أسفل الصفحة (لافتات النصوص أعلاه)؛ حارس التغييرات غير المحفوظة للقوالب/الاقتراحات (TPL-E)؛ لا توست.
- **ما خلف الإفصاح:** وحدة منظمة؛ اقتراحات السعر والتكلفة (الأساس يُحفظ بالاسم والوحدة فقط)؛ عدّل الافتراضيات لكل صف؛ الوحدات والتحويلات؛ القوالب ومراجعاتها وحدودها؛ قراءة القرار وسياسات المرجع (العرض يبقى، الإدارة في المالية).
- **ملاحظات المقاسات:** **360×800:** نموذج الإنشاء عمودًا واحدًا (نوع المرجع فوق الاسم فوق الوحدة)؛ سطر المرجع الطويل (النوع + الوحدة + الحالة + السعر المقترح + التكلفة المقترحة) يلتف حتى 3 أسطر داخل الصف بلا قص؛ الأرقام معزولة LTR (35.00) لا تنكسر وسط النص العربي؛ زر «سجّل بيع هذا المنتج» بعرض كامل داخل الصف لا يخرج عن حافته. **390×844:** الأساس المرسوم. **430×932:** البطاقات والقوائم ≤640px؛ صف المرجع يظل عمودًا واحدًا (لا شبكة بطاقات 2×2 — كثافة القراءة أهم من الامتلاء)؛ مع فتح الكيبورد في نموذج الإنشاء يختفي الشريط ويبقى «أضف مرجعًا» مرئيًا (قاعدة القشرة §4 بند ١٨).
