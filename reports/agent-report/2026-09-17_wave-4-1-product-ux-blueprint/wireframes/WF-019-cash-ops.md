## (د) ضبط بسبب (SCR-027) — الفرق عن العدّ

نفس بنية TPL-B بلا شريك «معدود»: `H1 «اضبط كاش الدرج»` · overline «تصحيح محفوظ» · حد الحقيقة «الضبط ليس مبيعات ولا مصروفًا… سيغير رصيد المحفظة والكاش المسجل فقط، مع سبب وتاريخ» · الحقول: **اتجاه فرق الكاش** (الكاش أقل/أكثر من المسجل) → قيمة الفرق → تاريخ الضبط → **«لماذا ظهر الفرق؟» (سبب)** → بيان مختصر → «حفظ ضبط الكاش». الفرق الجوهري: العدّ يقارن ويقترح الفرق؛ الضبط يبدأ من سبب يعرفه المالك بلا عدّ.

```

│  تراجع عن هذا الأثر                            │ ← H1
│  سيبقى الأصل ظاهرًا، ويضاف أثر مقابل له بدل      │
│  الحذف أو التعديل الصامت.                        │
│  ▐ ↺ الأثر الذي سيتم التراجع عنه ▌               │
│  │  +45.00                                      │ ← المبلغ بحرفيه
│  │  16/09/2026 · عربون طلب «صندوق خشبي مخصص»    │
│  (تحذير ارتباط المصدر إن وجد: «هذا الأثر مرتبط    │ ← يفتح الطلب
│  │ بطلب له حالة…» + [افتح الطلب])                │   قبل التراجع
│  ┌── النموذج ──────────────────────────────┐ │
│  │ تاريخ التراجع [16/09/2026]               │ │
```

## قائمة التحقق (مشتركة للخمسة — الفروق أعلاه)

- **العنوان:** كل مسار H1 فعله: «حوّل كاشًا بين محافظك» / «وزّع الكاش غير الموزع» / «عدّ اللي في الدرج فعلًا» / «اضبط كاش {اسم}» / «تراجع عن هذا الأثر».
- **السياق/الملخص:** أفعال حوكمة الكاش الأربعة + العكس: نقل داخلي محايد، تخصيص صريح للعالق، مطابقة دورية، تصحيح بسبب، وإلغاء أثر موثق — لا واحد منها إيرادًا ولا مصروفًا (جملة الحد دائمة).
- **CTA الأساسي:** «حفظ التحويل» / «سجّل التوزيع» / «سجّل التسوية» / «حفظ ضبط الكاش» / «حفظ التراجع» — save لاصق إلا العكس **commit** (أثره يعيد كتابة السجل).
- **الثانويات:** إعادة محاولة القراءة عند الخطأ؛ [أضف محفظة] من بوابة التحويل؛ فتح الطلب من تحذير المصدر.
- **فوق الطية:** بطاقة الحقيقة/المتاح (المبلغ المتاح أو الفرق الحي) + أول حقلي نموذج — الفرق في العدّ يُرى قبل الحفظ.
- **الحالات عند اختلافها عن القالب:** «تحتاج محافظتين للتحويل»؛ «لا توجد محافظ بعد؛ أنشئ محفظة أولًا» (توزيع/عدّ)؛ «لم نجد محفظة الكاش»/«لم نجد أثر الكاش» + رجوع؛ رابط وجهة غير صالح في التوزيع (إشعار صادق + نائب إلزامي)؛ الرصيد السالب مفسر بسببه وفعله؛ إعادة التأكيد المستعملة (EXE-001).
- **الرجوع:** الخمسة إلى «محافظ الكاش» ب`returnTo` (البديل `/cash`)؛ حارس المدخلات غير المحفوظة في الجميع؛ النجاح يسقط الوسخ ويعود للمصدر (عدا التوزيع: يبقى للسلسلة المتتابعة).
- **الرسائل والتأكيدات:** أخطاء role=alert تحت النموذج («أدخل مبلغًا صحيحًا موجبًا بالأرقام 0–9.»، «اذكر سبب التراجع قبل الحفظ.»)؛ لا حوارات — كل المسارات موثقة التراجع من سجلاتها.
- **ما خلف الإفصاح:** لا شيء معمد — النماذج قصيرة عمدًا؛ الحقول المتقدمة غير موجودة بقرار (البساطة حاكمة).
- **ملاحظات المقاسات:** **360×800:** المنتقيات عمود واحد؛ الفرق الحي بالعدّ رقم LTR معزول؛ أزرار النتيجة بعرض كامل. **390×844:** الأساس المرسوم. **430×932:** النماذج ≤640px؛ المبلغ والسبب في النصف السفلي حيث الإبهام؛ بطاقة العكس لا تتمدد.
