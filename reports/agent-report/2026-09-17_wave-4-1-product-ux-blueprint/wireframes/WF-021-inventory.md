## ⚠ التمييز المحوري: الهدر ≠ الضبط (EXE-012 — AUD-NEW-06)

| | **هدر مادة** (`/waste`) | **ضبط جرد** (`/adjust`) |
|---|---|---|
| المعنى | **فقد أو تلف حقيقي** خرج من المخزون | **تصحيح رصيد معلوم** بعد جرد/مطابقة |
| سبب إلزامي | نعم — «مثال: تلف أثناء القص أو فرق جرد» | نعم — نفس الحقل بمعنى جرد |
| أثر الربح | سؤال مالك صريح: «هل تريد اعتباره خسارة تؤثر على نتيجة المشروع؟» — نعم = حدث خسارة غير نقدية | **محايد دائمًا** — «الضبط ليس هدرًا — تصحيح جرد بمعنى محايد لا يُسجَّل خسارة» |
| اتجاه الكمية | نقص فقط | زيادة أو نقص (اتجاه صريح) |
| قيمة | تُشتق من رصيد المادة | الزيادة: معلنة أو «غير معروفة بعد»؛ النقص: مشتقة |

**منطقتا الخطر داخل السطح (TPL-E متغير inline قائم):**
- **إيقاف المتابعة** (عقد ٢٨): بطاقة عواقب — الرصيد والقيمة وعدد الحركات معلنة + قائمة «تبقى الحركات محفوظة / تختفي من النماذج / تبقى المشتريات مرتبطة / إعادة التفعيل يعيدها «غير محدد بعد»» + «أوقف المتابعة» (destructive) مفصولًا عن «إلغاء».
- **أخرِج المتبقي** (القرار ٢٠): «سيُسجَّل **هدر** بكمية 2.5 وقيمته كاملة 46.20 د.أ — لا حذف ولا شطبًا بلا أثر. يصير مخزون المادة بعدها صفرًا صادقًا» + سبب إلزامي + «أكّد إخراج الهدر» (destructive). *هذا إجراء مالي موثق لا حذفًا.*

## (د) محرر الحركة الأحادي (SCR-034 `/inventory/movement/:type` — TPL-B)

عنوان H1 وoverline بالنوع حرفيًا: «استلم شراء مواد» / «استهلك مادة» / «سجل هدر مادة» / «اضبط كمية مادة» (overline «حركة محفوظة» دائمًا). الرجوع «المواد والمخزون». حد الحقيقة: consume = «الاستهلاك ليس تعديلًا صامتًا لسعر الطلب.» · adjust = «الضبط ليس هدرًا — تصحيح جرد بمعنى محايد لا يُسجَّل خسارة.» · غيرها = «الحركة توضح كمية وقيمة المادة، لا مصروفًا تشغيليًا تلقائيًا.» + «لا يمكن إخراج كمية أكبر من المتاحة.»

**الفرق بين الأنواع الأربعة فوق النموذج المشترك** (المادة/الكمية/التاريخ/البيان/معاينة «بعد الحفظ»/حفظ حركة المادة):

```
│ استلام (receipt):                              │
│  شراء المواد المرجعي [اختر شراء المواد… ▾]      │ ← جسر ?purchase=
│  حالة الاستلام: قيمة مستلمة: 27.00 من 62.00 د.أ  │   من صفحة الشراء؛
│  · كمية مستلمة: 1.5 من 3 متر                    │   بطاقة حالة حية
│  هل تعرف قيمة هذا الاستلام؟ (•) نعم، معلومة      │
│  [قيمة الجزء المستلم 27.00] ( ) لا، غير معروفة   │ ← «قيمة صفرية
│  بعد — «تُسجَّل قيمة صفرية موسومة «غير معروفة»    │   موسومة» لا مجانية
│  — لا مجانية مفترضة»                             │   مفترضة
```

## قائمة التحقق

- **العنوان:** «المواد والمخزون» / «أي مادة تسجّل؟» / «أكّد رصيد {اسم}» / عناوين الحركة الأربعة الحرفية / «تراجع عن حركة المادة» — H1 وحده بلا منافس؛ ترويسة القائمة تحذف تسميتها (تطابق H1).
- **السياق/الملخص:** تفعيل صريح (لقطة رصيد تكفي) ← مواد بحقائقها (رصيد/قيمة/جهل معلن/نواقص) ← حركات بأربع نوايا منفصلة المعنى (استلام/استهلاك/هدر/ضبط) ← تراجع موثق. الهدر فقد/تلف قد يصير خسارة بقرار صريح؛ الضبط تصحيح محايد أبدًا.
- **CTA الأساسي:** «مادة جديدة» (create — الزر الدائم الوحيد في القائمة)؛ «حفظ المادة (ورصيد البداية)» / «أكّد الرصيد» / «حفظ حركة المادة» / «حفظ التراجع» في المحررات (الأخير commit).
- **الثانويات:** استلام/استهلاك/هدر/ضبط (مشروطة بوجود مواد بنمط «لاحقًا»)؛ بانتظار الاستلام (رحلة تفتح الاستلام محضرة)؛ أكّد الرصيد/أخرِج المتبقي/أوقف المتابعة/فعّل المتابعة بحسب حالة الصف؛ سجّل الحل للنقص؛ تراجع حركة؛ حل النقص بخيارين عند التجاوز.
- **فوق الطية:** حالة التفعيل (أو بطاقة الحقيقة بعده) + زر «مادة جديدة» + أول مادتين — النواقص والإخراج تحت الصف لا فوق الطية.
- **الحالات عند اختلافها عن القالب:** Loading «جارٍ قراءة المواد المحلية…»؛ Error «تعذر قراءة المواد — لم يتغير أي سجل. أعد فتح التطبيق للمحاولة.»؛ فراغ المواد الحرفي؛ نمط «لاحقًا» للأفعال المشروطة؛ «غير محدد بعد» و«التكلفة غير معروفة» و«صفر مؤكد» كلمات لا أرقامًا؛ الكمية غير المعروفة «—»؛ الحركة المرتدة تُوسم ويختفي زر تراجعها؛ محرر الحركة بلا مواد: صفحة «لا مواد متتبَّعة بعد» + CTA مادة جديدة (لا نموذج فارغ)؛ فشل الربط (linkIssue) رسالة role=status أعلى النموذج.
- **الرجوع:** القائمة → returnPath (البديل الأعلى /inventory — مفتوحة من العمل والمالية)؛ المحررات الخمسة → «المواد والمخزون» بحارس المسودة (UnsavedChangesGuard)؛ التراجع الناجح يقفل إلى /inventory.
- **الرسائل وموضعها:** FeedbackNote أعلى القائمة (تفعيل/إخراج/إيقاف/حل)؛ أخطاء المحررات داخل النموذج role=status/alert فوق زر الحفظ؛ مناطق الخطر inline تحت الصف المعني لا حوارات وسط الشاشة (نمط قائم موثق في TPL-E).
- **ما خلف الإفصاح:** نقص كل مادة (details داخل الصف)؛ حركات غير المكتملة (شروط الانتقال)؛ في المحررات: قيمة الاستلام/الزيادة خلف سؤال نعم/لا؛ سياق الهدر خلف subsection مستقلة.
- **ملاحظات المقاسات:** **360×800:** أزرار الحركات الأربعة تلتف صفّين؛ صف المادة عمودًا واحدًا (الرصيد يسار الصف بخط الأرقام)؛ لوحة النقص بعرض كامل. **390×844:** الأساس المرسوم. **430×932:** الصفوف ≤640px؛ معاينة الأثر منطقة ارتفاع محجوزة لا تقفز (آخر كتلة قبل الحفظ)؛ أزرار الخطر مفصولة عموديًا.
