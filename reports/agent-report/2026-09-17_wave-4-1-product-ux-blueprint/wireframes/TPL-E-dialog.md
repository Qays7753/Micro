# TPL-E — حوار تأكيد/رسالة (Dialog)

**يستخدم لـ:** حوار التغييرات غير المحفوظة (UnsavedChangesGuard)، تأكيدات التدمير الموثقة (حذف تقدير، تصفير البيانات، إخراج متبقٍ كهدر، إيقاف متابعة مادة)، حوار بوابة رمز القفل (DataActionPinGate)، وحوارات الرسالة الواحدة (إشعار حماية مطلوب). كلها قائمة في الكود عند BASE_SHA.

## الهيكل العام (390×844 — بطاقة وسط الشاشة فوق غطاء)

```
┌──────────────────────────────────────────────┐
│██████████████████████████████████████████████│
│████████ (السطح/المحرر خلفها معتم 45%) ██████│
│██████████████████████████████████████████████│
│        ┌──────────────────────────────┐      │
│        │  عندك تغييرات ما اتحفظت      │      │ ← عنوان 20px/700
│        │  خرجك الآن يترك حقل الوصف    │      │ ← جسم 15px ثانوي
│        │  فارغًا ولا يُسجَّل شيء.       │      │
│        │                              │      │
│        │ [ ابقَ وكمّل الكتابة ]        │      │ ← الأقل تدميرًا أولًا
│        │                              │      │
│        │ [ اخرج واحذف المدخل ]        │      │ ← التدميري مفصول
│        └──────────────────────────────┘      │
│██████████████████████████████████████████████│
└──────────────────────────────────────────────┘
```

## القواعد الملزمة

1. **البطاقة:** عرض `min(100% − 32px, 420px)` موسّطة، radius بطاقة 16px، فوق غطاء دافئ 45%. لا حوار بعرض الشاشة كاملًا.
2. **ترتيب الأزرار:** الفعل الأقل تدميرًا أولًا (يمين في RTL)؛ التدميري مفصول بمسافة 16px وبلون حبر الخطأ إن كان حذفًا/تصفيرًا. لا زر محايد بلا اسم.
3. **التركيز محصور:** ينتقل إلى الحوار عند الفتح ويعود للمشغّل عند الإغلاق؛ `role=dialog/alertdialog` + `aria-modal`.
4. **تسمية الشيء باسمه:** تأكيد الحذف يذكر اسم السجل («احذف «تقدير صندوق العروس» نهائيًا؟ لا يمكن التراجع») لا «هل أنت متأكد؟» الفارغة.
5. **التدمير المزدوج:** الأفعال غير القابلة للتراجع (تصفير البيانات، الاستبدال النهائي) تتطلب رمز القفل أو إدخال اسم المشروع — لا نقرة واحدة عابرة.
6. **حوار واحد في اللحظة:** لا تركيب حوارات؛ التوست لا يظهر فوق الحوار (z-ladder: الحوار 60، التوست 70 لكن لا يُطلق توست أثناء حوار مفتوح).
7. **الرسالة بلا فعل:** إشعارات «اقرأ فقط» (مثل إشعار تفعيل الحماية قبل الاستبدال) زر وحيد مسمى («حسنًا») يعيد التركيز للمشغّل.

## قائمة فحص الحالات

| الحالة | الشكل |
|---|---|
| Unsaved-guard | «ابقَ وكمّل الكتابة / اخرج واحذف المدخل» — البقاء أولًا |
| Destructive confirm | اسم السجل + «لا يمكن التراجع» + زر حبر خطأ مفصول |
| Typed confirm | حقل إدخال اسم المشروع يفعّل زر التنفيذ فقط عند التطابق |
| PIN gate | لوحة رمز القفل (DataActionPinGate) بعنوان وصف مخصص للفعل + إلغاء يعيد بلا أثر |
| Message-only | إشعار بحقيقة واحدة («هذا الإجراء يحتاج الحماية بالرمز أولًا…») + «حسنًا» |
| Saving داخل الحوار | لا يغلق الحوار قبل اكتمال الفعل؛ زره معطل |

## قواعد المقاسات الثلاثة

- **360×800:** البطاقة `100% − 32px`؛ الأزرار عمودين إن طال الاسم.
- **390×844:** الأساس — أزرار بعرض كامل متراصة عموديًا للوضوح.
- **430×932:** تبقى ≤420px موسّطة — الحوار لا يكبر مع الشاشة؛ الغطاء يملأ الفراغ.

## جدول: أي SCR يستخدم هذا القالب وما الفروق

| SCR (مصدر الظهور) | الحوار | الفروق |
|---|---|---|
| SCR-008 / SCR-014 / SCR-015 / SCR-001 (كل محرر عميق) | تغييرات غير محفوظة | نص الحارس يتكيف: «حقل الوصف فارغ»/«لم يُسجّل شيء»؛ يشمل محاولة الرجوع بالسهم |
| SCR-037 (أدواتي) | حذف تقدير | تأكيد ثانٍ مسمّى داخل الصف («احذف «كيك طبقتين» نهائيًا؟ … تراجع») — النمط القائم inline وليس بطاقة وسط الشاشة؛ يوثق كمتغير مقبول |
| SCR-035 (المخزون) | إيقاف متابعة / إخراج متبقٍ كهدر | تسمية الكمية والوحدة في نص الحوار + معاينة الأثر |
| SCR-055 (الإعدادات) | بوابات PIN للتصدير/الاستيراد/التصفير + تأكيد اسم المشروع للتصفير | الأشد تدميرًا: رمز مرة بالجلسة ثم إدخال اسم؛ الاستبدال محجوب قبل تفعيل القفل |
| SCR-055 (الإعدادات) | إشعار «الاستبدال يحتاج الحماية أولًا» | رسالة بلا فعل — زر «حسنًا» وحيد |
| SCR-049/SCR-014 (عكس/تراجع) | تأكيد العكس الموثق | سبب إلزامي + معاينة الأثر المحسوب قبل التنفيذ |
| (لا SCR) | لوحات «قريبًا» | **ليست حوارًا** — لوحة غير مُحجزة تحت الترويسة (aria-modal=false)؛ نمطها في WF-002 |
