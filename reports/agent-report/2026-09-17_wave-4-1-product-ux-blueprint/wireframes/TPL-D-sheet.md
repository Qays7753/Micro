# TPL-D — ورقة سفلية عابرة (Bottom Sheet)

**يستخدم لـ:** ورقة «التسجيل السريع» (بيع/مصروف) فوق أي سطح من سياق القشرة (`quickRecording` — قرار NAV-001)، وأي قرار لحظي قصير لا يستحق مسارًا كاملًا.
**القاعدة الحاكمة:** الورقة للفعل العابر فقط — إذا طال القرار تتحول الرحلة إلى مسار كامل (TPL-B).

## الهيكل العام (390×844 — الورقة فوق سطح معتم)

```
┌──────────────────────────────────────────────┐
│████████████ غطاء scrim دافئ █████████████████│
│████████████ (السطح خلفها باقٍ) ██████████████│
│ ┌──────────────────────────────────────────┐ │
│ │                  ▬▬▬ (مقبض 36×4)         │ │ ← radius علوي 20px
│ │ سجّل بيعًا                            [✕] │ │ ← عنوان 20px + إغلاق 44px
│ │ فعل واحد سريع فوق شاشتك الحالية            │ │ ← وصف 13px
│ ├──────────────────────────────────────────┤ │
│ │  ما بِيع؟                                  │ │
│ │  [ كيك شوكولا                    ]        │ │ ← حقول 48px
│ │  كم المبلغ؟ (د.أ)                          │ │
│ │  [ 35.00                         ]        │ │
│ │  ▸ تفاصيل اختيارية (زبون/طريقة قبض)        │ │ ← كشف تدريجي
│ ├──────────────────────────────────────────┤ │
│ │ [        احفظ البيع             ]         │ │ ← بعرض كامل أسفل الورقة
│ └──────────────── safe-area-bottom ────────┘ │
└──────────────────────────────────────────────┘
بعد الحفظ — وصل التسجيل (نفس الورقة):
│ │ ✓ سُجّل بيع كيك شوكولا بـ 35.00 د.أ        │ │
│ │   الكاش المسجل الآن: 245.00 د.أ            │ │
│ │ [        تم — أكمل يومك          ]         │ │ ← نقرة واحدة تغلق
```

## القواعد الملزمة

1. **عقد الورقة:** `role=dialog`، عنوان وصفي، التركيز ينتقل إليها ويعود للمشغّل، زر الرجوع يغلق الورقة أولًا قبل الشاشة، زر إغلاق 44×44 في سطر العنوان، تمرير داخلي مستقل.
2. **الإخفاء بالحالة:** عند فتح نموذج داخل الورقة تُخفى قائمة الأفعال (سمة `hidden`) — **تنبيه قائم:** محدد CSS المسؤول تالف في `index.css` (`.micro-sheet-actionsidden]`) — يوثق كعلة تنفيذ لا كقرار تصميم (INFERRED من الكود؛ انظر تقارير نظام التصميم).
3. **إغلاق بمدخل مكتوب:** لا إغلاق صمت — صناديق خيارين صريحين «أكمل الكتابة / تجاهل ما كتبت» داخل الورقة (نمط القائم).
4. **الارتفاع:** لا يدفن الفعل الأساسي خلف الشريط السفلي؛ الورقة تعلو الشريط أو تحجبه بغطائها.
5. **وصل التسجيل (Receipt):** بعد الحفظ يظهر «ما سُجّل + الكاش المسجل الآن» — نقرة واحدة تغلق وتعيد للسطح الأصلي؛ لا قفزة لصفحة أخرى.
6. **الكيبورد:** الورقة ترتفع مع لوحة المفاتيح؛ زر الحفظ بعرض كامل أسفل الورقة يبقى مرئيًا (قاعدة القشرة: الكروم يختفي مع الكيبورد والمحتوى لا يختفي).

## قائمة فحص الحالات

| الحالة | الشكل |
|---|---|
| Menu (لو دُعم مستقبلًا) | قائمة أفعال 64px للصف |
| Form | نموذج لحظي بحقول قليلة + حفظ |
| Validation | خطأ inline تحت الحقل داخل الورقة |
| Saving | الزر معطل + «جارٍ الحفظ…» |
| Receipt | وصل: العنوان + المبلغ + الكاش الآن + إغلاق |
| Discard-guard | «أكمل الكتابة / تجاهل ما كتبت» |
| Error حفظ | رسالة صريحة داخل الورقة + بقاء المدخلات كما كتبها المالك |

## قواعد المقاسات الثلاثة

- **360×800:** الورقة بعرض الشاشة كاملًا؛ الحقول عمود واحد.
- **390×844:** الأساس (عرض الورقة ≤640px كحد أقصى).
- **430×932:** لا تتوسع عن 640px — يبقى الغطاء مرئيًا على الجانبين فيؤكد أنها طبقة عابرة لا صفحة.

## جدول: أي SCR يستخدم هذا القالب وما الفروق

| SCR | الشاشة/السياق | الفروق |
|---|---|---|
| SCR-057 (ورقة فوقها) | البيع السريع `sale-form` | حقول: البند/المبلغ/طريقة القبض؛ الدين الناتج يفتح لوحة قرار الفرق داخل الورقة نفسها («الفرق دَين على العميل؟») |
| SCR-057 (ورقة فوقها) | المصروف السريع `expense-form` | حقول: البند/المبلغ/مصدر الدفع؛ «غير الموزع» يظهر أثره في المالية لا هنا |
| — | قرارات لحظية قصيرة | اختيار وجهة سريع/تأكيد إغلاق — أي محتوى أطول يتحول لمسار كامل (قاعدة 4) |
| (لا SCR) | لوحات الترويسة «قريبًا» | **ليست ورقة سفلية** — لوحة تحت الترويسة بلا مقبض؛ تُوثق في WF-002 |
