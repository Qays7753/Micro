# TPL-C — صفحة تفاصيل (Detail Surface)

**يستخدم لـ:** تفاصيل سجل قائم يُقرأ ويُصحح: تفاصيل الطلب، تفاصيل البيع المباشر (وضع التصحيح)، دفتر المحفظة، مال المالك (دفتر)، تفاصيل القرض، تفاصيل الأصل، صفحة التقدير.

## القواعد الملزمة

1. **الشريط السفلي:** يبقى للقارئ (OrderDetail وأمثاله) ويختفي إذا تحول التفصيل إلى محرر تصحيح (U-005: القارئ سطح، المصحح عمق).
2. **الملخص قبل السجل:** بطاقة واحدة برقم أساسي واحد (المتبقي/الدفتري/القائم) + مؤهل صادق؛ الأرقام الثانوية سطور لا بطاقات متنافسة.
3. **الفعل التالي واحد:** لوحة واضحة (جملة الحالة + زر) تشير للخطوة التالية في السلسلة («سجّل التسليم»/«سجّل سدادًا») — من خريطة الحالة نفسها التي تعرضها القائمة فلا تضارب بين القائمة والتفصيل.
4. **الخط الزمني:** صف لكل حدث بتاريخ DD/MM/YYYY واسم الحدث والأثر؛ كل تصحيح يظهر بما هو (عكس/تراجع موثق) — **الحذف ليس مسارًا**.
5. **التصحيح:** من «صحّح» إلى محرر عميق (TPL-B) يحرس المسودة؛ العكس/التراجع قسم صريح بسبب إلزامي ومعاينة أثر قبل التنفيذ.
6. **المشاركة (عقد 33):** زر «شارك» النصي يظهر فقط حيث يوجد نص جاهز قانوني (طلب، قبضة قائمة، كشف) ويفتح SCR-052. لا مشاركة لمسودة ميتة ولا لطلب ملغى «جاهز للمتابعة».

## قائمة فحص الحالات

| الحالة | الشكل |
|---|---|
| Loading | لوحة well |
| Not found | «لم نجد هذا السجل/المسودة» + رجوع للمصدر — لا صفحة بيضاء |
| Error | بطاقة خطأ + إعادة محاولة |
| Correction pending | قسم العكس مفتوح مع معاينة الأثر ومفتاح تأكيد مستقل |
| Cancelled (سجلات قابلة للإلغاء) | شارة «ملغى — سبب مسجل»؛ لا أفعال متابعة توهم نشاطًا |

## قواعد المقاسات الثلاثة

- **360×800:** الملخص عمودًا واحدًا؛ الرقم الكبير قد ينزل لسطر مستقل دون قص.
- **390×844:** الأساس.
- **430×932:** السجل يتنفس (صفوف أطول) بلا أعمدة إضافية — القراءة تظل سطرًا زمنيًا واحدًا ≤640px.

## جدول: أي SCR يستخدم هذا القالب وما الفروق

| SCR | الشاشة | الفروق عن الأساس |
|---|---|---|
| SCR-010 | تفاصيل الطلب | أغنى تفصيل: ملخص الاتفاق + عربونات + سلسلة حالة (قيد التنفيذ/جاهز للتسليم/تم التسليم/مغلق) + «شارك مع العميل» (منتجه الوحيد لـSCR-052) |
| SCR-005 | تفاصيل/تصحيح بيع مباشر | زر التصحيح يحوّل للوضع العميق (يخفي الشريط)؛ الربح خلف إفصاح لأنه مشروط بالتكلفة |
| SCR-022 | دفتر المحفظة | الرقم الأساسي = الرصيد المعلن؛ الفعل السياقي المقترح «وزّع على هذه المحفظة» (منتج `destinationWalletId` المرئي — توصية الوكيل 1 T7) |
| SCR-016 | مال المالك (الدفتر الموحد) | رقمان مفصولان (رأس المال/الحق المتبقي) بدل رقم واحد؛ فاعلا الإدخال والسحب داخله |
| SCR-046 | تفاصيل قرض | الخط الزمني = دفعات سداد؛ الرقم الأساسي = المتبقي القائم |
| SCR-043 | تفاصيل أصل | مؤهل «دفتري» صريح (الإهلاك غير نقدي لا يمس الصندوق) |
| SCR-040 | قراءة تقدير | «تقديري» مؤهل دائم؛ الفعل الأساسي «ابدأ مسودة من هذا التقدير» (نسخ قيم لا إنشاء مال) |
| SCR-030 | ورقة التحصيل (نتيجتها) | متغير إيصال: ما حُصّل اليوم + إشعار القبض القابل للمشاركة (عقد 33) |
