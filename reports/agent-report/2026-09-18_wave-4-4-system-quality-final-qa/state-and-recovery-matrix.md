# P-4.4-4 — مصفوفة الحالات والاسترداد

التاريخ: 2026-09-18 · الفرع: `feat/wave-4-4-4-states-recovery` · النطاق: جميع المسارات

## 1. العقد الموحد للحالات

| الحالة | القاعدة المطبقة | التحقق |
| --- | --- | --- |
| **Loading** | نص حالة معلن `role="status"` («جارٍ قراءة…») — لا أصفار قبل اكتمال القراءة، ولا إجراء يعتمد على بيانات لم تُحمّل؛ تحديث خلفي بلا وميض (stale-while-revalidate في الرئيسية) | اختبار DOM حي (Assets بقراءة بطيئة): لا فراغ فارغ بلا إعلان |
| **Empty** | مكوّن `EmptyState` بعقده الموثق: رمز هادئ + عنوان موجّه + شرح + فعل واحد («سجّل أول…») — «لا بيانات» ليس فشلًا | عقود W2 القائمة + مصفوفة §2 |
| **Partial** | درجات المعرفة المعلنة (مسجل/ناقص/يحتاج مراجعة/تقديري) — لا صفر مقابل مجهول أبدًا | عقد P-4.4-2 (المجهول ≠ صفر) |
| **Error** | `role="alert"` + رسالة تسمّي ما فشل + «لم يتغير أي سجل» (لا حفظ جزئي) + فعل تعافٍ في المكان | فحص مصدر ثابت على 27 صفحة قراءة |
| **Retry** | زر «إعادة المحاولة» في شاشة الخطأ يعيد القراءة في مكانها (أضيف في هذه الحزمة لكل صفحات القراءة) | اختبار DOM حي: فشل عابر → Retry → تعافٍ |
| **Success** | نجاح موثق بعد الحفظ المثبت فقط («سُجّل الاتفاق بنجاح…»، «سُجّل التوزيع ✓») — النموذج لا يغلق عند الفشل والمدخلات لا تُمسح | عقود ORD-001/F08 القائمة + UnsavedChangesGuard.saveFailure |
| **Disabled/Saving** | أزرار الحفظ معطلة أثناء التنفيذ (`disabled={saving/isActing}`) — لا إرسال مزدوج ولا حدث مكرر (مفاتيح الحتمية) | فحص مصدر ثابت على النماذج الحرجة + عقود Idempotency |
| **Offline** | التطبيق محلي أولًا: القراءات والكتابات تعمل بلا شبكة؛ المشاركة/النسخ لها مسارات بديلة صادقة | §3 |

## 3. تغطية سيناريوهات الاسترداد

| السيناريو | المعالجة | التحقق القائم/الجديد |
| --- | --- | --- |
| Retry في المكان | زر «إعادة المحاولة» بكل صفحات القراءة (أضيف لـ٢٠ سطحًا في هذه الحزمة؛ ٧ كانت تملكه + Home/Profile بإعادة تحميل + OrderDetail/Schedule بإعادة القراءة) | `StateRecovery.w44` (DOM حي) |
| Back | كل شاشة خطأ تحتفظ بزر عودة لسطح أمه بمسار رجوع محفوظ | عقود التنقل القائمة |
| إغلاق وفتح | حالة التطبيق محلية persistent (IndexedDB) — إعادة الفتح تعيد القراءة | عقود التخزين القائمة |
| Refresh | Home/Profile عبر `window.location.reload()`؛ البقية إعادة قراءة في المكان | فحص المصدر الثابت |
| Offline → Online | لا شبكة في المسار المالي أصلًا (محلي أولًا)؛ service worker يقدم shell دون اتصال | عقود PWA القائمة + P-4.4-6 |
| فشل حفظ | النموذج لا يغلق والمدخلات تبقى + رسالة تسمّي الفشل | `UnsavedChangesGuard.saveFailure.dom` |
| فشل مشاركة | مسار بديل صادق (تنزيل/نسخ)؛ إلغاء المستخدم ليس خطأ | `StateRecovery.w44` (اختباران) |
| فشل Clipboard | catch مع «تعذر النسخ… بقيت بياناتك كما هي» | Settings (فحص قائم) |
| استيراد غير صالح | بوابة استيراد كاملة التغطية برسائل رفض مسماة | عقود الموجة 2 |
| استعادة فاشلة | نسخة احتياطية قبل الاستعادة + حكم فحص السلامة بعدها (PASS/WARN/UNAVAILABLE/FAIL) | عقود الموجة 2 + TOOL-001 |
| PIN غير صحيح | عدّاد محاولات + تراجع تصاعدي معلن بالثواني | `AppLockGate`/`DataActionPinGate` |
| بيانات جزئية | درجات معرفة معلنة لا أصفار مضللة | عقد P-4.4-2 |
| عملية منفذة سابقًا | مفاتيح الحتمية لكل عملية مالية (`reused` صادقة) | عقود Idempotency القائمة |

## 4. تغييرات هذه الحزمة

1. **زر «إعادة المحاولة» في ٢٠ سطحًا** لم يكن يملكه (كل صفحات القراءة بلا
   استثناء الآن تقدم فعل تعافٍ في المكان): عدّاد `retryCount` في تبعيات
   قراءة السطح للأثر المحدود، أو `load()` المباشر حيث كان موجودًا.
2. **تصحيح نصوص**: «أعد فتح التطبيق للمحاولة» حُذفت حيث صار للزر معنى
   مباشر («إعادة المحاولة» في المكان) — بلا حاجة لإغلاق التطبيق.
3. **اختبارات** `StateRecovery.w44.dom.test.tsx` (6): تعافٍ حي من فشل عابر،
   تحميل معلن بلا أصفار، فحص مصدر ثابت لمصفوفة الحالات على 27 صفحة قراءة،
   حماية الإرسال المزدوج في النماذج الحرجة، ومسارا فشل المشاركة.
4. **سقوف §10.1**: +1 موثق على 10 أسطح (فعل «إعادة المحاولة» المعتمد).

لا تغيير في أي Writer أو Store أو عقد مالي — كل التغييرات عرض واسترداد.
