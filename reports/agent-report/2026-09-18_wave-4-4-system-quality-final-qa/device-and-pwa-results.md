## 3. المتصفحات

- **Chromium mobile:** مغطى بالكامل (كل الفحوص أعلاه).
- **WebKit/Safari:** **غير متاح في البيئة** (`playwright webkit` غير مثبت؛ لا يوجد executable) → موثّق كغير مُختبر — انظر «ما لم يُختبر» في `report.md`.
- **Desktop keyboard navigation:** مغطى (1280×800): تسلسل Tab منطقي، قائمة الشعار Enter/Tab/Escape مع إعادة التركيز، لوحتا «قريبًا» بحوار صحيح (التركيز يدخل، Escape يغلق ويعيد التركيز للمشغّل).

## 4. الأجهزة الفعلية

```text
REAL_DEVICE_QA_NOT_PERFORMED
```

لا يتوفر جهاز Android/iOS فعلي أو خدمة أجهزة آمنة في هذه البيئة. لم تُختبر: إيماءات اللمس الأصلية، الكاميرا، `navigator.share` الأصلي للنظام خارج المحاكي، لوحة المفاتيح الأصلية، تثبيت PWA من متجر/شاشة رئيسية فعلية، والأداء على عتاد منخفض.

## 5. PWA (بناء الإنتاج مخدومًا محليًا)

| الفحص | النتيجة |
|---|---|
| `manifest.webmanifest` مخدوم | نعم — name/short_name عربية، `display: standalone`، `dir: rtl`، `lang: ar`، `start_url: /`، `scope: /` |
| الأيقونات | 192/512 any + 512 maskable بمقصد صريح — لا letterbox |
| theme-color | وسمان بمخطط `prefers-color-scheme` (فاتح `#faf9f5` / ليلي `#211d18`) |
| Service Worker | مولّد (workbox، 173 أصلًا مُخزنًا مسبقًا 2338 KiB) — مسجّل `activated` ويسيطر |
| Offline shell | التنقل offline يعمل عبر `navigateFallback` — التطبيق يُحمّل كاملًا مع حالة «أنت غير متصل الآن» الصادقة |
| سلوك التحديث | `registerType: prompt` — «التحديث ينتظر موافقتك؛ لن نعيد تحميل الصفحة أو نستبدل النسخة أثناء عملك دون اختيارك» — تحديث بموافقة صريحة |
| التثبيت | لوحة `beforeinstallprompt` مع «تثبيت Micro» و«ليس الآن» وإخفاء 30 يومًا موثق |
| الروابط العميقة | فتح بارد على `/assets/:id` يعيد نفس الشاشة بعد reload؛ offline على أصل بلا بيانات يفتح بوابة البداية بصدق (لا بيانات → الإعداد) |
| الرجوع | `history.back()` يعمل من الشاشات العميقة |
| هوامش الأمان | `viewport-fit=cover` + `env(safe-area-inset-*)` في الكروم العلوي (16 استخدامًا) والسفلي — لا محتوى خلف شريط النظام |
| كلود/مزامنة | غير موجودة إطلاقًا — لا Auth ولا Sync ولا نداءات شبكة (خطوط مستضافة محليًا) |
