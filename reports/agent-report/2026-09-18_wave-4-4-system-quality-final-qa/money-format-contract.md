# P-4.4-2 — عقد تنسيق المبالغ

التاريخ: 2026-09-18 · الحالة: معتمد ومنفذ ومختبر

## 1. الصيغة المعتمدة

```text
25.00 د.أ
1,234.50 د.أ
-15.25 د.أ
```

| القاعدة | التطبيق |
| --- | --- |
| منزلتان عشريتان في العرض دائمًا | `formatMoneyMinor` (`Intl.NumberFormat` en-US, min=max=2) |
| لا خلط `25` / `25.0` / `25.00` | منسّق واحد بمفتاح واحد — لا مسار عرض آخر |
| تجميع الآلاف بفاصلة | `1,234.56` |
| الوحدة `د.أ` بمسافة بعد الرقم | `formatMoneyWithUnit` / `MoneyWithUnit` — الوحدة خارج العزل الاتجاهي للرقم |
| أرقام ASCII إنجليزية `0-9` | لا أرقام هندية في أي مخرج مالي |
| الإشارة السالبة ملاصقة داخل جدار LTR | `MoneyValue` — `-15.25` لا تنفصل في سياق RTL |
| إشارة موجبة اختيارية للسياق | `showPlus` → `+5.00` (للإيداع/التسوية، لا للصفر ولا للفراغ) |

## 2. فصل حالات القيمة — المجهول ليس صفرًا

| الحالة | التمثيل الداخلي | العرض |
| --- | --- | --- |
| صفر حقيقي (رصيد معدوم محسوب) | `0` | `0.00 د.أ` |
| غير مسجل (لا سجل أصلًا) | `null` | `—` |
| غير معروف (قراءة فشلت/غير منتهية) | `undefined` / فشل القراءة | `—` أو لغة الحالة الصريحة للسطح |
| قيمة غير صالحة | `NaN` / `Infinity` | `—` |

لا يمر أي مسار عرض قيمة مجهولة عبر `?? 0` أو `|| 0` قبل المنسّق — المنسّق
نفسه يفرّق (`formatMoneyMinor(null) === "—"` و`formatMoneyMinor(0) === "0.00"`).
السالب والموجب لا يميّزان باللون وحده: `data-negative` على `MoneyValue` + كلمة
الأثر/الاتجاه النصية في سياق السطر.

## 3. عدم تغيير القيم المخزنة

- العرض دالة صرفة على Minor Units الصحيحة: `minor → minor/100 → منزلتان`.
  لا تُحوَّل الوحدة الداخلية ولا يُبدَّل تمثيل التخزين.
- لا تقريب وسيط: كل المعادلات المالية تعمل على Minor صحيحة في النطاق؛
  التقريب الوحيد هو تمثيل العرض النهائي بمنزلتين، ولا يُعاد تغذيته للحساب.
- دورة الاسترجاع مثبتة اختباريًا: `formatMoneyMinor(minor)` → إعادة تحليل →
  `Math.round(x*100) === minor` لكل فئة القيم الواقعية (0، 1، 5، 9، 10، 99،
  100، 199، 1234، 99999، 123456789، -1525).
- الإدخال المالي (مسار الكتابة) يبقى على عقد `englishNumeric.ts` المستقل
  (أرقام إنجليزية، إزاحة عشرية آمنة بلا فواصل عائمة وسيطة) — العرض لا يتسرب
  إلى الإدخال ولا العكس.

## 4. JOD على كل الأسطح

الوحدة `د.أ` واحدة من `formatMoneyWithUnit` في كل الأسطح المالية (المالية،
البيان، الطلبات، التحصيل، الموردون، القروض، الأصول، الكاش، مال المالك،
التصدير/المشاركة النصية). لا يوجد مسار يبني `د.أ` بمنسّق محلي موازٍ بعد الجرد
(§3 من `presentation-format-inventory.md`).

## 5. التغطية الاختبارية

`PresentationFormats.w44.dom.test.tsx` — «عقد المبالغ»: الصفر الحقيقي،
الموجب، السالب، الكبير (999,999,999.99)، الكسور (0.01)، المجهول (null/
undefined/NaN/Infinity → `—` لا `0.00`)، الوحدة مع المسافة، دورة الاسترجاع
بلا تقريب مزدوج، ونقاء الدالة (المدخل لا يتغير). و«مكوّنات العرض»:
`data-negative` بوصفها إشارة غير لونية، جدار LTR للرقم، `showPlus` بحدودها،
و`—` للفراغ.
