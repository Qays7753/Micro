# P-4.4-5 — تدقيق الوصول ولوحة المفاتيح وZoom وReflow

التاريخ: 2026-09-18 · الفرع: `feat/wave-4-4-5-accessibility` · الهدف: WCAG 2.2 AA

## 1. الحقول — التسمية وربط الأخطاء

| المتطلب | الحالة |
| --- | --- |
| Label واضح لكل حقل | ✓ النمط السائد `label.micro-field` يلف الإدخال بالتسمية `<span>` (تسمية برمجية حقيقية)؛ الحقول المساعدة تحمل `aria-label` |
| Placeholder ليس تسمية | ✓ كل placeholder نموذج «مثال: …» مع تسمية `<span>` حقيقية فوقه |
| `aria-invalid` عند خطأ التحقق | **مرتبط في هذه الحزمة**: QuickSaleForm + QuickExpenseForm + LoanEditor بنمط التمييز الموثق أدناه؛ كان مرتبطًا أصلًا في AgreementEditor وSetup وDraftEditor وMaterialSheet |
| `aria-describedby` يربط برسالة الخطأ | ✓ نفس المواضع — فقرة الخطأ تحمل id والحقل يستدعيها عند وجود الخطأ |
| مكوّن Field الأساسي | **رُقّي في هذه الحزمة**: الوصلات تلقائية عند تمرير `controlId` (aria-invalid + aria-describedby + id للفقرة) — عقد المكوّن اكتمل فلم يعد الربط عبئًا على كل مستهلك |

**نمط التمييز الموثق** (جديد في هذه الحزمة): علم `fieldError` منفصل عن رسالة
النموذج — يُرفع فقط لأخطاء التحقق الحقلي («أدخل المبلغ…»)، ولا يُرفع أبدًا
لفشل الحفظ/القراءة (الحقل سليم والتخزين هو الذي فشل). فشل الحفظ يظل معلنًا
برسالة `role="alert"` دون تلويث الحقل.

**المحررات ذات الأخطاء بمستوى النموذج فقط** (CashWallet/Transfer/Adjustment/
OwnerWithdrawal/Material/FinancialEvent/DirectSale/SupplierPurchase/Asset/
G5Declaration/CashOpeningLater): أخطاؤها معلنة نصيًا عبر `role="status"/"alert"`
(3.3.1 Error Identification مستوفى)؛ ربط `aria-invalid` الحقلي لكل واحد منها
مسجل كتحسين موجه لاحق — النمط جاهز ومعمول به في الأسطح الرائدة أعلاه.

## 2. الأزرار والأيقونات

- كل زر أيقوني (`micro-icon-button`) يحمل `aria-label` — تحقق DOM حي على سطح
  القروض: كل الأزرار لها أسماء وصول (اختبار دائم).
- العناصر الزخرفية كلها `aria-hidden="true"` (نمط الأيقونات الموحد).
- لا زر مبني على div — النمط `<button type="button">` موحد (فحص بصري شامل).
- الحالة المعطلة مفهومة: `disabled` أصلي + نص الحفظ «جارٍ التسجيل…» معلن.
- `aria-busy` على زر التحميل في المكوّن الأساسي (Button primitive).

## 3. لوحة المفاتيح

| المتطلب | الحالة |
| --- | --- |
| Tab/Shift+Tab | ترتيب DOM الطبيعي RTL — لا tabindex موجب في أي مكان (لا مسح للترتيب) |
| Enter في النماذج القصيرة | ✓ آمن: نموذج البيع السريع Enter = submit مع حماية الإرسال المزدوج |
| لا Enter داخل textarea | ✓ فحص مصدر ثابت: لا textarea بمعالجات مفاتيح أو submit (4 محررات) |
| لا Enter لحذف عالي الأثر | ✓ كل أفعال الإلغاء/التراجع تمر بلوحة تأكيد/معاينة قبل الكتابة (عقود W1/W2) |
| Escape وتركيز اللوحات | ✓ P-4.4-1: لوحتا «قريبًا» + قائمة الشعار — Escape يغلق ويعيد التركيز للمشغّل وحبس التركيز داخل الحوار (مختبَر) |
| لا Shortcut لكتابة مالية | ✓ لا مستمعي مفاتيح عامين في الإنتاج |

## 4. Zoom وتكبير النص وReflow

- **عائلة الخطوط تحولت بالكامل إلى rem** (375 تعريفًا في index.css + 11 token
  في vf-tokens.css + سلم stylelint وحارس design-tokens معها): تكبير نص
  المتصفح (Chrome/إعداد الخط، Firefox text-only) يكبر كل النص الآن —
  WCAG 1.4.4 Resize Text. **الهوية البصرية عند الجذر الافتراضي 16px لم
  تتغير بالميلي** (NN/16rem ≡ NNpx).
- ما بقي px **عمدًا وموثقًا**: المسافات (سلم §1.3)، أنصاف الأقطار، حدود
  دقيقة، **أهداف اللمس 44/48px** (لا تتقلص مع النص — محروسة بـU-09)،
  `min-width: 320px` على الجذر.
- **Reflow عند 320px**: `html/body { min-width: 320px }` + قواعد الالتفاف
  («التسمية تلتف أينما احتاجت — لا قصّ ولا nowrap» §4 بند ٨) + القصّ
  المحروس لتسميات التنقل فقط (W3/U-04).
- **Zoom 200%**: صفحات متراكبة عموديًا بلا أعمدة أفقية ثابتة — لا تمرير
  أفقي على المقاسات المعتمدة (يُثبت حيًا في P-4.4-6 على المقاسات الثلاثة).

## 5. التباين والحركة

- **القيم الفعلية** لا الافتراض: حارس theme-contrast-guard يقيس 82 زوجًا
  نصيًا/علاميًا في الوضعين — نص ≥ 4.5:1 وعلامات ≥ 3.0:1 — كلها تمر.
- لا لون وحده: `data-negative` للسالب + كلمة الأثر النصية + الشرائح
  المختارة بتسطير معلن (aria-pressed) + درجات المعرفة بكلمات.
- `prefers-reduced-motion`: 7 قواعد إيقاف حركة — فحص مصدر ثابت يدوم.
- لا حركة جديدة أضيفت في الموجة.

## 6. الاختبارات (Accessibility.w44.dom.test.tsx — 7)

1. أسماء وصول كل أزرار سطح القروض (DOM حي).
2. خطأ التحقق يرفع aria-invalid + يربط الرسالة (نموذج البيع السريع حيًا).
3. مكوّن Field: الوصلات التلقائية عند controlId.
4. لا textarea بمعالجات إرسال (مصدر ثابت).
5. الأفعال عالية الأثر لها مسار تراجع موثق (مصدر ثابت).
6. لا font-size بpx متبقية + أهداف اللمس px محروسة (مصدر ثابت).
7. prefers-reduced-motion حاضر (مصدر ثابت).

## 7. سجل تحويل rem (الموثق المطلوب)

| العائلة | قبل | بعد | السبب |
| --- | --- | --- | --- |
| `--vf-text-*` (11 tokens) | px | rem | تكبير نص المتصفح يحترم السلم الرسمي |
| `font-size` في index.css (375) | px | rem | كل تعريفات الخط — عائلة واحدة كاملة |
| سلم stylelint + حارس design-tokens | px | rem | الحراس يتبعون العقد الجديد بنفس القيم (NN/16) |
| المسافات/الأنصاف/الحدود/الأهداف | px | **px (بقيت)** | لا تكسر تكبير النص، والأهداف اللمسية لا تتقلص عمدًا |
