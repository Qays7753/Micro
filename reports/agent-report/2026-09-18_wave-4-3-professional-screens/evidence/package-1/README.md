## ما تحقق حيًا إضافًا (بلا لقطة — سلوك تفاعلي)

- زر الشعار عنصر `button` بارتفاع **44px** فعلي (قيس بالـDOM) وبـ`aria-label="قائمة Micro"` و`aria-haspopup/aria-expanded` (D2).
- الإغلاق بـEscape يعيد التركيز إلى زر الشعار (D3) — تحقق DOM مباشر.
- الإغلاق بالنقر خارج القائمة (D3).
- شعار ثابت الموضع لا يغطي الإجراءات الأساسية.
