## ما تحقق حيًا إضافًا

- تسجيل التزام من مسار «شو عليّ؟» فتح الكاتب الرسمي `/finance/new/operating_expense_payable?returnTo=/finance` وعاد بعد الحفظ إلى المالية والرقم تجمّع فورًا من مصدرَيه.
- رجوع ديناميكي لسلامة الحسابات حسب المصدر (من المالية ← «المزيد من المالية»).
- الحالة الفارغة الصادقة لكل بطاقة مركز («غير مسجل» بدل 0.00 مضلل — D8).
