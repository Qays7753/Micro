# أدلة Wave 4.3 الحية (Live Evidence)

كل اللقطات أدناه من **QA حي بمحاكي متصفح headless** (agent-browser/Chromium) على بناء React dev للتطبيق، جلسة بيانات اختبار نظيفة (مشروع «مشغل أم للعطور» أُنشئ خلال الجلسة نفسها). **لم يُختبر جهاز فعلي** — القيود موثقة في تقرير Wave 4.3 §«ما لم يُختبر فعليًا».

## طريقة القراءة

- الاسم `pN-XX-وصف-العرض-النمط.png` = الحزمة N من حزم P-4.3-1..6.
- العرض: 360 / 390 / 430 بكسل. النمط: فاتح (light) أو ليلي (dark).
- كل لقطة تُثبت شيئًا محددًا مذكورًا في README حزمتها.

## نطاق الجلسة الحية الموثقة بالأدلة

| المحور | النتيجة |
|---|---|
| المقاسات الثلاثة × الوضعين | لا تمرير أفقي على أي سطح مُفحص (~60 فحص مسار×مقاس، منها 16 مسارًا عميقًا على 360 و15 على 430) |
| أخطاء Console عبر الرحلة الكاملة | **صفر** (تشمل: إعداد → بيع سريع → طلب كامل → تسليم → تحصيل → مشاركة → توزيع → إعدادات/وضع ليلي) |
| الشريط السفلي | 5 مقاعد بالترتيب المعتمد دائمًا (مشروعي الآن، العمل، المالية، أدواتي، السوق) — لا سادس |
| قائمة الشعار | فتح/إغلاق بـEscape مع إعادة التركيز للشعار، إغلاق بالنقر الخارجي (مختبر حيًا) |
