## ما تحقق حيًا إضافًا

- مجموعات حالة العمل (يحتاج تنفيذًا الآن/ينتظر العميل/ينتظر تحصيلًا/تم تسليمه + الملغاة المطوية) ظهرت بالتتابع الصحيح أثناء دورة حياة الطلب.
- إعادة فتح ورقة التحصيل بعد الاكتمال تعرض «لا ديون» الصادقة — لا رسالة نجاح قديمة (متطلب F06: إعادة فتح التفاصيل).
- «تراجع موثق» حاضر في نصوص الأثر الظاهرة (قاموس P-4.3-4).
