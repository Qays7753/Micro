> **مصدر الحقيقة:** ملفات Markdown هي المصدر المعتمد. ملف Word هو نسخة عمل للمالك.
>
> **منهجية القياس:** مسح الكود كاملًا في `MicroRouter.tsx` وكل صفحات `src/pages/` وكل خدمات `src/application/`، إضافةً إلى مشي التطبيق المباشر على `https://micro-prototype.pages.dev/` بعرض 390px. المسارات المؤكدة مباشرةً موسومة ✓؛ المسارات المشتقة من الكود موسومة `من الكود`.

## مفتاح الأعمدة

### أعمدة القياس (حقائق)

| العمود | التعريف |
|---|---|
| `ID` | معرّف ثابت `F-001` فصاعدًا |
| `الاسم الظاهر` | التسمية العربية التي يراها المستخدم، أو `بلا تسمية ظاهرة` |
| `الوظيفة` | ما يفعله في جملة واحدة |
| `المسار` | الـ route |
| `مسار الوصول` | سلسلة النقرات حرفيًا من فتح التطبيق |
| `عدد النقرات` | عدد النقرات في المسار |
| `عدد المداخل` | كم مسارًا مختلفًا يصل إليه |
| `درجة الظهور` | حسب مقياس الطبقات أدناه |
| `شرط الظهور` | `دائم` أو الشرط |
| `يفترض نوع نشاط؟` | `نعم — ويفترض: <ماذا>` / `لا` |
| `من أساسيات التأسيس؟` | `نعم` / `لا` |
| `يعتمد على` | ما يجب أن يوجد أولًا |
| `الحالة الفارغة` | ما يراه المستخدم بلا بيانات |
| `موقع الكود` | `path:line` |
| `العقد الحاكم` | ملف في `docs/contracts/` أو `لا يوجد` |
| `تغطية الاختبار` | `مغطى` / `جزئي` / `بلا اختبار` |

### مقياس درجات الظهور

| الدرجة | التعريف |
|---|---|
| `أ — رئيسي` | في التنقل السفلي أو المنطقة الرئيسية للشاشة الأم |
| `ب — ثانوي` | نقرة واحدة من سطح رئيسي، ظاهر بلا توسيع |
| `ج — مدفون` | ثلاث نقرات أو أكثر، أو خلف طبقة مطوية |
| `د — مشروط` | يظهر فقط عند تحقق شرط (بيانات، وضع، حالة) |
| `هـ — غير قابل للوصول` | موجود في الكود بلا مسار من الواجهة أصلًا |

## ✦ ✦ ✦ فاصل: ما يليه رأي وليس قياسًا ✦ ✦ ✦

### أعمدة الرأي (تقدير الكارتوغرافي)

| العمود | التعريف |
|---|---|
| `التكرار المتوقع` | `يومي` / `أسبوعي` / `شهري` / `مرة واحدة عند التأسيس` / `نادر` + سبب في سطر |
| `القيمة اليومية` | هل استخدامه يغيّر ما يفعله المالك اليوم؟ `عالية` / `متوسطة` / `منخفضة` |
| `الفجوة` | المسافة بين موقعه وتكراره (يومي في `ج` = فجوة كبيرة) |
| `توصيتي بالموقع` | أين أضعه ولماذا في جملة |
| `مخاطرة النقل` | `منخفضة` / `متوسطة` / `عالية` + ماذا ينكسر |

### أعمدة المالك (فارغة — يملؤها هو)

| العمود | التعريف |
|---|---|
| `تكراري:` | يكتب المالك تكراره الفعلي |
| `قراري:` | يكتب المالك قراره بالنقل أو الإبقاء |
