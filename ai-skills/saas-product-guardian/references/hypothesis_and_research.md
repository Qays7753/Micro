# الفرضيات والبحث

## مستويات الدليل

| المستوى | المعنى |
|---|---|
| حقيقة مالية/تقنية | قاعدة يجب ألا تنكسر أو معلومة يمكن توثيقها مباشرة |
| دليل مستخدم | سلوك أو نتيجة ظهرت مع مستخدم حقيقي، ولا تعمم وحدها |
| دليل خارجي | تقرير أو دراسة أو مشروع، يرفع احتمال الفرضية ولا يثبت سوقنا |
| دليل كود | طريقة تنفيذ أو pattern، لا يثبت حاجة المستخدم |
| فرضية مرجحة | منطق معقول يحتاج اختبارًا |
| مجهول تجاريًا | لا دليل على العودة أو الدفع أو الحجم |

## محاور التحقق

افحص التكلفة والتسعير والربح والكاش، الطلب والموعد والقدرة، مصدر الاتفاق خارج النظام، المواد والمخزون والهدر، الوقت، الخصوصية والأوفلاين، التدريب، العودة، واستعداد الدفع.

## بطاقة البحث

لكل ادعاء سجّل: الادعاء، المستخدم، السياق، الضرر، الحل الحالي، النتيجة المطلوبة، المصدر، قوة الدليل، البدائل، ما قد ينقضه، طريقة الاختبار، معيار القبول، وتاريخ المراجعة.

## قواعد بحث GitHub

اقرأ README والكود والاختبارات والـissues وملف LICENSE. ميّز بين maturity وstars. لا تعتبر feature موجودة دليل ضرورة. افحص commit أو release عند الاستفادة. سجّل provenance. إذا غاب الترخيص، لا تنسخ الكود. إذا كان الترخيص Copyleft أو BSL، اعرض المخاطر ولا تقتبس قبل مراجعة قانونية.

## أسئلة تمنع الانسياق

- هل هذه مشكلة مستخدم أم حل أعجبنا؟
- هل تظهر في الحرفة والطعام والخدمة أم في قطاع واحد؟
- هل أقل حل عبارة عن قاعدة أو نص أو تذكير بدل وحدة جديدة؟
- هل سيغير المستخدم قرارًا فعليًا؟
- هل القيمة تستحق الحقول والحالات والصيانة؟
- ما الذي سنحذفه عمدًا؟
- ما الذي لا نعرفه بعد؟
