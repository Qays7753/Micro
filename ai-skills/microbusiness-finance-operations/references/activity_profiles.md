# Activity Profiles

## الأطعمة المنزلية

ابدأ من وصفة اختيارية: مكونات، كمية، وحدة، سعر وتاريخ، تغليف، هدر، yield، وعدد حصص. عند الطلب، اسأل عن الكمية وموعد التسليم. احسب تكلفة الدفعة والوحدة، واحفظ snapshot عند اعتماد السعر. أظهر نقص البيانات أو قدمها بدل إخفائها.

لا تجعل allergen أو nutrition أو procurement أو forecasting شرطًا للـMVP.

## الحرف اليدوية

ابدأ من قطعة أو طلب مخصص: خامات، كمية، وقت تصميم وتنفيذ، تخصيص، تغليف وتوصيل. اسمح بتعديل المواصفات قبل التأكيد وبعده عبر revision. احفظ snapshot للتكلفة والسعر وقت الاتفاق. لا تفترض أن كل خامة مخزون قابل للعد؛ بعض المواد تُسجل كمصروف أو مورد مشترك.

لا تجعل BOM متعدد المستويات أو الإنتاج الدفعي أو lot traceability شرطًا للنسخة الأولى.

## الخدمات

ابدأ من خدمة: مدة تقديرية، موعد، توفر، مواد، تنقل، عمولة، سعر ثابت أو مبني على وقت. اعرض تعارض الموعد وتحذير القدرة دون حظر. بعد التنفيذ، استخدم checklist أو ملاحظة إتمام، ثم التحصيل. اجعل قياس الوقت الفعلي اختياريًا.

لا تفرض مخزونًا أو فاتورة أو موظفين أو dispatch على خدمة فردية.

## النواة المشتركة

كل profile يستخدم customer، catalog item أو service، cost structure، price decision، order، reminder، collection، result. الحقول المشتركة لا تعني أن الشاشة أو الشرح متطابقان.

## قاعدة التصميم

عند إضافة حقل، اسأل: هل هو ضروري لإجابة سؤال المستخدم الآن؟ إن كان خاصًا بقطاع، ضعه داخل profile. إن كان اختياريًا، لا تجعله يوقف التسجيل. إن كان يغير الحساب، أظهر أثره وتاريخ إدخاله.
